先审阅安装脚本并确认系统环境，然后接入你准备使用的模型账户。

01

检查系统环境

安装脚本会自动检测你的操作系统和处理器架构，在 Linux 上还会检测 C 标准库（glibc 或 musl），并仅安装对应平台已签名的官方发行包。{{with .Latest}}每条安装命令下方的说明列出了 {{.Version}} 版本支持的平台。{{end}}

Linux 和 macOS 需要 curl、tar、gzip 和 openssl（macOS 已自带）；Windows 仅需 PowerShell。支持 macOS 11 及以上版本、Windows 10 版本 1809 及以上版本（目前均为公测版）。在 Linux 和 macOS 上请以普通用户身份运行安装脚本，切勿使用 root；在 Windows 上无需管理员权限。

02

安装前自动校验

上方的安装命令会在替换可执行文件前自动校验数字签名与归档校验和。

运行前可先审阅安装脚本源码：install.sh 或 install.ps1。若需离线审阅，请先保存脚本并检查内容，随后执行 sh install.sh，或在 PowerShell 中执行 .\install.ps1。

03

在项目中启动

cd path/to/your-workspace
rune

在 Settings → Connections 中接入你的模型账户，随后在 Models 中选定模型。建议从 Ask 模式开始，逐一审阅每条命令和每次编辑。

安装脚本选项

可通过环境变量指定版本号、安装目标绝对路径，或在 Linux 上指定 C 标准库。未设置时默认安装已发布的最新版本、写入用户 bin 目录并自动检测环境。若已将审阅后的脚本保存为 install.sh：

RUNE_VERSION=X.Y.Z sh install.sh
RUNE_INSTALL_DIR="$HOME/bin" sh install.sh
RUNE_LIBC=musl sh install.sh

在 PowerShell 中，先设置环境变量，再运行安装命令：

$env:RUNE_VERSION = "X.Y.Z"
irm {{.Origin}}{{url "install.ps1"}} | iex

请将 X.Y.Z 替换为已发布的版本号。以上示例均为独立可选项，并非需要依次执行的步骤。若目标系统、处理器或标准库没有对应的构建包，安装脚本会拒绝执行。

更新现有安装

针对目标版本重新运行安装脚本即可（若此前自定义了 RUNE_INSTALL_DIR，请保持一致）。脚本会校验下载包并一步替换程序。完成后可运行 rune -version 确认。

在 Linux 和 macOS 上，版本兼容的已打开会话会在空闲时自动切换至新构建版本；在 Windows 上，新打开的 Rune 窗口会使用新版本。请勿强行终止正在执行的任务。重要项目和 Rune 数据请保持独立备份。

“rune: command not found”

安装脚本会输出可执行文件所在的目录。你可以使用完整路径直接运行 rune，或手动将该目录加入 PATH；安装脚本绝不会自动修改你的 shell 配置文件或 PATH。若使用默认目录，可将以下行添加到 ~/.bashrc 或 ~/.zshrc：

export PATH="$HOME/.local/bin:$PATH"

在 fish 中，只需运行一次 fish_add_path ~/.local/bin。在 Windows 上，请参阅安装与更新中的 PowerShell 命令。配置完成后请打开一个新终端窗口。

卸载 Rune

完成或停止手头任务并关闭所有 Rune 窗口，然后删除程序文件及其许可证声明。若此前自定义了安装目录，请将 ~/.local/bin 替换为你的实际目录。

rm ~/.local/bin/rune
rm -r ~/.local/share/runeagent

在 Windows 上，请参阅安装与更新中的 PowerShell 卸载步骤（包括收回 Rune 命令沙盒的访问权限）。你的设置、会话记录、加密密钥及还原点数据会保留在 Rune 数据目录中，直到你手动删除。运行 rune -config 输出的第一行即为该目录路径，请在删除程序前查看。删除数据目录会清除历史记录和还原点，仅卸载程序时无需删除它。
