一条命令安装，进入你的工作区。

先审阅安装脚本并确认系统环境，然后接入你准备使用的模型账户。

01

检查系统环境

安装脚本会自动检测你的操作系统和处理器架构，在 Linux 上还会检测 C 标准库（glibc 或 musl），并仅安装对应平台已签名的官方发行包。{{with .Latest}}每条安装命令下方的说明列出了 {{.Version}} 版本支持的平台。{{end}}

Linux 和 macOS 需要 curl、tar、gzip 和 openssl（macOS 已自带）；Windows 仅需 PowerShell。支持 macOS 11 及以上版本、Windows 10 版本 1809 及以上版本（目前均为公测版）。在 Linux 和 macOS 上请以普通用户身份运行安装脚本，切勿使用 root；在 Windows 上无需管理员权限。

02

安装前自动校验

上方的安装命令会在替换可执行文件前自动校验数字签名与归档校验和。

运行前可先审阅安装脚本源码：install.sh 或 install.ps1。若需离线审阅，请先保存脚本并检查内容，随后执行 sh install.sh，或在 PowerShell 中执行 .\install.ps1。

03

在项目中启动

cd path/to/your-workspace
rune

在 Settings → Connections 中接入你的模型账户，随后在 Models 中选定模型。建议从 Ask 模式开始，逐一审阅每条命令和每次编辑。

体验你的第一次会话

安装会对你的机器做哪些改动

单个可执行文件
Rune 会安装在 ~/.local/bin/rune，Windows 上则位于用户目录下的 .local\bin\rune.exe。无需 root 或管理员权限。
不改动 Shell 配置
绝不修改你的 shell 配置文件。如果该文件夹不在 PATH 中,安装脚本会把 Rune 链接到一个已在 PATH 中的文件夹并说明这一点,或打印一行命令,让你当前窗口立即可以运行它。在 Windows 上,脚本会把该文件夹加入你的用户 PATH,新窗口也能找到 Rune。
许可证声明
保存在用户数据目录旁：~/.local/share/runeagent，Windows 上为 %LOCALAPPDATA%\RuneAgent。
你的 Rune 数据
设置、会话记录和加密存储的密钥保存在主目录下的单一数据文件夹中，在首次启动 Rune 时创建。
自备模型接入
使用你自己的模型提供商账户或受支持的本地服务端点。Rune 不预置任何 API 额度。
了解签名校验机制

安装脚本选项

安装脚本会输出它使用的安装目录,且绝不修改 shell 配置文件。在你已打开的窗口中运行下面这一行,rune 便能立即使用,无需新开终端。若希望之后打开的终端也能使用,请自行把同一行加入 ~/.bashrc 或 ~/.zshrc:

export PATH="$HOME/.local/bin:$PATH"

在 fish 中,只需运行一次 fish_add_path ~/.local/bin。在 Windows 上,安装与更新中给出了 PowerShell 命令;安装脚本已为你添加该目录,新窗口可直接找到 rune。

卸载 Rune

完成或停止手头任务并关闭所有 Rune 窗口，然后删除程序文件及其许可证声明。若此前自定义了安装目录，请将 ~/.local/bin 替换为你的实际目录。

rm ~/.local/bin/rune
rm -r ~/.local/share/runeagent

在 Windows 上，请参阅安装与更新中的 PowerShell 卸载步骤（包括收回 Rune 命令沙盒的访问权限）。你的设置、会话记录、加密密钥及还原点数据会保留在 Rune 数据目录中，直到你手动删除。运行 rune -config 输出的第一行即为该目录路径，请在删除程序前查看。删除数据目录会清除历史记录和还原点，仅卸载程序时无需删除它。
