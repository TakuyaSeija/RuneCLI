添加模型提供商

提供商（provider）即负责响应 Rune 模型请求的服务端账户。Rune 本身不内置账户，也不附带任何预置 API 额度：每次请求均直接发送给你所接入的提供商，并由其计费。

  1. 按 Ctrl+G，打开 Connections 并选择 Add connection。
  2. 在 MODEL PROVIDERS 下选择对应的提供商预设；若接入其他兼容 OpenAI 协议的接口，请选择 compatible。
  3. 如果所选预设没有固定接口地址，请先输入你的接口地址；随后将 API 密钥粘贴到带掩码的输入框中并按 Enter。
  4. 在保存连接前，Rune 会发送一次真实请求来验证账户。该请求可能会产生计费，并会向提供商发送简短的测试文本。
  5. 打开 Models，选择该提供商并按 Enter 选定一个模型。

成功保存连接证明该账户完成了一次响应，但并不代表该提供商列表中的每一个模型都对你的账户开放。API 密钥在你的电脑上加密存储，详见凭据加密。

各提供商使用说明

不同提供商和不同模型的推理控制方式各有差异。以下说明列出了 Rune 实际发送的参数行为；上游提供商仍可能自行调整模型的具体执行方式。你可以在 Models 页面对模型按 Alt+C 配置可选推理级别，详见生成与推理。

alibaba
请使用阿里云百炼（Model Studio）对应工作区与地域的兼容模式地址，并搭配同一地域的密钥。思考模式仅支持开启（on）或关闭（off），不区分强度级别。对于始终强制思考的模型，切勿将其配置为可选 Off，否则服务端会拒绝请求。百炼上的 GLM 模型需要传入 Rune 未发送的特定专有参数才会返回工具调用，建议通过 Z.ai 调用 GLM 模型。
cerebras
各模型的推理级别不尽相同，且服务端模型列表不会直接返回这些级别。gpt-oss-120b 与 qwen-3.8-27b 支持 Low、Medium 和 High，可通过 Alt+C 手动添加。
cloudflare
即 Workers AI。接口地址中包含你的账户 ID，密钥需使用具备 Workers AI 访问权限的 API 令牌（而非 Tunnel 令牌）。可用模型从你账户的模型列表中读取。
compatible
任意兼容 OpenAI 协议的接口。Rune 不会对其模型能力做任何预设假设：请对照该接口自身的文档，使用 Alt+C 设置上下文窗口、输出上限及推理选项。
deepinfra
其模型列表会返回价格并标记支持推理的模型。推理级别为 Low、Medium 和 High；未显式选择级别时使用模型自身的默认设置。
fireworks
推理级别涵盖 Low 到 Max。若某个模型仅支持其中部分级别，可通过 Alt+C 调整。
huggingface
接入 Inference Providers 路由服务，需使用具备调用 Inference Providers 权限的令牌。具体由哪家后端服务商承载某模型及其支持的特性，取决于该模型与路由组合。
inclusionai
通过蚂蚁集团百灵（Ling）API 调用 InclusionAI 的 Ling 系列模型。3.0 和 3.1 系列模型仅支持开启或关闭思考，不区分级别。若为你自行托管的 Ling 服务，请使用 compatible 预设添加。
inference
其模型列表会直接声明每个模型支持的思考级别，Rune 会原样提供这些选项。
meta
接入 Meta Model API（非 Meta AI 聊天网页版登录）。推理级别从 Minimal 到 Extra high。Muse Spark 模型始终启用推理，且会拒绝 Off 请求与停止词（stop words），因此在 Generation 中请将 Stop 留空。
mimo
按量计费密钥与 Token Plan 密钥对应不同的接口地址；Rune 会根据你输入的密钥前缀自动匹配地址。
minimax
Rune 会请求将思考过程与正文回答分离返回。目前仅 MiniMax-M3.1-Flash 支持推理强度级别（Low 到 Max），可通过 Alt+C 添加。请勿为 MiniMax 模型配置 Off 选项。
moonshot
即 Kimi。kimi-k3 支持 Low、High 和 Max 级别（可通过 Alt+C 添加）；kimi-k2 系列不设强度级别。请勿为 Kimi 模型配置 Off 选项。
novita
在同时支持思考开关的模型上，思考模式仅分开启或关闭，不设强度级别。单价直接从其模型列表中读取。
nvidia
托管版 NIM API。各模型的思考控制方式不同且未在服务端列表中标出，请对照对应模型的文档卡片逐个配置。自托管 NIM 请填入你自己的服务地址。
openrouter
单个账户即可调用众多不同价格与配额的模型。请准确选择目标模型并核对其当前单价。
siliconflow
默认使用国际站地址；.cn 国内站账户请填入对应的国内站地址与密钥。对于 SiliconFlow 标记支持思考开关的模型，可切换思考开启或关闭。注意：deepseek-ai/DeepSeek-V3.1 仅在关闭思考（off）时才支持工具调用。
stepfun
推理级别为 Low、Medium 和 High。其中 step-3.5-flash-2603 仅支持 Low 与 High，请通过 Alt+C 为其移除 Medium。
tencent
腾讯混元正在迁移至 TokenHub：请输入输入框旁提示的对应地域 TokenHub 地址，并搭配同一地域的密钥。思考模式支持开关及 Low、Medium、High 三个级别。TokenHub 代托管的部分第三方厂商模型会拒绝 Off 请求。
together
其模型列表提供单价信息，但不包含思考级别元数据：请根据模型文档使用 Alt+C 手动添加支持的级别。
tokenrouter
指位于 tokenrouter.com 的 TokenRouter 服务。其他域名上的同名或近似名称服务属于不同公司，各自使用不同的接口地址。
zai
Z.ai 标准 API。Coding Plan 套餐拥有独立的密钥、接口地址和受支持工具列表。推理级别从 Minimal 到 Max，未指定时默认使用服务端默认值（Max）。glm-5.3 始终开启思考且仅接受 Low、High 和 Max。停止序列最多只接受 1 个停止词。

本机运行的模型服务

Ollama 在本机 11434 端口提供本地模型推理服务，无需密钥。注意这与 Ollama 的云端网页搜索服务不同。使用本地模型可将提示词留在你的电脑上，但网页工具、辅助任务和终端命令仍可能访问外部网络服务。

9router 是运行在你电脑上的本地路由应用（默认监听 20128 端口），负责将请求转发给由你在其中配置的上游账户。只需在 Rune 中添加一次连接，即可使用它提供的所有模型。对于 Claude Code 系列模型（cc/…），Rune 会自动走 9router 的 Anthropic 原生协议接口，从而准确获取缓存与思考 token 统计，无需额外配置。Off 仅代表关闭推理请求：当某条路由声明无法关闭思考时，选择 Off 会自动改为请求 Low 级别。

预设中的本机地址只是默认端口配置，并不代表相关服务已经在你的电脑上运行。请先启动对应的本地服务，Rune 的连接测试会告诉你服务是否正常响应。

密钥环与账户管理

单个连接下可以保存多把密钥。运行 rune -provider keys <name> 可查看脱敏后的密钥列表，Connections 页面也可在不暴露明文的情况下管理它们。当某把密钥返回余额不足或耗尽自身配额时，Rune 会立即交棒给环中的下一把密钥；详见运行时与重试。

移除连接会删除其账户配置，但关联的密钥仍可能保留在加密凭据库中供日后复用；若需彻底删除某把密钥，请显式执行删除密钥操作。API 密钥绝不会通过明文 HTTP 发送给其他机器。

选择模型

Settings → Models 会列出已接入提供商返回的模型，并支持手动刷新列表。按 Enter 即可选定模型，也可直接在对话中输入 /model provider:id。在模型条目上按 Alt+C 可编辑 Rune 记录的模型元数据：上下文窗口大小、输出上限、可选推理级别以及单价。你填入的单价仅用于计算侧边栏显示的估算花费，不等同于提供商的正式账单。

Models → New-session fallback 用于指定新建会话默认使用的初始提供商，不会切换已打开的现有对话；若要在当前会话中切换，请使用 /provider 或 /model。
