启动与查看

请在操作系统的终端 shell 中运行以下命令。当前已安装版本的权威帮助信息可通过 rune -help 查看。会连接提供商、修改账户、删除数据或启动服务进程的命令属于实际操作，并非无副作用的诊断标志。

rune [dir]
在当前目录或指定工作区目录中打开交互式智能体界面。
rune -p "prompt"
执行单次提示词并直接打印回答与工具进度，不进入全屏界面。在无人交互响应的情况下，权限请求会被直接拒绝，而不会静默放行。
-project <dir>
为其他命令指定目标工作区目录。
-version · -help
打印应用版本号或命令行参考说明。
-settings · -tools
查看当前生效的模型控制参数，或提供给智能体的工具列表。
-read-only
限制会修改文件的工具。注意：这并不保证不读取任何文件或不向外发送任何数据。
--no-color
禁用彩色输出。同时也支持标准 NO_COLOR 环境变量。

配置管理

-config
显示当前选定的设置文件路径。
-config show|defaults|check
显示当前生效值、显示出厂默认值，或校验配置文件语法。show 的输出可能包含私有账户元数据；check 仅校验语法，不验证网络连通性。
-config explain <key>
说明单个配置键的当前生效值及生效时机。
-config set <key> <value>
保存一项全局配置。例如：rune -config set terminal.command_timeout 2m。
-config reset <key>
移除全局覆盖值，恢复当前默认值或继承关系。
-config format
在不改变配置语义的前提下重新格式化分组设置。
-set key=value
修改受支持的工作区/模型偏好，而非任意全局配置键。

账户与模型

建议优先使用 Connections 界面下带掩码的凭据编辑器。在命令行参数中直接传入真实密钥容易通过 shell 历史记录和进程列表泄露。下方语法示例特意使用了占位符。

rune -provider add <name> -key <key> [-preset <p>] [-base <url>] [-model <id>]
-provider list
列出已配置的账户、预设及网页服务可用状态。
-provider key <name> <key>
向指定账户的密钥环中添加一把密钥。此操作会修改凭据存储。
-provider keys <name>
查看脱敏后的密钥元数据。
-provider dropkey <name> <n>
在确认密钥身份后，移除指定序号的凭据。
-provider default <name>
设置新会话的默认回退提供商；不会切换所有现有对话的提供商。
-provider remove <name>
移除提供商配置。请勿假设此前保存的所有凭据都已被安全擦除。
-provider test <name>
发送一次真实的、可能产生计费的请求以测试该账户。
-provider models <name>
查询该账户下的可用模型目录。会发起网络请求。
-provider dryrun <name> [model]
预览请求内容而不实际发送。预览中可能包含私有上下文，请勿直接原样公开分享。
-provider timeout <name> <seconds>
为该账户设置可选的请求超时（5–3600 秒）；设为 default 可移除覆盖值。
-provider new-store --yes
将无法读取的旧凭据存储搁置一旁，并初始化全新的空凭据库。仅在深思熟虑决定恢复时使用；执行后需重新添加所有密钥。
-model list · -model set <id>
列出或选择目标工作区使用的模型。

会话与存储

-session · -resume <id>
打开会话选择器（通过管道调用时则输出列表），或恢复已知 ID 的会话。
-session rename <id> <title>
重命名指定会话。
-session delete <id>
永久删除指定会话。执行前请先核对会话身份。
-storage [list|prune]
查看各项目的存储占用，或清理已不存在的旧项目所残留的符合条件的数据。
-sandbox [setup|reset]
查看 Windows 命令隔离状态、显式配置其专用沙盒账户，或移除 Rune 的沙盒访问权限与账户配置。其他平台不使用此项配置。

扩展与诊断

-skills [operation]
列出、查看、启用、禁用、安装或重新加载可复用的技能指南。安装操作会接收已审阅的文件夹或 zip 归档，除非指定 --scope user 设为个人级，否则默认放入当前项目中。
-mcp [operation]
管理、批准、校验并测试外部工具定义。建立连接可能会启动本地子进程或访问远程服务；仅通过配置校验并不代表连接已成功建立。
--scope user|project|private-project
为扩展能力变更选择配置作用域。修改共享的 project 作用域会影响该项目的所有协作者。
-doctor
运行诊断检查（包含网络连通性检查）。该命令可能发起网络请求，分享输出前请先审阅内容。
-db <path>
使用替代的引擎数据库文件。这与通过 RUNE_HOME 切换整个设置主目录相互独立。
-host
启用按行分隔的 JSON 协议供前端集成调用，而非打开交互式终端界面。它不是公开的网络服务器。
-script <file>
回放预先编写的模型脚本。脚本可能会发起真实的工具调用，切勿在实际工作区中运行未经审阅的脚本。

关于扩展能力的配置与权限控制，请继续阅读技能（Skills）或 MCP 连接。切勿仅仅为了绕过某个报错而盲目切换到 Full 模式或删除本地数据。
