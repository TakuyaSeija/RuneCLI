配色主题

Settings → Appearance → Color theme 提供 Violet（紫罗兰）、Cyan（青色）和 Amber（琥珀）三种主题。在该行按左右方向键可直接切换并保存；按 Enter 会打开独立列表，在列表中按 Enter 应用所选主题，按 Esc 则放弃仅浏览未确认的选项并返回。出厂默认主题为 Amber。

主题仅影响界面视觉呈现，不改变模型行为或权限。也可以使用 /theme violet、/theme cyan 和 /theme amber 选择主题。对应的全局配置键为 ui.theme；重置该项将移除你的覆盖设置。

对话侧边栏

可在 Appearance 页面、使用快捷键 Ctrl+O 或执行 /panel 切换侧边栏。出厂默认设为开启。在较窄的终端窗口中，即使该偏好处于开启状态，并排显示的侧边栏也可能自动隐藏。隐藏侧边栏不会停止用量统计、文件跟踪或任务计划更新。

由终端自身控制的外观

壁纸、透明度、背景模糊、窗口装饰及字体渲染均由你的终端模拟器或桌面环境控制。Rune 本身不设背景图片或模糊选项。同一套主题在浅色或深色终端背景下可能呈现不同的视觉效果。

组合键与鼠标手势同样取决于终端配置。某些终端配置可能会将 Ctrl+滚轮保留为缩放、将 Alt+滚轮保留为横向滚动，或将部分快捷键占用为终端自身操作。

高级显示选项

ui.mouse
默认 true。启用 Rune 内的鼠标点击、滚轮滚动与拖拽复制；设为 false 则将所有鼠标选择交给终端处理。
ui.scroll_lines
滚轮每格移动的行数，默认 2（1–30）。
ui.scroll_smooth
默认 true。在支持同步整帧绘制且达到 30 fps 以上的终端上启用平滑滚动，其余终端按格跳转。

这三项鼠标与滚动偏好属于 TOML 专属选项，而帧间隔、Escape 判定时间与颜色探测属于固定的运行时常量。滚动偏好无法让终端上报其本身不支持的输入。

rune -config explain ui.theme
rune -config reset ui.theme

重置会直接修改全局偏好设置。请使用 /help 查看当前版本的阅读与导航快捷键，不要凭其他终端应用的习惯盲目猜测。
