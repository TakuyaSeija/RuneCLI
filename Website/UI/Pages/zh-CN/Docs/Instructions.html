项目引导文件

工作区根目录下的 AGENTS.md 用于提供项目引导说明：构建命令、代码规范以及与当前项目相关的边界约定。它不是存放 API 密钥的文件，不代表授予执行权限，也不是分类器策略文件。请勿在其中写入凭据，且只放入你确实打算作为上下文发送给模型的文本。

自动注入项目引导文本的出厂配额上限为 32,768 个字符，由 Settings → Tools → Project instructions 中的 instructions.max_chars 控制。当文件超出该配额时，Rune 会明确说明省略了哪一部分，AI 在依赖后续规则前会主动读取剩余部分；超出部分并不会凭空消失。如果会话期间引导文件发生了改动，Rune 会通知模型重新读取相关源文件。

准确添加附件

/attach <path> 会将文件添加到下一条待发消息中；/detach <number|all> 则用于移除待发送附件。发送前请先核对待发送列表。不同模型对文本、图片或其他媒体格式的支持程度各不相同；成功挂载文件本身并不代表模型一定能理解其内容。

已发送的附件绑定的是发送那一刻的文件版本。后续编辑该路径下的文件，绝不会把旧消息里的附件暗中替换成新字节。当原始文件内容无法恢复时，Rune 会如实报告文件已更改或已消失，而不会拿新内容冒充旧内容。如果任务需要使用修改后的新版本，请显式重新添加附件。

出厂默认限制包括：每个附加文本文件最多读取 60,000 个字符，且历史对话中最多保留 10 个附件。受上下文窗口与提供商请求体大小限制，较早的媒体附件可能会提前移出上下文。这些限制与当前消息的附件列表以及对话界面的折叠显示相互独立。

项目记忆（Memory）

Rune 支持带有 MEMORY.md 索引的持久化项目笔记；关于笔记存放位置及模型如何读取它们，详见项目记忆。模型在会话开启时只会收到索引文件，而不会自动收到每一篇笔记的正文，仅在需要时按需读取相关笔记。索引召回预算默认为 20 KiB；调大该预算会在每次请求中占用更多模型上下文，但并不会让笔记内容变得更准确。

建议将项目记忆用于记录稳定的架构决策、纠错说明和跨会话延续的工作。请勿在其中存放凭据或每次临时命令的输出结果。笔记内容可能会包含在后续的模型请求中，且不能作为独立的权限来源。模型通过文件工具配合虚拟路径 @memory/ 访问项目记忆，而不会在你的代码仓库内创建 memory 目录。

分清各类文件的职责

AGENTS.md
作为模型上下文提供的项目开发引导说明。
CLASSIFIER.md
用于对适用的 AI 操作进行策略审查的规则文件。它有独立的重新加载机制，不等同于项目引导说明。
rune.toml
保存在所选 Rune 主目录下的全局设置文件。项目目录内的同名文件不会自动成为全局设置文件。
Skill（技能）
针对特定任务激活或读取的可复用指南。它本身无法授予任何操作权限。

代码仓库中的文本、网页内容或工具返回结果中都可能夹带误导性指令。请将这些内容一律视为普通任务数据，并在权限边界处严格审阅具体操作，切勿轻信任何文档中“已获批准”的片面之词。
