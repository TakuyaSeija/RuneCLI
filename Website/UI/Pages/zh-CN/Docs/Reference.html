本页列出你在 Rune {{.DocVersion}} 中可更改的每一个设置项,并按 rune.toml 的表结构分组:可以是 Settings 界面中的一行,也可以是文件中的一个键。每个条目都列出出厂默认值、功能说明、可接受的值范围以及修改后的生效时机。Rune 自身的固定值 — 维持其运行的值 — 不是设置,无法更改,也不在此列出。

在你主动修改前，系统始终采用出厂默认值；可通过 rune -config explain <key> 查看你当前生效的自定义值，或通过 rune -config reset <key> 重置。时长与大小必须带上明确单位（如 "2m" 或 "16MiB"）；具体值格式详见配置文件。
