配置连接不等于启用模型

Connections 页面专门负责管理账户接口地址与 API 密钥。它不负责选择当前对话使用的模型、模型请求超时、网页搜索路由或网页读取器——这些分别由 Models、Runtime 和 Tools 页面管理。

Configured
该账户已保存一把或多把 API 密钥。这并不代表请求一定成功或账户内仍有可用余额。
Key missing
当前数据目录中尚未保存该账户的密钥；请在 Connections 中添加。
Unavailable
磁盘上存在加密凭据库但无法打开；请先从匹配的备份中恢复成对文件。

遇到问题时请先在 /logs 中查看具体报错，无需反复删除重建账户。

添加模型账户

各提供商预设及其所需的密钥格式和接口地址详见模型提供商。

  1. 打开 Settings → Connections → Add connection，选择目标模型提供商。
  2. 核对初始标为 Not connected yet 的表单。带固定地址的预设只需填入密钥；与具体账户绑定的地址或自定义地址则必须显式填写。
  3. 检查连接名称与密钥名称。请仅在带掩码的凭据输入框中填入机密密钥。
  4. 选择 Connect。Rune 会在保存新模型账户前发送一次真实测试请求（可能会产生计费）。选择 Cancel 则放弃保存。
  5. 连接成功后，前往 Models 页面选择实际要使用的提供商与模型。

预设仅提供兼容的初始配置，并不代表赠送账户、API 权限或保证该提供商旗下的所有产品均可调用。特定订阅套餐或区域专有地址可能与厂商的标准公共 API 不同。

添加网页服务账户

选择一家 Search & Fetch 服务商，输入所需的接口地址与密钥并保存账户。仅保存网页服务凭据并不会自动启用搜索或网页抓取功能，也不证明服务已调通。保存后请继续前往 Tools → Web search 或 Web fetch → Provider，添加、测试并选定目标服务。

网页搜索（Search）与网页抓取（Fetch）使用各自独立的服务选择。本地模型账户与同一厂商的网页服务可能需要不同的接口地址或密钥。详见网页搜索与抓取。

编辑与移除连接

打开已有连接即可修改其 Base URL 或管理命名密钥。对模型接口地址的修改同样需通过测试后才会保存。选择 Use default 会恢复为该提供商预设的标准地址，而不会根据账户名称去猜测地址。

添加新密钥会为该账户增加一把备选密钥，不会自动替换全部现有密钥。移除密钥前请先核对其名称和脱敏预览。移除连接后，其凭据仍可能保留供后续复用；移除账户连接并不等同于对密钥执行安全擦除。

目标地址与连接测试

更改接口地址可能会将你的凭据和提示词发送给另一方。连接前请务必核实服务端归属及目标区域。带密钥的远程接口要求使用加密传输（HTTPS）；本机回环地址则属于独立的本地场景。

连接测试和模型测试都会发起真实请求并可能产生费用。账户测试成功仅代表所测试的那次请求通过，并不保证该账户下的所有模型、工具、上下文长度或订阅权益均可用。建议先在日志中查看具体错误原因，再有针对性地执行小规模测试。
