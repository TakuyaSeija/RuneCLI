对话记录区

用户消息、模型回答和工具执行步骤共同呈现在同一个对话流中。每个工具步骤都会标明操作名称并展示执行结果。失败、被拒绝或未执行的调用不属于已完成的操作；请仔细阅读提示信息，不要仅凭界面上出现了方框就认为执行成功。

较长的用户消息和工具输出结果会在视觉上自动折叠。点按底部的 “lines cut. Click to open all” 提示即可展开已显示的完整结果。注意这与工具输出截断上限不同：展开视觉折叠无法找回从未返回给前端的文本。若有未返回的剩余文本，系统会通过已保存输出提示告知智能体去何处读取。

折叠状态的命令框会在单行内展示命令内容（无论是在流式生成、正在运行还是执行结束后）。较长脚本中的每个换行符在此显示为 ↵，超出宽度的部分则以 … 标记；这两者仅作界面展示之用，绝不会混入实际执行的命令中。命令输出默认最多展示 4 行，底部会注明隐藏的命令行数与输出行数。点击命令框即可展开完整的多行原始命令及全部输出。

点击对话中的链接会打开 REFERENCE（链接详情）面板并展示完整目标地址。对于网页链接，选择 Open in browser 或按 Enter 会调用系统浏览器打开，选择 Copy complete destination 或按 C 会复制完整地址，按 Esc 关闭面板。对于本地文件路径，仅支持复制路径：Rune 绝不会通过点击链接直接打开或运行本地文件。

底部输入框（Composer）

底部的输入框用于编写下一条消息，边框上会显示当前选定的模型、适用的推理强度选项以及当前权限模式。按 Enter 发送消息，按 Alt+Enter 插入换行。多行输入随内容增高时设有高度上限，以确保上方始终留有可见的对话区域。

输入 / 可打开斜杠命令面板，并支持按命令名或描述筛选。当命令面板打开时，按 Tab 可补全命令；在表单和命令面板之外，按 Tab 则会循环切换权限模式。由于你的终端模拟器可能会拦截部分组合键，若某个快捷键未生效，请运行 /help 查阅。

以 ! 开头输入内容会将其切换为你亲自执行的手动命令模式，此时输入框标题会显示 Shell · full access once。使用前请先阅读手动命令。

侧边栏

Sessions（会话统计）
显示会话标题、开始时间、活动时长与步数、上下文占用、输入/输出/缓存 token 用量及费用。未知的上限或未知的价格会如实保持未知状态，而不会当成 0 计算。
Plan（任务计划）
由智能体记录的任务清单，分为待办（todo）、进行中（doing）和已完成（done）三种状态。任务状态代表智能体自身的进度汇报，并非任务结果正确的独立证明。
Files changed（已修改文件）
列出当前会话跟踪的已修改文件及其相比初始状态的新增、删除行数。行数统计基于文件的实际内容差异，而非简单累加每次编辑步骤的数字。

按 Ctrl+O 或输入 /panel 可显示或隐藏侧边栏。当终端窗口过窄时，侧边栏会自动隐藏。隐藏侧边栏不会停止计费统计或丢失任何记录。按 Ctrl+T 可直接打开任务计划视图。

提问与权限确认

权限确认卡片用于询问某项拟议操作是否允许执行；提问表单则用于请你做出决策或补充缺失的需求信息。这两者在确认前都还不算已完成的工具结果。请先阅读作用范围，选定选项并确认。当界面提供“记住此次批准”选项时，它仅对该选项明确标出的范围生效。

内容较长的卡片配有独立的滚动阅读区，并将回答按钮固定在底部。滚动卡片内容本身不会提交回答，等待超时也不会自动变成批准。权限确认的默认等待时间为 10 分钟；向用户发起的提问默认不会超时（除非另有配置）。

状态栏与阅读导航

底部状态栏会明确区分正在工作、等待你确认、正在重试和正在压缩上下文等状态。发送消息后输入框变空，并不证明上游提供商已经收到请求。排查响应延迟时，请结合状态栏提示与 /logs 一并查看。

临时状态提示默认停留 8 秒；若后续有新提示或重试倒计时排队，当前提示会在 3 秒后让位（重试倒计时在此期间继续计时）。Esc 和 Ctrl+C 的二次确认提示始终优先显示在最上层：3 秒内再次按 Esc 可停止 AI 任务，4 秒内再次按 Ctrl+C 可退出程序。

向上滚动离开最新消息后，界面会保持你的当前阅读位置不变。按 Ctrl+↓ 可直接跳回最新对话底部。设置、日志、上下文和还原视图各自拥有独立的导航焦点；在空闲状态下按 Esc 即可退出当前视图。
