收集最小的有效排查信息

记录 rune -version 的输出、准确的报错信息、底部状态栏提示、受影响的命令或设置项，以及问题是仅出现在单个会话还是所有会话中。查看对应的 /logs 条目，并使用 explain 检查相关配置键。对外分享前请先隐去私有项目内容。

rune -version
rune -config check
rune -config explain network.stream_idle_timeout

以上命令用于检查版本号与本地配置。注意：配置文件语法有效并不代表提供商网络连接一定畅通。运行 -doctor、提供商连接测试和模型测试则会发起真实的网络请求。

安装问题

rune: command not found
安装脚本在结束时会输出实际使用的安装目录。你可以使用完整路径直接运行 rune，或按照安装与更新中的说明将该目录添加到 PATH，然后打开一个新终端。
No build for your system
当前版本没有针对该操作系统、处理器架构或 C 标准库发布已签名的构建包。首页各安装命令下方的说明列出了当前提供的构建包。此时脚本未对系统做任何安装改动。
SIGNATURE CHECK FAILED 或 CHECKSUM MISMATCH
下载到的文件并非官方发布的原版文件。脚本未执行任何安装；请勿使用这些文件。请稍后在可信网络环境下重试，若问题持续出现请向官方反馈。
Run as your normal user
在 Linux 和 macOS 上，由于程序安装在你个人的主目录下，安装脚本会拒绝以 root 身份运行。请打开普通用户终端重新运行。在 Windows 上同样无需管理员 PowerShell，程序会直接安装到当前窗口所属账户的用户目录中。
程序无法在当前系统上运行
操作系统版本低于 Rune 支持的最低要求，或处理器架构不匹配。受支持的版本范围详见平台支持。

快捷键、鼠标、颜色与复制问题

按下快捷键毫无反应，通常是因为该组合键被终端模拟器自身拦截占用了。例如 Konsole 默认将 Ctrl+滚轮用于画面缩放，部分终端会将 Alt+滚轮用于横向滚动；运行 /help 可查看 Rune 实际支持的按键列表。如果文字颜色在浅色或深色背景下显得异常，通常是因为终端未上报自身背景色：请将环境变量 RUNE_THEME 设为 dark、light 或具体的十六进制颜色值。

在 Linux 上，复制操作需要通过终端模拟器写入剪贴板；当通过 SSH 连接或运行在 tmux 内时，该权限往往默认关闭。请在终端或 tmux 中开启它（例如在 tmux 中执行 set -g set-clipboard on），或者按住 Shift 键拖选以使用终端原生的文本选择功能。

在 Auto 模式下命令仍不断请求确认

Auto 模式只有在命令能够被沙盒严格隔离时才会免询问自动执行。如果当前系统不提供沙盒支持（例如旧版本 Linux 内核），每条命令都会先向你询问；运行 /help 可在 This machine 小节下查看沙盒是否已激活。在未配置专用沙盒账户的 Windows 系统上，Git Bash 及其他基于 MSYS2 或 Cygwin 的程序在每次执行命令前都会先询问；运行 rune -sandbox 可查看专用账户未生效的原因，运行 rune -sandbox setup 即可完成配置。此外，试图连接本机已在运行的外部程序（如容器引擎或密钥代理）的命令也会触发询问，这属于独立的权限确认。

后台命令看似卡住不动

在停止或向后台命令发送输入前，请先阅读该命令的状态报告和日志。在 Linux 上，Rune 能感知命令何时正在等待键盘输入；macOS 仅上报不回显输入（如密码提示）；而 Windows 则完全不上报输入等待状态，因此在这些系统上，安静无输出的命令既可能是在等待输入，也可能仍在正常处理中。切勿仅仅因为命令没有声音就盲目猜测密码或发送确认回车。关闭所有 Rune 窗口并经过分离会话保留期（默认 60 秒）后，后台命令会自动终止。

模型报错提示上下文过大

Rune 会根据提供商上报的 token 用量，或在提供商因请求过大拒绝请求后，自动压缩较早的对话历史。如果已没有更早的历史片段可供安全压缩，系统会直接展示提供商返回的错误，而不会重复发送同一请求。请在 Models → Alt+C 中核对模型的上下文窗口大小，针对无关的新任务使用 /new 开启新会话，或手动运行 /compact。如果小型摘要模型因批次过大拒绝压缩请求，可适当调小 compact.max_batch_size。

密钥显示不可用（Unavailable）

Key missing（缺少密钥）代表当前数据文件夹中没有该账户的密钥，前往 Connections 添加即可。Unavailable（不可用）代表加密凭据库已存在但无法打开（例如对应的密钥材料文件丢失，或与另一个备份的凭据库混用）。请优先从备份中恢复匹配的成对文件。选择新建凭据存储（Start a new credential store）会将旧文件搁置一旁并要求重新添加所有密钥——这是最后手段，绝非日常测试方法。各状态的详细说明见凭据加密。

消息看似一直在等待

请结合状态栏区分以下几种情况：排队等待的输入、尚未回答的权限确认或提问表单、已发出请求但尚无流式数据返回的生成过程、重试等待倒计时，以及正在压缩上下文（Compacting）。仅凭输入框变空无法判断当前处于哪种状态。请避免反复发送“继续（Continue）”消息来试探状态，这反而会排入更多待处理的任务。

持续缓慢输出的流与完全无数据的停滞流不是一回事。修改超时配置前请先核对实际触发的是哪一个超时项。前台命令转入后台并不代表命令失败或被终止，请以任务报告显示的状态为准。

账户或模型调用失败

请先核对当前选定的提供商/模型组合以及接口地址。Key missing、Unavailable 和 Resting（冷却中）是三种不同的凭据状态。模型出现在目录列表中并不证明你的账户有权调用它，模型 ID 中包含某个字眼也不证明该路由一定支持某种推理模式。

自动重试无法修复无效的密钥或不受支持的参数控制项。请先查看具体的错误分类，切勿在未查明原因前盲目重置凭据库、切换提供商或反复发送会产生计费的测试请求。

输出结果或搜索结果不完整

请区分 4 行界面视觉折叠、返回文本字符上限、达到扫描上限而停止的搜索，以及模型上下文溢出。可先点开视觉折叠，阅读是否有已保存输出提示或继续读取提示，并缩小读取的行范围或搜索目录范围。未完成的搜索并不代表其余文件中不存在匹配项。

上下文窗口大小不等于单次最大回复长度。人为调大本地显示的能力数值无法突破提供商服务端的真实上限；而把最大输出调得过小，则可能导致模型在完成思考后没有剩余配额输出最终回答。

分类器策略或网页工具状态异常

分类器开关显示为 Enabled（已启用）并不代表当前处于 Active（正在生效）状态：请检查当前权限模式、是否存在有效的策略文件、工具排除列表，以及是否需要在空闲状态下执行重新加载（reload）。策略审查失败绝不会变成自动批准。当显式指定的网页服务商缺失时，网页工具会报告不可用，而不会静默改用其他第三方服务。

网页搜索（Search）与网页抓取（Fetch）使用各自独立的服务选择。在 Connections 中保存网页服务账户并不会自动选定工具使用的服务商，需前往 Tools 页面完成选择。

版本更新之后

在 Linux 和 macOS 上，已打开的兼容会话可在空闲时自动无缝切换到新安装的构建版本，无需强制重启。在 Windows 上，已打开的窗口会继续运行启动时的旧版本，新打开的 Rune 窗口则会使用新版本。偶发的单次恢复失败并不代表应该把整个会话删掉。

如果 Rune 提示数据目录无法完成升级更新，请先解决提示中指出的前置问题（如磁盘空间不足或目录无写入权限）后再试。如果报告某一项保持未改动，请勿假设其他所有项目也都失败了。切勿在未查明原因的情况下，把删除活动运行时文件、关闭策略审查、切换到 Full 模式或清空整个存储目录当成万能解法。
