RuneAgent 是什么

RuneAgent 是直接运行在终端里的编程智能体。你只需描述期望的结果，模型便会提出行动方案，由 RuneAgent 在同一段对话中读取文件、调用工具并展示执行结果。它使用你自行接入的模型账户工作，既不捆绑内置订阅，也不依赖 Atoryn 提供的模型。

程序本体与会话数据都保存在你自己的电脑上。但这并不意味着每次任务都在完全离线的状态下运行：你所选的模型提供商仍会收到完成请求所需的提示词、上下文及受支持的附件；终端命令和接入的外部服务同样可能使用网络。处理敏感资料前，请先阅读隐私与数据。

在项目中启动

使用首页上的命令安装 RuneAgent；具体步骤说明详见安装与更新。随后打开你准备让 RuneAgent 协助处理的项目文件夹。建议从一个已纳入版本控制的小型项目开始，并在启动前先检查项目中已有的未提交改动。

cd path/to/your-workspace
rune

你也可以直接传入目录路径启动：rune path/to/your-workspace。启动时的工作目录决定了文件访问、会话归属和项目引导说明的工作区边界。如果直接在整个用户主目录（home）下启动，所授予的工作区范围将远大于在单个代码仓库下启动。

接入并选择模型

  1. 按 Ctrl+G 并打开 Connections → Add connection。
  2. 选择目标模型提供商。核对服务地址，填入所需的自定义地址，并在带掩码的 API 密钥字段中输入密钥。建立连接时会发送一次真实测试请求，可能会产生计费。
  3. 打开 Models，选择刚刚接入的提供商，并按 Enter 选定一个具体模型。仅在列表中浏览或搜索不会切换当前会话的模型。
  4. 发送任务前，请先看一眼底部输入框旁的模型名称和权限模式。

提供商预设仅提供连接参数模板，不等同于赠送账户权限。实际可用的模型取决于你的账户权益、接口端点和模型目录。详见模型提供商、连接管理与模型与能力。

下达一个边界清晰的任务

建议从默认的 Ask 模式开始。在此模式下，工作区内的文件读取可直接进行，而每次编辑文件和运行命令都会先请求你批准。一条清晰的提示词应当指明期望结果、限制条件以及验证方式：

排查为什么导入器会放行空白日期。说明原因，补充一个回归测试，并在运行任何命令前先向我展示拟议的修复方案。

在每张权限确认卡片上，请仔细阅读实际将要执行的命令、文件路径或代码差异。每次批准仅对其写明的作用范围生效，并非对后续所有操作的空白支票。连按两次 Esc 可随时停止正在运行的 AI 任务。在智能体工作期间，你也可以随时发送补充说明；系统会在后续步骤中按顺序处理，而不会撤回已经在途的网络请求。

审阅执行结果

阅读最终报告和各步工具输出，检查被修改的文件，并亲自验证运行结果。模型有时可能会误解任务意图，或者声称完成了超出测试实际覆盖范围的工作。侧边栏会如实展示当前跟踪的文件差异，而 /logs 和 /context 则有助于排查报错和检查上下文。

/undo 可将符合条件的文件恢复到本次会话修改前的初始状态。但它无法逆转已发布的远程部署、已发送给外部服务的消息或所有外部副作用。请将它视为本地文件还原工具，而非 Git 或常规备份的替代品。
