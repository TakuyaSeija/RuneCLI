当前会话的生成控制

Settings → Generation 用于调整当前活动会话与模型的生成参数。清空可选值会将控制权交还给提供商或初始默认值。rune.toml 中的全局初始值与现有会话的选择相互独立。当前模型不支持的控制项可能不会显示。

推理与强度

可在 Generation 页面、通过 /thinking 命令或按 Alt+T 从当前模型提供的推理级别中进行选择。Models → Alt+C 则用于配置持久化的初始推理行为及可用选项。模型列表中的 Thinking 徽标代表该模型支持推理，并不代表当前会话已开启推理。

Off（关闭）
请求禁用推理。但这并不能保证上游提供商或路由节点完全不执行思考过程。
On / effort（开启 / 强度级别）
启用受支持的推理或选择具体的推理强度级别。调高强度可能会增加延迟与 token 消耗，但并不保证回答质量一定更好。
Route default（路由默认）
在提供该选项的路由上，将推理控制权交由路由决定。它既不等同于 Off，也不代表固定某一个正向推理级别。

在 9router 上,Off 不发送任何级别,因此路由保留自身默认值;只有在开启思考时选定级别才会覆盖它。

以文本形式展示的思考过程按词数（words）统计；若上游路由直接上报了思考 token 数，界面则会改为显示上报的 token 数。Rune 不会自行捏造 token 估算值。未显示思考过程并不证明推理已被关闭：部分接口本身不会返回思考文本。

采样参数

控制项作用与常见范围
Temperature（温度）控制随机性，常见范围为 0–2。调低温度并不保证每次回答都完全一致。
Top P核采样阈值，常见范围为 0.01–1。通常建议在它与温度之间二选一调整，而非同时修改两者。
Frequency penalty（频率惩罚）抑制重复出现的 token，常见范围为 −2–2；负值反而会鼓励重复。
Presence penalty（存在惩罚）抑制在同一话题上反复停留，常见范围为 −2–2。

实际可接受的参数范围取决于具体模型与接口端点。开启推理时，部分采样控制项可能会暂时不可用。过高的惩罚值或过高的随机性都可能导致输出结果质量下降。

输出上限与停止序列

Max output（最大输出）是在模型已知上限内设置的正整数回复 token 上限。在生成最终回答前，推理过程可能会先消耗其中一部分配额。配额过小可能导致回答截断；配额过大则可能允许单次请求产生更高费用。留空该值并不代表允许无限长度输出。

最多可设置 4 个停止字符串（stop sequences）来提前终止生成。会话内编辑器接收以英文逗号分隔的条目；而在 TOML 数组中则可原样保留包含英文逗号的精确字符串。如果停止字符串恰好匹配了普通代码片段，可能会导致回答意外中断。

/set temperature=0.2
/set temperature=

第一条命令为当前会话设置温度偏好；第二条命令清空该可选设置。Generation 页面下方的辅助模型控制项属于全局设置，详见下一篇文档。
