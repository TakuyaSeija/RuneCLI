对话与全局快捷键

Enter · Alt+Enter
发送消息，或插入换行符。带修饰键的回车组合取决于终端模拟器实际转发的按键事件。
Ctrl+G · Ctrl+O
打开设置（Settings），或切换侧边栏显示。
Ctrl+T · Ctrl+R
打开任务计划，或展开/收起工具步骤与思考过程。在会话选择器中按 Ctrl+R 则会打开重命名输入框。
Alt+T
循环切换当前所选模型支持的推理强度选项。
Tab
补全斜杠命令，或循环切换权限模式。在表单内则保持常规的焦点切换功能。
连按两次 Esc
停止正在运行的 AI 任务：第一次按下显示确认提示，3 秒内按第二次即停止任务。在空闲子视图中按一次 Esc 即可关闭视图。
连按两次 Ctrl+C
退出 Rune。第一次按下进入待退出确认状态，不会取消正在运行的对话轮次，也不会清空输入框草稿。
Ctrl+L · Ctrl+↓
重绘屏幕画面，或跳至最新消息底部。

文本编辑快捷键

以下快捷键在底部输入框、可编辑回答框、Settings 输入字段、模型搜索框、MCP 字段及会话搜索/重命名框中通用。列表与按钮使用各自的导航键。逻辑行（logical line）以实际插入的换行符为界；视觉行（visual row）则可能由自动折行产生。

按键功能
← / →按单个可见字符左右移动光标。
Ctrl+← / Ctrl+→移至前一个以空白分隔的词首 / 下一个词的词尾。
↑ / ↓按视觉行上下移动，并保持目标列位置。
Ctrl+A / Ctrl+E移至当前逻辑行的行首 / 行尾。
Home / End移至整个输入内容的开头 / 结尾。
Backspace / Delete删除光标前 / 后的可见字符，或删除当前选区。
Ctrl+U / Ctrl+K向前 / 向后剪切至当前逻辑行边界。在换行符处按 Ctrl+K 仅删除该换行符；在全文末尾则不执行操作。
Ctrl+W / Alt+D剪切光标左侧 / 右侧以空白分隔的词（包含该方向上相邻的空白字符）。
Ctrl+Y / Alt+Y粘贴最近一次剪切的文本 / 紧接在粘贴后循环切换更早剪切的文本。
Ctrl+_ / Alt+R撤销 / 重做当前输入框内的文本编辑。
Shift+←/→/↑/↓按字符或视觉行扩展文本选区。
Ctrl+Shift+← / →按词扩展文本选区。
Alt+X / Alt+W交换相邻的两个字符 / 相邻的两个词。
Alt+U / Alt+L / Alt+V将光标后的词或当前选区转为全大写 / 全小写 / 首字母大写。

直接输入、粘贴或按删除键会替换当前选中的文本。临时撤销记录和剪切环仅属于当前输入框，容量有限，且在切换字段或切换会话时清空，不能当作文件备份。Rune 并未实现完整的 Readline 快捷键别名集（例如 Ctrl+B/F 和 Alt+B/F 不作为移动光标的替代快捷键）。

输入历史与滚动阅读

在底部输入框中，上下方向键会先在可见的多行文本间移动，到达首行或末行后再继续按则会调出历史提示词。PgUp / PgDn 可直接翻阅历史提示词。输入历史按会话独立保存。

鼠标滚轮每滚动一格默认移动 2 行（可在配置中调整）。当终端转发组合滚轮事件时，Ctrl+滚轮或 Alt+滚轮的滚动距离为普通滚轮的 3 倍。部分终端会将这些组合手势保留为字体缩放或横向滚动；此时普通滚轮和键盘翻页键仍可正常使用。

鼠标操作

单击可放置文本光标或触发控件。按住鼠标左键拖选文本后松开即可自动复制：文本写入剪贴板后，高亮选区随即消失。在对话记录区拖选只会复制该面板内的正文，不会混入侧边栏内容或 Rune 的方框边框，表格则会复制为以制表符（Tab）分隔的单元格。复制折叠状态的命令框会还原其原始换行符，不会带入 ↵ 和 … 等显示标记。在输入框内拖选会直接复制文本，而不会移动输入光标或覆盖草稿；若要选中文本进行编辑替换，请使用 Shift 配合方向键。带掩码的密钥输入框绝不允许复制。

自动复制依赖终端模拟器允许程序写入系统剪贴板；通过 SSH 连接或运行在多路复用器（如 tmux、screen）内时，该权限可能默认关闭。在支持 Shift+拖拽的终端上，按住 Shift 拖选会调用终端原生选区（会包含界面边框）。若将配置项设为 ui.mouse = false，则所有鼠标选区均交由终端自身处理。

点击链接会打开 REFERENCE 面板：按 Enter 在浏览器中打开网页地址，按 C 复制完整地址，按 Esc 关闭面板。在链接文字上按住鼠标拖选只会复制文本，绝不会触发打开链接。

列表与表单导航

使用方向键选择条目，按 Enter 打开或确认。按 Tab / Shift+Tab 切换焦点。按 Esc 取消编辑或返回上一级。在 Models 页面中，按 Ctrl+F 聚焦搜索框，按 Alt+C 打开模型能力配置，按 T 发送真实请求测试模型，按 Delete 移除所选模型的本地自定义配置。

在提问表单中，按 Alt+Left/Right 可在不同问题间切换；普通左右方向键用于编辑文本或选择按钮。翻页键（PgUp/PgDn）用于阅读超长卡片正文，不会直接提交答案。在自定义回答输入框中，上下方向键会先在文本行间移动，到达边界后才会移出输入框。鼠标拖拽只会复制文本，不会误触下方的按钮控件。

终端环境差异

快捷键只有在终端模拟器将其上报给 Rune 时才能生效。操作系统全局快捷键、终端预设配置以及传统控制字符编码都可能占用部分按键组合。背景图、模糊效果和透明度同样归终端模拟器管辖，而非由 Rune 控制。请运行 /help 查看当前已安装版本实际支持的按键说明，不要直接套用 shell 的键位映射假设。
