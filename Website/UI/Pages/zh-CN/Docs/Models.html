浏览已接入账户的模型

Models 页面列出了已配置提供商及其模型目录返回的可用模型，以及你手动添加的精确模型 ID。搜索框用于筛选当前列表，而非跨全网所有厂商搜索。模型是否可用取决于你的账户权益、接口地址、权限以及本地目录的刷新时间。

可在左侧选择特定提供商或选择 All providers（全部提供商）。仅在列表中上下浏览不会改变当前对话使用的模型。选中目标模型后按 Enter，即可应用该提供商/模型组合。按 Ctrl+F 可返回搜索框。当前正在生效的模型组合会与列表高亮选中项分开标示。

刷新目录与自定义模型 ID

选择 Refresh catalog 会发起一次网络请求，拉取该账户可用的模型 ID 及官方公布的元数据，但不会自动切换当前活动模型。选择 Enter model ID 允许你手动添加精确的模型标识符；但仅添加 ID 并不证明你的账户一定有权调用该模型。

未知的上下文窗口、输出上限和价格会如实保持未知状态。请勿仅凭模型名称中的某个词去猜测其能力，也不要为了声称上游有更大配额而人为调大本地显示数值。在列表项上按 T 会发送一次真实的模型测试请求，可能会产生费用。

使用 Alt+C 配置模型能力

按 Alt+C 可打开所选模型的持久化能力设置。模型能力（Capabilities）描述的是该模型能够接受的上限与特性；而 Generation 页面描述的则是当前会话实际请求的参数。最大输出能力上限不等同于每次请求实际要求的回复长度。

Context / output（上下文与输出上限）
记录已知的模型容量上限。在本地设置覆盖值无法突破上游服务端的真实限制。
Reasoning（推理配置）
配置会话初始推理行为及可选的推理强度列表。Thinking 徽标代表模型支持推理，并不代表当前会话已开启推理。
Media / controls（媒体与控制项）
请仅开启接口端点实际支持的能力。在启用推理期间，部分不支持的采样控制项可能会隐藏或置灰。
Pricing（价格）
填入已知的输入/输出/缓存单价，供本地费用统计使用。未知价格不代表免费（0 元），且填入缓存价格也不证明该接口一定支持提示词缓存。

默认回退与移除模型

New-session fallback（新会话回退提供商）用于为今后新建的会话指定初始提供商，不会覆盖现有的所有会话。在模型条目上按 Delete 会隐藏或移除该条目并清除其本地自定义设置，但不会删除上游服务端的模型。重新添加同名模型时会拉取最新的目录元数据，不一定保留你此前删除的自定义选项。

了解费用统计的边界

费用统计（Spend）基于已知用量且已知单价的请求进行计算。如果某次请求在执行时单价未知，而在稍后补充了模型单价，系统会随之补算其费用；已完成计价的请求则会保留当时记录的成本。受四舍五入、缓存计费规则、账户折扣或上游未完整上报用量等因素影响，提供商最终账单可能与本地统计存在差异。

本地消费提醒阈值并非强制断网硬上限。请与你的提供商核实准确单价，并使用提供商账户后台的预算控制来设置强制额度上限。若只需针对单次回答调整生成参数，请参阅生成与推理，无需修改模型的底层能力定义。
