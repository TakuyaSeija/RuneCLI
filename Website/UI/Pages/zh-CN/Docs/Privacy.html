本地运行不等于完全离线

Rune 运行在你自己的电脑上，并将设置、会话和项目数据保存在本地。使用本软件无需注册 Atoryn 账户，且软件不包含任何产品遥测（telemetry）采集。但它仍会根据你所使用的账户、模型目录、模型和工具发起必要的网络请求。

调用远程模型会将相关的请求内容发送给对应的提供商。程序在本地运行并不意味着所有代码和数据都只留在机器内部。处理敏感工作时，请先核实目标服务地址、模型配置、附加文件以及提供商自身的数据保留政策。

哪些数据可能会向外发送

主模型
你的提示词、选定的对话上下文、工具声明与执行结果，以及完成该次请求所需的受支持附件。
辅助模型
用于策略审查、指令提取、历史摘要或标题生成的相关内容片段。若为辅助任务单独配置了其他提供商，该提供商将收到这部分数据。
网页搜索与抓取服务
搜索关键词，或目标网页 URL 及特定服务所需的请求参数。内置的网页抓取器则会直接连接目标网站。
MCP 与终端命令
传递给外部工具或本地子进程的数据。这些外部程序自身的联网行为和数据留存政策不受“本地智能体”这一统称的约束。
账户测试与模型目录
认证/连接测试请求及模型列表查询请求。测试请求可能会产生计费。

切换接口端点即意味着改变数据流向。当显式绑定的网页服务不可用时，系统绝不会静默回退给另一家第三方服务商。

哪些数据保留在本地

当前选定的 Rune 主目录保存着配置文件、加密凭据、对话与项目数据、项目记忆以及符合条件的文件还原快照。在工作区中修改文件不会自动清除历史会话记录。因此，在你结束工作后，历史会话中仍可能保留着私密提示词和工具输出。

上下文压缩仅改变发送给模型的上下文内容，并非安全擦除机制。删除会话和清理存储空间是需要显式执行的维护操作。移除某个账户连接并不保证其所有凭据或历史请求元数据均已从磁盘上彻底抹除。

分享诊断信息时的注意事项

运行日志、上下文视图、请求预览（dry run）及生效配置输出中可能包含私有代码、本地路径、账户名称或任务细节。凭据脱敏机制有助于隐藏已知的密钥，但无法保证过滤掉每一处私密字符串。

对外分享前请先人工审阅，尽量只截取最小的相关片段。切勿将真实 API 密钥粘贴到聊天窗口、版本控制系统或公开的问题报告中。建议使用脱敏后的密钥元数据和最小复现步骤，而不要直接打包上传整个数据文件夹。

你手中的控制权

你可以自主选择目标工作区和权限模式、仅挂载必需的文件、审阅账户接口地址，并在需要时启用提供商后台的数据留存与预算控制。使用本地模型可以避免向远程模型披露代码，但独立的网页工具、辅助模型路由或终端命令仍可能访问外部网络。

-read-only 标志仅限制修改文件的工具，并不代表禁止读取文件或禁止网络传输。本地费用提醒阈值并非强制断网硬上限。撤销（undo）操作可以恢复本地文件，但无法撤回已经发送给外部服务的信息。
