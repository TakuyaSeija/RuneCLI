系统与环境要求

Linux
支持 x86_64 或 arm64（以各版本实际发布的已签名构建包为准）。glibc 构建版可在 glibc 2.17 及更新版本的发行版上运行（已在 CentOS 7、Debian 11/12 和 Ubuntu 24.04 上实测通过）。静态编译的 musl 构建版不依赖系统的 C 标准库（已在 Alpine 上实测通过）。
macOS
macOS 11 及以上版本，支持 Apple silicon 或 Intel 处理器。macOS 支持目前处于公测阶段（beta）。
Windows
Windows 10 版本 1809 及以上，或 Windows 11，支持 x64 或 ARM64 架构。Windows 支持目前处于公测阶段（beta）。
安装脚本依赖
在 Linux 和 macOS 上需要：curl、tar、gzip 以及用于签名校验的 openssl（OpenSSL 或 macOS 自带的 LibreSSL）。在 Windows 上仅需系统自带的 PowerShell。在 Linux 和 macOS 上请以普通用户身份运行，切勿使用 root；在 Windows 上无需管理员权限。
模型账户
准备一个你自选的模型提供商账户，或在你自己电脑上运行的本地模型服务。参阅模型提供商。

当前版本为哪些系统提供了已签名构建包，均标明在首页各安装命令下方。各操作系统之间的行为差异详见平台支持。

安装

安装命令位于首页：Linux 与 macOS 使用由 sh 执行的 install.sh，Windows 使用在 PowerShell 中运行的 install.ps1。你可以先阅读脚本内容：install.sh 和 install.ps1 均以纯文本形式提供，与安装命令实际获取的内容完全一致。脚本会依次执行以下步骤，一旦任意步骤失败便会立即停止，不会对系统做任何改动：

  1. 检查操作系统及其版本、确认当前为普通用户身份，并检查所需命令行工具是否齐全。
  2. 检测处理器架构，并在 Linux 上检测 C 标准库（glibc 或 musl）。
  3. 下载该版本的校验和列表，并使用脚本内嵌的发布公钥校验数字签名。
  4. 下载适用于当前机器的归档包，并与已签名校验和列表进行比对。
  5. 检查归档包内是否仅包含程序文件及其许可证文件，并验证程序能否正常启动及报告预期版本号。
  6. 通过一次原子重命名将程序放置到位，并将许可证与第三方声明保存在用户数据目录旁。
操作系统可执行文件位置许可证声明位置
Linux, macOS~/.local/bin/rune~/.local/share/runeagent（或 $XDG_DATA_HOME/runeagent）
Windows%USERPROFILE%\.local\bin\rune.exe%LOCALAPPDATA%\RuneAgent

安装脚本绝不会修改你的 shell 配置文件或 PATH。如果安装目录不在 PATH 中,脚本会把 Rune 链接到一个已在 PATH 中的文件夹并说明这一点;若无法做到,则打印一行命令,让你当前窗口立即可以运行它。发布校验详细说明了数字签名能证明什么、不能证明什么，以及如何手动校验下载包。

安装命令通过 curl 和 PowerShell 下载文件，不会给程序打上“来自互联网”的隔离标记。但如果你通过浏览器手动下载归档包，系统会附加该标记：在 macOS 上，Gatekeeper 会因此拒绝启动该 rune 副本，请在完成归档校验后运行 xattr -d com.apple.quarantine rune 移除标记；在 Windows 上，从文件资源管理器打开此类程序时 SmartScreen 可能会弹出警告。

安装脚本选项

在不设置额外环境变量时，安装脚本默认选择最新发布的版本、安装到你的用户 bin 目录，并在 Linux 上自动检测 C 标准库。在 Linux 和 macOS 上，可将脚本保存为 install.sh，审阅后配合以下任意环境变量运行；在 Windows 上，请在运行安装命令前于同一个 PowerShell 窗口中设置环境变量。

RUNE_VERSION
指定已发布的版本号，例如 {{.DocVersion}}。可通过指定版本号安装历史版本。
RUNE_INSTALL_DIR
指定存放可执行文件的绝对路径目录，替代默认目录。
RUNE_LIBC
仅限 Linux：设为 gnu 或 musl 以手动指定构建版本，跳过自动检测。若指定的组合没有对应的已发布归档包，安装会被拒绝。
RUNE_VERSION={{.DocVersion}} sh install.sh
RUNE_INSTALL_DIR="$HOME/bin" sh install.sh
$env:RUNE_VERSION = "{{.DocVersion}}"
irm {{.Origin}}{{url "install.ps1"}} | iex

将 rune 加入 PATH

许多 Linux 发行版默认已将 ~/.local/bin 纳入 PATH（前提是你登录系统时该文件夹已存在），而 macOS 默认不包含该目录。如果提示找不到 rune，请手动将该文件夹加入 PATH。对于 bash 或 zsh（macOS 默认 shell），可将以下行添加到 ~/.bashrc 或 ~/.zshrc，然后打开一个新终端：

export PATH="$HOME/.local/bin:$PATH"

在 fish 中，只需运行一次 fish_add_path ~/.local/bin。在 Windows 上，可在 PowerShell 中运行以下命令将该目录加入当前用户的 PATH，完成后打开一个新终端：

[Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path", "User") + ";$HOME\.local\bin", "User")

如果你设置了自定义的 RUNE_INSTALL_DIR，请将上述路径替换为你自己的目录。

首次启动

在你的项目目录中打开终端并运行 rune。首次启动时，Rune 会在你的主目录下创建数据文件夹 .rune（Windows 上为 %USERPROFILE%\.rune，或由 RUNE_HOME 指定的文件夹），其中包含：

  • rune.toml：你的设置文件。它只记录你主动修改过的选项，其余所有默认值均直接取自当前运行的软件版本。
  • 经加密存储的 API 密钥。
  • 按项目分别保存的会话历史、项目记忆（memory）以及供撤销（undo）使用的文件快照。

在 Windows 上，首次启动还会请求一次管理员权限确认，用于配置 Rune 运行命令专用的独立沙盒账户。如果你选择拒绝，Rune 不会在每次启动时反复弹窗；后续想配置时可随时运行 rune -sandbox setup。安全机制说明了未配置该账户时的防护差异。

运行 rune -config 输出的第一行即为当前使用的数据文件夹路径。Rune 将自身数据统一保存在那里，不会污染你的项目目录：只有在你所选权限模式下由 AI 工具执行的修改、你手动输入的 ! 命令，或你以项目作用域（project scope）保存的技能与 MCP 配置，才会改动项目中的文件。接下来可参阅简介中的接入并选择模型。

更新

针对目标版本重新运行一次安装脚本即可（若此前设置了 RUNE_INSTALL_DIR，请保持一致）。脚本会校验下载包并一步替换程序文件；完成后可通过 rune -version 检查结果。

已经打开的 Rune 窗口可以继续正常工作。在 Linux 和 macOS 上，已打开的窗口会在进入空闲状态后自动切换到新版本构建，且新版本首次启动时会自动升级数据文件夹结构。在 Windows 上，正在运行的程序文件无法原地变身为新程序：已打开的窗口会保持启动时的旧版本，而你新打开的下一个 Rune 窗口则会使用新版本。请勿为了强制更新而关闭正在执行任务的窗口。

卸载

完成或停止手头任务并关闭所有 Rune 窗口，随后删除程序文件及其许可证声明。在 Linux 和 macOS 上运行：

rm ~/.local/bin/rune
rm -r ~/.local/share/runeagent

在 Windows 的 PowerShell 中运行：

rune -sandbox reset
Remove-Item "$HOME\.local\bin\rune.exe"
Remove-Item -Recurse "$env:LOCALAPPDATA\RuneAgent"

在 Windows 上，先运行 rune -sandbox reset 可收回 Rune 命令沙盒在你文件夹上的访问权限并移除专用沙盒账户（可能会请求管理员权限确认）。你的数据文件夹会保留在磁盘上，直到你手动删除它。其中存有你的历史记录、设置、密钥和还原点，仅卸载程序时无需删除它。如果确定要一并删除数据文件夹，请先通过 rune -config 查看其准确路径，且切勿在 Rune 仍在运行时删除它。

环境变量

RUNE_HOME
使用另一个数据文件夹替代主目录下的 .rune，拥有独立的设置、密钥和会话记录。
NO_COLOR
禁用彩色输出，效果与 --no-color 相同。
RUNE_THEME
当终端模拟器未主动上报背景色时，用它告知 Rune 你的终端背景：可设为 dark、light 或十六进制颜色值。注意它不是界面主题选项（主题选项位于 Appearance 中）。
RUNE_VERSION, RUNE_INSTALL_DIR, RUNE_LIBC
仅供安装脚本读取；详见安装脚本选项。
