使用斜杠命令

在输入框中输入 / 即可搜索命令面板。使用上下方向键选择，按 Tab 补全，按 Enter 执行。方括号 [...] 中的参数为可选项；尖括号 <...> 表示需要由你填入的具体值，请勿原样输入尖括号本身。当前已安装版本的权威命令列表以 /help 为准。

会话与上下文

/new
在当前工作区开启一段新对话。不会删除当前会话记录。
/session
打开当前工作区的可搜索会话选择器。
/resume <id>
恢复指定 ID 的已保存会话。
/compact
压缩并总结较早的上下文。此操作会发起一次模型请求并可能省略部分历史细节，但不会清除磁盘上的历史存储。
/context
查看当前提供给模型的上下文内容。对外分享前请将其视为私有工作内容妥善检查。
/logs [all|warn|error]
打开诊断事件视图，可按严重程度筛选。失败的请求与重试记录均在此展示；查看日志本身并不会自动重试请求或切换账户。

模型与权限

/model [provider:id|id]
选择提供商/模型组合；不带参数时直接打开 Models 列表。若模型 ID 在多个提供商下重名，建议在列表中按提供商明确选择。
/provider [name]
选择负责回答的提供商；不带名称时打开提供商列表。切换此项会改变后续任务发送的目标服务端。
/thinking [off|effort]
查看或从当前模型支持的选项中选择推理强度。按 Alt+T 可循环切换。设为 off 仅代表向服务端发起关闭推理的请求，并不能证明上游路由完全不进行推理。
/mode [ask|auto|full]
循环切换或显式指定当前会话的权限模式。Full 模式会授予广泛的自主执行权限，切勿仅仅为了掩盖报错而切换到 Full。
/classifier [on|off|model|reload]
查看或配置策略审查。reload 会为空闲会话重新加载策略文件；仅凭开关处于开启状态并不能证明审查正在生效。
/set key=value
修改受支持的模型或会话控制项，例如 /set temperature=0.2。清空可选值（如 /set temperature=）会将控制权交还给默认值或提供商。

文件与扩展能力

/attach path
为下一条消息添加文件附件。发送前请先审阅待发送附件；受支持的文件内容将发送给所选提供商。
/detach number|all
按序号移除单个待发送附件，或清空全部待发送附件。
/undo
预览并将符合条件的文件恢复到本次会话首次修改前的状态。注意：此操作可能会覆盖外部编辑器刚刚所做的修改。
/redo
预览并恢复最近一次撤销（undo）所替换的内容。它不是无限层级的备份历史。
/skills [list|show|enable|disable|reload]
管理可用的技能指南。show、enable 和 disable 接收列表中显示的技能 ID。编辑技能文件后可运行 reload 刷新目录。
/skill <id>
在当前对话中激活某项技能指南。激活指南并不代表自动批准该指南中提到的所有操作。
/mcp [list|add|connect|status]
管理外部工具连接。添加或连接前请先审阅服务器、目标地址与访问权限；本地 MCP 服务器可能会直接启动可执行代码。

视图与应用控制

/settings
打开设置（Settings）页面。/* 是它的简写别名，键盘快捷键为 Ctrl+G。
/theme [name]
选择 violet、cyan 或 amber 主题。终端自身的背景色与透明度仍由终端模拟器控制。
/panel
显示或隐藏对话侧边栏。在较窄的终端窗口中仍可能自动隐藏。
/verbose
展开或收起工具步骤与思考过程。此开关不会调大工具返回输出的长度上限。
/help
查阅当前构建版本的命令与键盘快捷键参考。
/quit
退出 Rune。关闭最后一个窗口会停止正在运行的 AI 任务；已保留的后台进程则有独立的生命周期。

诸如 rune -config 之类的命令行参数需要在操作系统的终端 shell 中运行，而非输入在斜杠命令面板中；详见命令行参考。若想直接从输入框手动执行一条 shell 命令，请以 ! 开头输入，详见手动命令。
