Install

One command. Verified before it lands.

The installer picks the right build for your system, checks its signature and checksum, and places a single binary in your home folder. It never asks for root.

$ {{.InstallCmd}}
{{- if not .Latest}}

Not yet available. The first public release has not been published. This page lists it the moment it is.

{{- end}}

What the installer does

  1. Detects your processor and C library, and chooses the matching build.
  2. Downloads it together with the signed checksum list, over HTTPS only.
  3. Checks the signature against the RuneAgent release key built into the installer, then the file's checksum against that list.
  4. Installs rune into ~/.local/bin in one atomic step, so a running RuneAgent switches to the new version when it is idle.

If any check fails, nothing is installed and the installer says why.

Requirements

  • Linux on x86_64. The standard build runs on any distribution from the last decade; a fully static build covers systems without glibc, such as Alpine.
  • curl, tar and OpenSSL 3, which the installer uses to check the signature.
  • An API key for the model provider you want to use, or a local model server.

macOS and Windows are in development.

Options

Set these before sh in the command above:

  • RUNE_VERSION=X.Y.Z installs a specific release instead of the newest.
  • RUNE_INSTALL_DIR=/some/dir installs somewhere other than ~/.local/bin.
curl -fsSL {{.Origin}}{{url "install.sh"}} | RUNE_VERSION=X.Y.Z sh

Update and uninstall

To update, run the install command again. To uninstall, delete the rune binary. Your sessions and settings stay in a data folder in your home directory until you remove that too.

Verify by hand

Check that the key's fingerprint matches the one published on the security page, then:

openssl pkeyutl -verify -pubin -inkey signing-key.pem -rawin \
  -in SHA256SUMS -sigfile SHA256SUMS.sig
sha256sum --check --ignore-missing SHA256SUMS

Both must succeed: the first proves the list was signed by RuneAgent's release key, the second that your file matches the list.
