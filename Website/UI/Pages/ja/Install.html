1 回のインストールで、あなたのワークスペースへ。

インストーラの内容とシステム環境を確認し、使用するモデルアカウントを接続してください。

01

システム環境の確認

インストーラはお使いの OS とプロセッサ、さらに Linux では C ライブラリ（glibc または musl）を自動判別し、その組み合わせ向けに公開・署名されたビルドのみをインストールします。{{with .Latest}}各インストールコマンドの下にある行に、リリース {{.Version}} の対応環境が表示されています。{{end}}

Linux と macOS では curl、tar、gzip、openssl が必要です（macOS には標準搭載されています）。Windows では PowerShell のみが必要です。macOS 11 以降および Windows 10 バージョン 1809 以降に対応しています（いずれもベータ対応）。Linux と macOS では root ではなく一般ユーザーで実行してください。Windows でも管理者権限は不要です。

02

インストール前の検証

上部のインストールコマンドは、プログラムを配置する前にデジタル署名とアーカイブのチェックサムを検証します。

実行前にインストーラのソースコード（install.sh または install.ps1）を確認できます。手元で確認してから実行する場合は、スクリプトを保存して内容を確認したうえで、sh install.sh（PowerShell では .\install.ps1）を実行してください。

03

プロジェクトを開く

cd path/to/your-workspace
rune

Settings → Connections でモデルアカウントを接続し、Models で使用するモデルを選択します。まずは Ask モードで開始し、各コマンドや編集内容を確認しながら進めてください。

最初のセッションの手順を見る

マシン上で変更される内容

単一のプログラム
Rune は ~/.local/bin/rune（Windows ではユーザープロファイル内の .local\bin\rune.exe）に配置されます。root や管理者権限は不要です。
シェル設定はそのまま
シェルの設定ファイルを書き換えることはありません。配置先フォルダが PATH にない場合は、PATH にあるフォルダへ Rune をリンクしてその旨を伝えるか、いま開いているウィンドウで実行できる1行を表示します。Windows ではユーザーの PATH にフォルダを追加するため、新しいウィンドウでも Rune を見つけられます。
ライセンス表記
~/.local/share/runeagent（Windows では %LOCALAPPDATA%\RuneAgent）に保存されます。
Rune のデータ
設定、セッション、暗号化されたキーは、Rune の初回起動時にホームディレクトリ内に作られるデータフォルダにまとめて保存されます。
モデルへの接続
プロバイダのアカウント、または対応するローカルエンドポイントをご用意ください。Rune に API クレジットは付属していません。

インストーラのオプション

インストーラは使用したフォルダを表示し、シェルの設定ファイルは書き換えません。いま開いているウィンドウで下の行を実行すれば、その場で rune を実行できます。新しいターミナルは不要です。今後開くターミナルでも使えるようにするには、同じ行をご自身で ~/.bashrc または ~/.zshrc に追加してください:

export PATH="$HOME/.local/bin:$PATH"

fish の場合は fish_add_path ~/.local/bin を 1 回実行してください。Windows の PowerShell 設定手順はインストールとアップデートにあり、インストーラがフォルダを追加済みなので、新しいウィンドウでも rune をすぐに使えます。

Rune のアンインストール

実行中の作業を完了または停止してすべての Rune ウィンドウを閉じてから、プログラム本体とライセンス表記ファイルを削除してください（インストール先を変更した場合は ~/.local/bin を実際のパスに置き換えます）。

rm ~/.local/bin/rune
rm -r ~/.local/share/runeagent

Windows でのコマンドサンドボックス権限の解除を含む PowerShell 手順については、インストールとアップデートをご覧ください。設定、セッション、暗号化されたキー、復元用データは、ご自身で削除しない限り Rune のデータフォルダに残ります。データフォルダの場所は rune -config の出力の 1 行目に表示されるため、プログラムを削除する前に確認してください。このフォルダを削除すると履歴と復元ポイントが失われます（通常のアンインストールでは削除不要です）。
