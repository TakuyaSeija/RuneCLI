設定画面の開き方と操作

Ctrl+G を押すか、/settings（またはエイリアスの /*）を入力します。概要画面から 6 つのセクションへ移動できます。矢印キーで行やカードを選び、Enter で開きます。Tab／Shift+Tab でフォーカスを移動し、Esc でエディタをキャンセルするか 1 段前の階層に戻ります。画面下部のフッターには選択中の項目の説明が表示されます。

値を編集したら Apply を選んで保存します。Cancel を選ぶと元の値が維持されます。一部の選択肢は左右キーで切り替えるとそのまま保存されるため、ヒント表示と保存完了メッセージを確認してください。別画面のリストで項目にカーソルを合わせただけでは、設定は適用されません。

6 つの設定セクション

Models
接続済みアカウントのモデル一覧の閲覧、プロバイダ／モデルのペアの適用、カタログの更新、および Alt+C によるモデルの機能定義・単価の永続設定を行います。
Generation
現在のセッションにおける推論、サンプリング、最大出力トークン数を設定します。同じページの下部にはグローバルな補助モデル設定があります。
Connections
アカウント接続（API アドレスと名前付きキー）を管理します。Web プロバイダの選択やモデルリクエストのタイムアウト設定はここにはありません。
Runtime
モデルリクエストのタイムアウト、再試行の挙動、クレジット残高不足時のクールダウン、および共通の接続・ストリーム待機時間を管理します。
Tools
ツールごとの待機時間と出力・処理上限、質問フォームと権限確認の制限時間、および Web 検索・取得プロバイダの選択を行います。
Appearance
カラーテーマと会話サイドパネルの表示設定を行います（ターミナル自体の壁紙、ぼかし、透過の設定ではありません）。

グローバル設定とセッション設定の違い

ツールの上限、再試行・ネットワーク設定、および補助モデルの設定は、選択中の Rune ホーム全体に対するグローバル設定です。一方、Generation のメイン項目とモデル選択は、現在のアクティブなセッション／モデルに適用されます（モデルごとに保存した設定は、次回そのモデルに戻った際に再利用されます）。

グローバルな [generation] テーブルは開始時の初期値を提供するものであり、既存のすべてのセッションの設定を上書きするものではありません。また、New-session fallback は今後新しく開始するセッションの初期プロバイダを選ぶものであり、現在開いているすべての会話を切り替えるものではありません。

リセットと反映タイミング

Use default を選ぶと保存済みのグローバルな上書き設定が削除され、現在の既定値または継承動作に戻ります。初期値と同じ数値を手動で保存した場合は「明示的な選択」として記録され、未設定状態とは区別されます。セッションごとの任意指定の Generation 項目では、入力欄を空にするとプロバイダまたは既定値の動作に戻ります。

設定の変更は通常、Rune を再起動することなく反映されます。即座に反映される項目と、実行中の処理は開始時の設定を維持したまま次の操作から新しい値を使う項目があります。各キーの正確な挙動は rune -config explain <key> で確認してください。なお、分類器（Classifier）のポリシーは待機中に明示的な再読み込みが必要です。

変更前の確認

設定ファイルの構文が正しくても接続が機能するとは限らず、また Configured と表示されていてもクレジット残高があるとは限りません。接続テストは実際のリクエストを送信するためコストが発生する場合があります。プロバイダを変更するとデータの送信先が変わり、再試行回数や出力上限を増やすと消費額が増える可能性があります。

すべての詳細設定に UI 上の行があるわけではありません。存在しない設定項目を推測したり無関係な設定を書き換えたりせず、詳細設定を確認・リセットする方法については設定ファイルをご覧ください。
