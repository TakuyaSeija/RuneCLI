Rune {{.DocVersion}} が rune.toml から読み取るすべての設定項目を、設定ファイル内のグループ順に記載しています。各項目には、既定値（初期値）、機能の説明、指定可能な値、および変更が反映されるタイミングを示しています。ほとんどの項目は Settings 画面に対応する行があり、その他の項目は rune -config set で変更できます。

既定値は、ご自身で変更しない限り適用される初期値です。現在有効な値は rune -config explain <key> で確認でき、rune -config reset <key> で上書き設定を解除できます。時間やサイズには "2m" や "16MiB" のように単位が必要です（値の書式については設定ファイルをご覧ください）。

ターミナル（Terminal）

詳しくはターミナルとバックグラウンド処理を参照してください。

terminal.command_timeout

フォアグラウンドコマンドをバックグラウンドへ移行するまでの待機時間です（移行後もコマンドは実行を続けます）。

既定値 "120s"指定可能な値 1s〜24h の時間（強制終了期限ではなくフォアグラウンド待機時間）反映タイミング 次の操作（ターン／リクエスト）から適用（実行中の処理は開始時の設定で完了）

terminal.shell

コマンド実行用のシェルです。auto（このマシンに bash があれば bash、なければ /bin/sh。Windows では PowerShell 7、なければ Windows PowerShell、なければ cmd）または実行ファイルの絶対パスを指定します。各シェルにはそれぞれの方式（POSIX シェルは -c、PowerShell はエンコード済みスクリプト、cmd は /C）でコマンドが渡されます。

既定値 "auto"指定可能な値 auto、またはインストール済みシェル実行ファイルの絶対パス反映タイミング 即時 — 再起動なしで次の読み取りから適用

terminal.term

ツールプロセスに渡される TERM 環境変数の値です。

既定値 "xterm-256color"指定可能な値 空でない有効な文字列反映タイミング 即時 — 再起動なしで次の読み取りから適用

terminal.inherit_environment

開発用の許可リストではなく、すべての環境変数を引き継ぎます。

既定値 false指定可能な値 true / false反映タイミング 即時 — 再起動なしで次の読み取りから適用

terminal.flush_interval

リアルタイム出力のフラッシュ間隔です。

既定値 "150ms"指定可能な値 最大 24h までの正の時間反映タイミング 即時 — 再起動なしで次の読み取りから適用

terminal.input_wait_delay

コマンドの出力が途絶えてから、キー入力待ちでブロックされているかを Rune がシステムに問い合わせるまでの時間です（検知可能なプラットフォームで、無出力状態につき 1 回確認されます）。

既定値 "2s"指定可能な値 最大 24h までの正の時間反映タイミング 即時 — 再起動なしで次の読み取りから適用
