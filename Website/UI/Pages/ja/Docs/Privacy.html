ローカル実行はオフラインを意味しない

Rune はお使いの PC 上で動作し、設定、セッション、プロジェクトデータをローカルに保持します。Atoryn のアカウントは不要で、製品のテレメトリ収集も行いません。ただし、あなたが使用するアカウント、カタログ、モデル、およびツールが必要とするネットワーク通信は実行されます。

リモートモデルを使用すると、リクエストに必要な内容がそのプロバイダへ送信されます。プログラムがローカルで動いているからといって、すべてのコードがマシン外に出ないわけではありません。機密性の高い作業を行う際は、送信先、モデル設定、添付ファイル、およびプロバイダ側のデータ保持ポリシーを必ず確認してください。

外部へ送信され得るデータ

メインモデル
入力したプロンプト、選択された会話コンテキスト、ツールの定義と実行結果、およびリクエストに必要な対応添付ファイル。
補助モデル
ポリシー審査、指示の抽出、履歴の要約、タイトル生成に必要な関連テキスト。別のプロバイダを補助モデルに設定している場合は、そのプロバイダへ該当データが送信されます。
Web 検索とページ取得サービス
検索クエリ、または対象ページのアドレスとサービス固有のリクエスト。組み込みのページリーダーを使用する場合は、対象の Web サイトへ直接接続します。
MCP とシェルコマンド
外部ツールやプログラムに渡されたデータ。それらのツール自身の通信動作やデータ保持は、「ローカルエージェント」という枠組みだけでは制限されません。
アカウントテストとカタログ取得
認証・疎通テスト用のリクエストと、モデル情報取得リクエスト（テストには課金が発生する場合があります）。

接続先エンドポイントの選択は、データの送信経路の決定そのものです。明示的にピン留めした Web プロバイダが利用できない場合でも、勝手に別のサードパーティサービスへフォールバックすることはありません。

ローカルに保存されるデータ

選択中の Rune ホームには、設定、暗号化された認証情報、会話およびプロジェクトデータ、メモリ、復元用のファイルスナップショットが保存されます。作業フォルダを切り替えても過去の履歴は消えないため、作業終了後も非公開のプロンプトやツール出力がセッション内に残ります。

コンパクションはモデルに渡すコンテキストを要約するだけであり、データの完全消去機能ではありません。セッションの削除やストレージの整理（prune）は明示的なメンテナンス操作として実行してください。また、接続設定の削除は、関連するすべての認証情報や過去のリクエストメタデータの完全消去を保証するものではありません。

診断情報を共有する際の注意

ログ、コンテキスト表示、リクエストのドライラン、および有効な設定の出力には、非公開のコード、ファイルパス、アカウント名、作業内容が含まれている場合があります。既知のシークレットに対する伏せ字処理は行われますが、あらゆる非公開文字列の除去を保証するものではありません。

外部に共有する際は、内容を自分で確認したうえで必要な最小限の抜粋のみを共有してください。実際の API キーをチャット、バージョン管理、公開バグレポートに貼り付けないでください。データフォルダ全体をそのまま渡すのではなく、マスクされたキー情報と最小限の再現手順を使用してください。

あなた自身で行える管理

適切なワークスペースと権限モードを選び、必要なファイルのみを添付し、アカウントの接続先を確認し、必要に応じてプロバイダ側のデータ保持設定や予算上限機能を活用してください。ローカルモデルを使えばリモートモデルへのデータ送信は減らせますが、個別の Web ツール、補助モデル経路、またはコマンド実行が外部サービスと通信する可能性は残ります。

-read-only は変更系ツールを制限するものであり、ファイルの読み取りやネットワーク送信を禁止するものではありません。利用額の警告（Spending warning）は強制的な停止上限ではありません。また、/undo は対象のローカルファイルを復元しますが、すでに外部へ送信された情報を取り消すことはできません。
