スキルは手順ガイド

スキル（Skill）は、特定のタスク向けの再利用可能な手順書と参考資料をまとめたパッケージです。実行権限を付与する仕組みではありません。エージェントが関連するスキルを見つけて SKILL.md を読み取るか、あなたが会話内で明示的にスキルを有効化して使用します。第三者が作成したガイドやスクリプトは、従う前に必ず内容を確認してください。

スキルの確認と使用

/skills list
利用可能なスキルガイドとその正確な ID を一覧表示します。
/skills show <id>
指定したガイドの詳細情報を表示します。
/skill <id>
現在の会話で指定したガイドを有効化します。ガイド内のテキストが無関係なアクションを承認したり、実行チェックを無効化したりすることはありません。
/skills enable|disable <id>
現在のプロジェクトにおけるスキルの有効・無効を切り替えます（すべてのユーザーやプロジェクトからアンインストールするものではありません）。
/skills reload
編集後にスキルカタログを再読み込みします。変更されたガイドを使用する際は、改めて内容を確認してください。

保存場所とインストール

プロジェクト用のスキルは .rune/skills/<name>/SKILL.md（ポータブル形式では .agents/skills/）に配置されます。個人用のスキルは選択中の Rune ホーム内の skills フォルダ（有効な場合はポータブルな個人用フォルダも対象）に配置されます。

rune -skills install <folder-or-zip> は、確認済みのパッケージを現在のプロジェクトの .rune/skills/ にインストールします。これにより他のプロジェクトと混ざらず、リポジトリを含めそのプロジェクトのファイルを使う全員で共有できます。すべてのプロジェクトで使える個人用ガイドにするには --scope user を追加します。rune -skills update <folder-or-zip> は同じ方法で選んだスコープのインストール済みスキルを置き換えます（前のバージョンの控えは残らないため、元のファイルを保管するかバージョン管理を使用してください）。各パッケージは英小文字の名前と一致するフォルダ名、name と description メタデータを含む SKILL.md、および任意の相対パス参照ファイルで構成されます。ダウンロードしたテキストを無条件に信用せず、内容を確認したうえでインストール・更新を行ってください。

AI に渡されるスキルカタログ

AI には最初からすべてのスキルの全文が渡されるわけではありません。利用可能なスキルの名前と 1 行の説明を並べた短いカタログだけが渡され、AI は必要になった時点で初めて該当ガイドの全文を読み取ります。このカタログのサイズ上限は初期設定で 8 KiB（skills.max_catalog_size）です。上限に収まらなかったスキルも検索（discover）可能な状態で残るため、AI は必要に応じて見つけて読み取ることができます。この上限はトークン数ではなくバイト単位であり、capabilities.catalog_bytes を保存している場合はそちらが優先されます。

上限を変更するには rune -config set skills.max_catalog_size 16KiB、初期値に戻すには rune -config reset skills.max_catalog_size を実行します。カタログを大きくすると、毎回のリクエストで消費されるモデルのコンテキスト量が増えます。

公式のオフラインヘルプスキル

Rune には設定ガイド用のスキルが標準で同梱されており、追加のダウンロードや外部アカウントなしで利用できます。管理対象の公式テキストが変更または破損した場合は自動的に修復されます。カスタマイズを行いたい場合は、公式コピーを直接編集するのではなく、別の個人用／プロジェクト用スキルを作成してください。

rune-settings-guide という名前はこの公式ヘルプのために予約されており、同じ名前でパッケージをインストール・更新することはできず、同名の別ファイルが公式ヘルプを置き換えることもありません（一覧では shadowed として表示されます）。それ以外の一般的なスキル名が複数のスコープに存在する場合はプロジェクト側のスキルが優先されるため、一覧に表示される正確な ID で区別してください。なお、拡張機能やガイドを無効化すると公式ヘルプも参照できなくなりますが、これはインストールされたバイナリから機能が失われたことを意味するものではありません。
