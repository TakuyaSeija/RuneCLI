コマンドの使い方

コンポーザーに / を入力するとコマンドパレットを検索できます。矢印キーで選択し、Tab で補完、Enter で実行します。角括弧 [ ] の引数は省略可能で、山括弧 < > はそのまま入力する文字列ではなく、あなたが指定する値を表します。インストール済みビルドの正確な仕様は /help で確認できます。

セッションとコンテキスト

/new
このワークスペースで新しい会話を開始します（現在のセッションは削除されません）。
/session
このワークスペースの検索可能なセッションピッカーを開きます。
/resume <id>
保存されている特定のセッションを再開します。
/compact
古いコンテキストを要約します。モデルへのリクエストが発生し、過去の細部が省略される場合があります（ディスク上の保存データは消去されません）。
/context
モデルに渡されているコンテキストを確認します。共有する際は非公開の作業データとして扱いに注意してください。
/logs [all|warn|error]
診断イベントを開きます（重要度での絞り込みも可能）。失敗したリクエストや再試行の履歴はここに記録されます。ログの確認自体は、再試行やアカウント変更の許可を意味しません。
/shells
このセッションで実行中および最近のバックグラウンドシェルプロセスと、そのリアルタイム出力を確認します。

モデルと権限

/model [provider:id|id]
プロバイダとモデルのペアを選択します（引数なしの場合は Models 画面を開きます）。モデル ID が複数のプロバイダで重複する場合は、一覧からプロバイダごと選択してください。
/provider [name]
回答を担当するプロバイダを選択します（名前を省略すると一覧を開きます）。以降の作業の送信先が変わります。
/thinking [off|effort]
現在のモデルで利用可能な推論（Reasoning）設定を確認または選択します。Alt+T でも順番に切り替えられます。off は推論無効化の要求であり、上流の経路が推論を一切行わないことを保証するものではありません。
/mode [ask|auto|full]
セッションの権限モードを順番に切り替えるか、明示的に指定します。Full は広範な自律権限を与えるため、単なるエラー回避目的で使用しないでください。
/classifier [on|off|model|reload]
ポリシー審査の確認または設定を行います。reload は待機中のセッションに最新のポリシーを反映します（スイッチが有効なだけでは、審査が実際に稼働している証明にはなりません）。
/set key=value
/set temperature=0.2 のように、対応しているモデル／セッション制御パラメータを変更します。/set temperature= のように任意の値を空にすると、既定値またはプロバイダ側の設定に戻ります。

ファイルと拡張機能

/attach path
次のメッセージにファイルを添付します。送信前に添付待ちリストを確認してください。対応形式のコンテンツは選択中のプロバイダに送信されます。
/detach number|all
添付待ちのファイルを番号指定で 1 つ外すか、すべて解除します。
/undo
対象ファイルの差分をプレビューし、このセッションで最初に行われた変更より前の状態に復元します（セッション外で後から加えた編集が上書きされる場合があります）。
/redo
直前の undo が置き換えた内容をプレビューして元に戻します（無制限のバックアップ履歴ではありません）。
/skills [list|show|enable|disable|reload]
利用可能なスキルガイドを管理します。show、enable、disable には一覧表示されるスキル ID を指定します。編集後は reload でカタログを更新してください。
/skill <id>
現在の会話で指定したガイドを有効化します。ガイドを有効化しても、その中に書かれたすべての操作に実行権限が与えられるわけではありません。
/mcp [list|add|connect|status]
外部ツール接続を管理します。追加や接続の前に、サーバー、接続先、アクセス権限を確認してください（ローカルサーバーはコードを実行できます）。

画面表示とアプリケーション

/settings
Settings 画面を開きます。/* はエイリアスで、キーボードショートカットは Ctrl+G です。
/theme [name]
テーマ（violet、cyan、amber）を選択します。ターミナル自体の背景色や透過はターミナル側の設定に従います。
/panel
会話サイドパネルの表示・非表示を切り替えます（画面幅が狭い場合は非表示のままになることがあります）。
/verbose
ツールステップや思考過程を展開または折りたたみます（ツールが返す出力文字数の上限を増やすものではありません）。
/help
現在のビルドのコマンドおよびキーボードリファレンスを表示します。
/quit
Rune を終了します。最後のウィンドウを閉じると実行中の AI 作業は停止します（保持されたバックグラウンドタスクには個別の生存期間があります）。

rune -config などのシェルコマンドはスラッシュコマンドパレットではなく、OS のターミナルで実行します。それらについては CLI リファレンスを参照してください。コンポーザーから自分でシェルコマンドを実行する場合は、先頭に ! を付けて入力します（詳しくは手動シェルコマンドをご覧ください）。
