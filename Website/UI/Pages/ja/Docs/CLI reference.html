起動と確認

以下のコマンドは OS のシェルから実行します。インストール済みビルドの正確な一覧は rune -help で確認してください。プロバイダへの通信、アカウントの変更、データの削除、またはサーバーの起動を行うコマンドは実際の操作を伴うものであり、単なる診断用フラグではありません。

rune [dir]
現在のディレクトリ、または指定したワークスペースで対話型エージェントを開きます。
rune -p "prompt"
フル画面インターフェースを開かずに 1 つのプロンプトを実行し、回答とツールの進捗を出力します。応答するユーザーがいないため、権限確認が必要な操作は黙って承認されるのではなくすべて拒否されます。
-project <dir>
他のコマンドオプションの対象となるワークスペースを指定します。
-version · -help
アプリケーションのバージョンまたはコマンドリファレンスを表示します。
-settings · -tools
有効なモデル制御設定、またはエージェントに提供されるツール一覧を確認します。
-read-only
変更を伴うツールを制限します。ただし、ファイルの読み取りや外部へのデータ送信が一切行われないことを保証するものではありません。
--no-color
色表示を無効にします。環境変数 NO_COLOR にも対応しています。

設定管理

-config
現在選択されている設定ファイルの場所を表示します。
-config show|defaults|check
有効な設定値の表示、初期設定値の表示、または設定ファイルの検証を行います。show には非公開のアカウントメタデータが含まれる場合があり、check は通信の疎通を証明するものではありません。
-config explain <key>
指定したキーの有効な値と反映タイミングを表示します。
-config set <key> <value>
グローバル設定を 1 つ保存します（例：rune -config set terminal.command_timeout 2m）。
-config reset <key>
グローバルな上書き設定を削除し、現在の既定値または継承動作に戻します。
-config format
設定の意味を変えずに、グループ化された設定ファイルの書式を整えます。
-set key=value
任意のグローバル設定キーではなく、対応しているワークスペース／モデル設定を変更します。

アカウントとモデル

認証情報の入力には、Connections 画面のマスクされた入力欄を使用してください。コマンドライン引数に実際のキーを渡すと、シェルの履歴やプロセス一覧から漏洩する恐れがあります。以下の構文ではプレースホルダーを使用しています。

rune -provider add <name> -key <key> [-preset <p>] [-base <url>] [-model <id>]
-provider list
アカウント、プリセット、および Web サービスの利用可否を一覧表示します。
-provider key <name> <key>
アカウントのキーリングにキーを追加します（認証情報が変更されます）。
-provider keys <name>
マスクされたキーのメタデータを確認します。
-provider dropkey <name> <n>
対象を確認したうえで、指定した番号の認証情報を削除します。
-provider default <name>
新規セッション用のフォールバックプロバイダを選択します（既存のすべての会話を切り替えるものではありません）。
-provider remove <name>
プロバイダ設定を削除します。保存されているすべての認証情報が完全に消去されるとは限りません。
-provider test <name>
課金対象となり得る実際のリクエストを送信して、アカウントをテストします。
-provider models <name>
アカウントのモデルカタログを取得します（ネットワークリクエストが発生します）。
-provider dryrun <name> [model]
リクエストを送信せずに内容をプレビューします。プレビューには非公開のコンテキストが含まれる場合があるため、そのまま共有しないでください。
-provider timeout <name> <seconds>
アカウントごとのリクエストタイムアウトを 5〜3600 秒の範囲で設定します。default を指定すると上書きを解除します。
-provider new-store --yes
読み取れなくなった認証情報ストアを退避し、空の状態で新しく開始します。意図的な復旧判断を行った後にのみ使用してください（すべてのキーを再登録する必要があります）。
-model list · -model set <id>
対象ワークスペースのモデル一覧を表示、またはモデルを選択します。

セッションとストレージ

-session · -resume <id>
セッション選択画面を開く（パイプ接続時は一覧出力）か、指定した ID のセッションを再開します。
-session rename <id> <title>
指定したセッションの名前を変更します。
-session delete <id>
指定したセッションを完全に削除します。実行前に対象のセッションを確認してください。
-storage [list|prune]
プロジェクトストレージの使用状況を確認するか、すでに存在しないプロジェクトに属する対象データを整理（prune）します。
-sandbox [setup|reset]
Windows のコマンド隔離状態の確認、専用アカウントの明示的なセットアップ、または Rune のサンドボックスアクセス権・アカウント設定の削除を行います（他のプラットフォームではこの仕組みは使用しません）。

拡張機能と診断

-skills [operation]
再利用可能なスキルガイドの一覧表示、詳細表示、有効化、無効化、インストール、再読み込みを行います。インストールは確認済みのフォルダまたは ZIP を受け取り、--scope user で個人用にしない限り現在のプロジェクトに配置します。
-mcp [operation]
外部ツール定義の管理、承認、検証、テストを行います。接続するとローカルプロセスの起動やリモートサービスへの通信が発生する場合があります（検証だけでは接続成功の証明にはなりません）。
--scope user|project|private-project
拡張機能の変更を保存する設定スコープを選択します。共有プロジェクト（project）への変更は、そのプロジェクトを参照する他のユーザーにも影響します。
-doctor
接続チェックを含む診断を実行します。ネットワークリクエストが発生する場合があるため、出力を共有する前に内容を確認してください。
-db <path>
別のエンジンストアを使用します（RUNE_HOME で設定ホーム全体を切り替える操作とは異なります）。
-host
対話型 UI ではなく、フロントエンド連携用の行区切り JSON モードで動作します（公開ネットワークサーバーではありません）。
-script <file>
記述されたモデルスクリプトを再生します。スクリプトは実際のツール呼び出しを提案できるため、未確認のスクリプトを本番の作業環境で実行しないでください。

拡張機能の設定やアクセス権の管理については、スキルまたは MCP 接続を参照してください。エラーを回避する目的で安易に Full モードへ切り替えたり、ローカルデータを削除したりしないでください。
