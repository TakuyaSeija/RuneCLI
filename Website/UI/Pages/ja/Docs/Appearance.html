カラーテーマ

Settings → Appearance → Color theme では、Violet、Cyan、Amber から選択できます。行の上で左右キーを押すとその場で切り替わって保存され、Enter を押すと個別の一覧が開き、選択したテーマを Enter で適用できます。閲覧しただけで適用せずに閉じるには Esc を押します。初期設定のテーマは Amber です。

テーマは画面の見た目だけを変更するもので、モデルの挙動や権限には影響しません。/theme violet、/theme cyan、/theme amber コマンドでも切り替えられます。グローバル設定キーは ui.theme で、リセットすると上書き設定が解除されます。

会話サイドパネル

パネルの表示・非表示は Appearance 設定、Ctrl+O、または /panel で切り替えられます。初期設定では有効になっています。ターミナルの横幅が狭い場合は、設定が有効でも横並びのパネルが自動的に隠れることがあります。パネルを非表示にしても、使用量の集計、ファイル変更の追跡、プランの記録は停止しません。

ターミナル側が管理する項目

壁紙、背景の透過、ぼかし、ウィンドウ装飾、フォントの描画は、お使いのターミナルやデスクトップ環境側で制御されます。Rune 自体には背景画像やぼかしの設定はありません。同じテーマでも、ターミナルの背景が明るい場合と暗い場合で見え方が変わることがあります。

就職キー付きのショートカットやマウス操作もターミナルの仕様に依存します。ターミナルのプロファイルによっては、Ctrl+ホイールがズーム、Alt+ホイールが横スクロール、あるいは特定のショートカットがターミナル自身の操作に割り当てられている場合があります。

高度な表示オプション

ui.mouse
既定値は true。Rune 内のマウスクリック、ホイールスクロール、ドラッグによるコピーを有効にします。false にするとマウス選択をすべて端末側に委ねます。
ui.scroll_lines
ホイール 1 ノッチあたりの移動行数（既定値 2、1–30）。
ui.scroll_smooth
既定値は true。同期フレーム描画で 30 fps 以上を維持できる端末で滑らかにスクロールし、それ以外の端末ではノッチ単位で移動します。

これら 3 つのマウス・スクロール項目は TOML 専用の設定であり、フレーム間隔・Escape 判定時間・色検出は固定の実行時定数です。スクロール設定を変更しても、端末が未対応の入力を送れるようにはなりません。

rune -config explain ui.theme
rune -config reset ui.theme

reset はグローバル設定の変更です。閲覧や移動のキー操作については、他のターミナルアプリの動作を推測するのではなく /help で確認してください。
