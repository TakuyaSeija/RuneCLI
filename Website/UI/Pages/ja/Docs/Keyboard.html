会話とアプリケーション操作

Enter · Alt+Enter
メッセージを送信、または改行を挿入します。就職キー付きの Return の動作はターミナルが報告する入力に依存します。
Ctrl+G · Ctrl+O
Settings を開く、またはサイドパネルの表示を切り替えます。
Ctrl+T · Ctrl+R
プランを開く、またはステップと思考過程を展開／折りたたみます（セッションピッカー内での Ctrl+R は名前変更を開きます）。
Alt+T
選択中のモデルで利用可能な推論（Reasoning）設定を順番に切り替えます。
Tab
スラッシュコマンドを補完するか、権限モードを切り替えます（フォーム内ではフォーカス移動として動作します）。
Esc 2 回
実行中の AI 作業を停止します。1 回目で確認を表示し、3 秒以内に 2 回目を押すと停止します（待機中のサブ画面は Esc 1 回で閉じます）。
Ctrl+C 2 回
Rune を終了します。1 回目で終了確認状態になり、ターンのキャンセルや下書きの消去は行われません。
Ctrl+L · Ctrl+↓
画面を再描画する、または最新のチャット位置へジャンプします。

テキスト編集

以下のキーバインドは、コンポーザー、編集可能な回答欄、Settings の入力欄、モデル検索、MCP の入力欄、およびセッションの検索・名前変更で共通して使えます。リストやボタンにはそれぞれ固有の移動キーがあります。「論理行」は挿入された改行コードまでを指し、「表示行」は画面端での折り返しを含みます。

キー動作
← / →表示上の 1 文字分移動します。
Ctrl+← / Ctrl+→前の空白区切りの単語の先頭／次の単語の末尾へ移動します。
↑ / ↓列位置を維持したまま、表示行を上下に移動します。
Ctrl+A / Ctrl+E現在の論理行の先頭／末尾へ移動します。
Home / End入力全体の先頭／末尾へ移動します。
Backspace / Deleteカーソルの前／後の 1 文字、または選択範囲を削除します。
Ctrl+U / Ctrl+K論理行の境界まで後方／前方を切り取り（Kill）ます。改行位置での Ctrl+K はその改行のみを削除し、入力末尾では何もしません。
Ctrl+W / Alt+D左側／右側の空白区切りの単語を（隣接する空白ごと）切り取ります。
Ctrl+Y / Alt+Y直前に切り取ったテキストを貼り付け（Yank）／貼り付け直後にそれ以前の履歴を順番に呼び出します。
Ctrl+_ / Alt+Rその入力欄でのテキスト編集を元に戻す（Undo）／やり直す（Redo）。
Shift+←/→/↑/↓文字単位または表示行単位で選択範囲を拡張します。
Ctrl+Shift+← / →単語単位で選択範囲を拡張します。
Alt+X / Alt+W隣接する文字／単語を入れ替えます。
Alt+U / Alt+L / Alt+V次の単語または選択範囲を大文字化／小文字化／先頭文字のみ大文字化します。

テキストを選択した状態で文字入力、貼り付け、または削除を行うと選択範囲が置き換わります。一時的な Undo 履歴や切り取ったテキストはその入力欄に属し、上限があり、入力欄やセッションが切り替わるとクリアされます（ファイルのバックアップではありません）。なお、Rune は Readline のすべてのエイリアスを備えているわけではありません（たとえば Ctrl+B/F や Alt+B/F は移動キーとしては動作しません）。

履歴の呼び出しとスクロール

コンポーザー内で上下キーを押すと、まず表示されているテキスト内を移動し、先頭・末尾に達した後にプロンプト履歴を呼び出します。PgUp／PgDn は直接履歴を呼び出します。履歴はそのセッションに属します。

マウスホイール 1 ノッチで設定された行数（初期値は 2 行）スクロールします。ターミナルがイベントを転送する場合、Ctrl+ホイールまたは Alt+ホイールで 3 倍の距離を移動します。ターミナル側がこれらをズームや横スクロールに予約している場合でも、通常のホイール操作とキーボード操作はそのまま利用できます。

マウス操作

クリックするとテキストカーソルの配置やボタンの操作が行えます。テキスト上をドラッグして離すとコピーされ、クリップボードに格納されるとハイライトが消えます。会話領域でのドラッグはサイドパネルや枠線を除いたそのペインの本文のみをコピーし、表はタブ区切りのセルとしてコピーされます。折りたたまれたコマンドをコピーすると、表示記号の ↵ や … を除いた元の改行付きのコマンドが取得できます。入力欄でのドラッグはカーソル位置や下書きを変えずにテキストをコピーします（編集用にテキストを選択する場合は Shift+矢印キーを使用してください）。マスクされたシークレット欄がコピーされることはありません。

コピーが機能するには、ターミナル側でクリップボードへの書き込みが許可されている必要があります（SSH 経由やマルチプレクサ内ではブロックされることがあります）。ターミナルが対応している場合、Shift+ドラッグを使うと枠線を含めたターミナル標準のテキスト選択が行えます。ui.mouse = false に設定すると、すべての選択操作がターミナル標準の動作になります。

リンクをクリックすると REFERENCE パネルが開きます。Enter で Web アドレスをブラウザで開き、C で完全なリンク先をコピーし、Esc でパネルを閉じます。リンク上をドラッグした場合はテキストのコピーとなり、リンクが開かれることはありません。

リストとフォーム

矢印キーで項目を選び、Enter で開くか確定します。Tab／Shift+Tab でフォーカスを移動し、Esc でエディタをキャンセルするか 1 段前の画面に戻ります。Models 画面では、Ctrl+F で検索欄へ移動、Alt+C でモデル設定を開き、T で実際のリクエストによるテストを実行、Delete で選択した項目のローカル設定を削除します。

質問フォームでは、Alt+左右キーで質問を切り替えます。通常の左右キーはテキスト編集またはボタンの選択に使われます。PageUp／PageDn キーはカード内の長文をスクロールするだけで、回答を送信することはありません。自由記述欄の内部で上下キーを押すと、まず入力テキスト内を移動してから欄の外へ移動します。マウスドラッグは背後のボタンを押さずにテキストを選択します。

ターミナルによる違い

ショートカットは、ターミナルがそのキー入力を Rune に渡した場合にのみ機能します。OS のショートカット、ターミナルのプロファイル、従来の制御文字エンコーディングによって特定のキーの組み合わせが予約されていることがあります。背景、ぼかし、透過も Rune ではなくターミナル側の管轄です。シェルのキーマップがそのまま使えると想定せず、/help で現在のビルドの操作キーを確認してください。
