Access is not selection

Connections owns account addresses and API keys. It does not choose the current model, model request timeout, web-search route or page reader. Those belong to Models, Runtime and Tools respectively.

A key count or Configured state means credentials are present, not that a request succeeded or that credit is available. Resting can mean a credential is temporarily unavailable. Check the actual failure instead of repeatedly replacing the account.

Add a model account

Each provider preset, with its key and address, is listed in Model providers.

  1. Open Settings → Connections → Add connection and choose the intended model provider.
  2. Review the form, initially marked Not connected yet. A preset with a fixed address asks for its key; an account-dependent or custom address must be supplied explicitly.
  3. Check the connection name and key name. Enter secrets only in the credential field.
  4. Connect. Rune tests a new model account before accepting it; the request may be billed. Cancel leaves the addition unsaved.
  5. Select the actual provider/model under Models after connection.

A preset supplies compatible setup defaults. It is not an account, an API entitlement or a promise that all provider products work. Plan-specific subscriptions and regional addresses can differ from a vendor's ordinary API.

Add a web account

Choose a Search & Fetch vendor, enter the required address/key and save the account. Saving web access alone does not enable or prove a search/page provider works. Continue in Tools → Web search or Web fetch → Provider to add, test and select the intended service.

Search and fetch have independent selections. A local-model account and the same vendor's web service may require different addresses or keys. See Web search & fetch.

Edit and remove

Open an existing connection to change its Base URL or manage named keys. Model endpoint changes are tested before acceptance. Use default restores the provider's supplied address, not one guessed from an account name.

Adding a key adds an alternative; it does not replace every key automatically. Review a key's name and masked preview before removal. Removing a connection may leave its credentials available for reuse; account removal is not a secure-erasure promise.

Destination and testing

Changing an endpoint can send both credentials and prompts to another party. Verify ownership and the intended region before connecting. Remote keyed endpoints require encrypted transport; an on-machine endpoint is a separate local case.

Connection and model tests are real requests and can incur cost. A successful account test applies to the tested request, not every model, tool, context length or entitlement. Prefer a small, deliberate test after checking the exact error in logs.
