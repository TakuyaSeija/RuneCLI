Global helper jobs

The auxiliary rows under Settings → Generation apply to every session using the selected Rune home. They can use the active model or an explicitly configured provider/model pair. Changing one can change cost, latency and which provider receives relevant data; the confirmation is not approval for unrelated actions.

Configured output allowances remain bounded by the chosen model's actual capability and the provider's complete request-size limit. A larger number in Settings cannot enlarge a service's limits. Reset a model override to inherit rather than inventing a placeholder model.

Supporting models that require reasoning can need a larger effective output allowance. The advanced auxiliary.mandatory_reasoning_output_tokens factory value is 4,096; it is not an amount universally added to every job. The requested result still needs room within the selected model's limit.

Sanitizer

The sanitizer helps the classifier identify the user's original instructions and restrictions. It does not clean files, remove odd Unicode from every message or rewrite the conversation. It runs only where classifier review is applicable. Unavailable extraction can fall back to original instructions; restrictions are not thereby removed.

Factory values
Enabled, inherited model, 120-second request timeout, 4,096 output tokens and source text sent in batches of at most 64 KiB.
Keys
sanitizer.enabled, sanitizer.model, sanitizer.timeout, sanitizer.max_output_tokens, sanitizer.max_batch_size.

The batch size is measured in bytes of text, not tokens. Smaller batches can add requests; a batch larger than a provider accepts is refused by that provider.

Classifier

A policy-review model evaluates applicable proposed actions against your CLASSIFIER.md rules. It is inactive in Ask and needs usable policy in Auto or Full. Human-permission calls use your explicit decision rather than that AI review. An enabled flag does not prove a particular action was reviewed.

Factory values include enabled, inherited model, 120 seconds, 1,024 output tokens, 256 KiB combined text evidence and 64 KiB per policy file. Tool exclusions and recent-input context lists are separate choices. See Classifier policy for authority, reload and failure behavior.

Compaction

Compaction summarizes older history to make room in model context. /compact requests it manually; Rune also runs it by itself from the input usage your provider reports, or after the provider actually rejects a request as too large. Rune never guesses a token count from text, thinking or image size. The summary is not a perfect copy of every fact, and it does not delete stored sessions.

KeyFactory value / meaning
compact.modelInherit active model.
compact.max_output_tokens32,768 requested summary tokens, constrained by the model.
compact.max_batch_size128 KiB of quoted history text per summary request. A size in bytes, not tokens; lower it if a small summary model rejects a batch.
compact.keep_recent_turnsFive recent turns desired in full; available context can require fewer.
compact.fallback_context_tokens200,000 reported input tokens: the point at which Rune compacts by itself when the model publishes no context window. It does not enlarge a known limit or infer tokens from text length.
compact.message_chars32,000 characters of historical assistant/tool-result text considered per message.
compact.tool_chars2,000 characters of historical arguments per call.

Original user instructions are handled separately from those assistant/tool excerpts and are split into batches, never silently shortened. When the summary model actually rejects the context, a larger active model can be used instead. A needed failure can ask whether to retry. Cancelling or declining stops the attempt; a failed summary is not reported as complete.

Titles and reset

The title job names a conversation from relevant early work. It inherits the active model, requests up to 256 output tokens and limits the title to 60 characters by default. Changing these settings affects future title generation, not every existing title; use session rename to change one title.

Inspect a key with rune -config explain <key>. Use default or rune -config reset <key> removes a global override. Reducing review budgets can reduce coverage; increasing auxiliary work can increase cost. Review the specific consequence before changing a global value.
