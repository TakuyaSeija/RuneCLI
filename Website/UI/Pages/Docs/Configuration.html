Location and scope

Global configuration is rune.toml in the selected Rune data home, normally ~/.rune/. The Settings reference lists every setting you can change: a row in Settings or a key in the file. RUNE_HOME selects a different home. A file named rune.toml inside a project is not automatically the settings file, and -project chooses a workspace rather than a settings home.

Use rune -config to see the actual location. The file holds your saved choices; absent values inherit the current defaults. Its top-level version = 1 describes the configuration format, not the application version. Do not change it to request an upgrade.

Inspect one thing at a time

-config explain <key>
Read a key's effective value, description and application timing.
-config defaults
Read factory defaults separately from your saved choices.
-config check
Validate configuration syntax and supported values. It does not test keys, credit or connectivity.
-config show
Inspect effective configuration. It may contain private account metadata; redact before sharing.
-settings
Inspect model controls for the selected workspace.

Change and reset

rune -config explain terminal.command_timeout
rune -config set terminal.command_timeout 2m
rune -config reset terminal.command_timeout
rune -config check

Run the set command only when you intend that global change. Reset removes the override; it does not write a copied default. In Settings, Use default serves the same purpose for global values. Unknown or retired keys are errors, not silently supported aliases.

TOML has no native null. Remove an optional key or use the supported reset command instead of writing null. Do not assume an empty string, “auto”, “none” or an empty list means reset for every setting.

Types and units

Boolean
true or false, unquoted in TOML.
Count / tokens
A whole number within the setting's range. Tokens, characters and bytes are different measurements.
Duration
A string with explicit units such as "500ms", "60s" or "2m". Only permission/question waits accept unlimited.
Size
Use explicit binary units such as "16MiB". A unitless size is interpreted as KiB, not bytes.
List
Use the documented exact entries. [] is an explicit empty selection, not necessarily a reset.
[terminal]
command_timeout = "2m"

[generation]
temperature = 0.2
stop = ["END,EXACT", "STOP"]

This is syntax guidance, not a recommended universal configuration. The stop array preserves exact strings, including commas; the session editor instead accepts comma-separated entries. Global generation defaults do not overwrite all current sessions.

Timing and risk

Changes normally propagate without restarting. Use explain for the particular setting: live values and next-operation values have different timing. Editing CLASSIFIER.md does not reload an already-pinned session policy; use the idle reload action.

Keep account endpoints and credentials out of public examples. Validate hand edits without replacing unrelated choices. Higher limits can increase memory, disk, context and cost; they do not grant access or make an unsupported model work.
