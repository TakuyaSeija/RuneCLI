Open and navigate

Press Ctrl+G, enter /settings, or use its /* alias. Overview links to six sections. Arrows choose a row or card; Enter opens it. Tab/Shift+Tab moves focus, and Esc cancels an editor or returns one level. The footer describes the selected control.

Open a value, edit it and choose Apply. Cancel keeps the earlier value. Some choice rows save directly as Left/Right changes them; read the hint and wait for the success message. Merely highlighting an item in a separate chooser is not necessarily applying it.

One home for each setting

Models
Browse configured accounts' models, apply a provider/model pair, refresh a catalog, and configure persistent capability and price information with Alt+C.
Generation
Current-session reasoning, sampling and requested output. Global auxiliary-model controls are lower on the same page.
Connections
Account access: API addresses and named keys. It does not choose a web provider or own model request timeouts.
Runtime
Model request timeouts, retry behavior, key ring rotation and shared connection/stream waits.
Tools
Tool-specific waits and output/work limits, question and permission deadlines, and separate web provider selection.
Appearance
Theme and conversation side-panel preference. It does not configure terminal wallpaper, blur or transparency.

Global and session choices

Tool limits, retry/network settings and auxiliary-model choices are global to the selected Rune home. Main Generation controls and model selection affect the active session/model. Saved model preferences can be recalled when returning to a model.

The global [generation] table supplies starting defaults, not an instruction to overwrite every existing session. New-session fallback selects a starting provider for future sessions, not the provider for every open conversation.

Reset and application timing

Use default removes the saved global override so the current default or inheritance applies. Saving the literal factory number is a choice; it is not the same as leaving the key unset. For optional session Generation values, clearing the field returns control to the provider/default.

Settings normally follow changes without restarting Rune. Some consumers update live; others use the new value at the next operation while in-flight work keeps its starting settings. Use rune -config explain <key> for the exact key. Classifier policy has a separate explicit reload.

Inspect before changing

A valid configuration does not prove a connection works, and Configured does not prove an account has credit. Connection tests make real requests and can cost money. Changing a provider can change where your data goes; increasing retries or output can increase spending.

Not every advanced option has a UI row. The configuration-file guide explains how to inspect and reset those options without inventing controls or replacing unrelated choices.
