Add a provider

A provider is the account that answers Rune's model requests. Rune brings no account and no API credit of its own: each request is sent to, and billed by, the provider you connect.

  1. Press Ctrl+G, open Connections and choose Add connection.
  2. Under MODEL PROVIDERS, pick the preset for your provider, or compatible for any other OpenAI-compatible endpoint.
  3. If the preset has no fixed address, enter your address first. Then paste the API key into the masked field and press Enter.
  4. Rune sends one real request to check the account before it saves the connection. That request can be billed and sends test text to the provider.
  5. Open Models, choose the provider and select a model with Enter.

Saving a connection proves the account answered once. It does not prove every model in the provider's list is available to you. Keys are stored encrypted on your computer; see Credentials.

Notes by provider

Reasoning controls differ by provider and by model. These notes describe what Rune sends; the provider can still change what a model does with it. Set a model's reasoning choices with Alt+C in Models, as described in Generation & reasoning.

alibaba
Use the compatible-mode address of your Model Studio workspace and region, with a key from that region. Thinking is on or off, with no levels. Never offer Off for a model that always thinks: it refuses the request. GLM models on Model Studio return tool calls only with an option Rune does not send, so use them through Z.ai.
cerebras
Reasoning levels differ by model and are not listed by the service. gpt-oss-120b and qwen-3.8-27b take Low, Medium and High; add them with Alt+C.
cloudflare
Workers AI. The address contains your account ID, and the key is an API token with Workers AI access, not a Tunnel token. Models are read from your account's model list.
compatible
Any OpenAI-compatible endpoint. Nothing about its models is assumed: set context, output and reasoning with Alt+C from the endpoint's own documentation.
deepinfra
Its model list gives prices and marks which models reason. Levels are Low, Medium and High; without a chosen level the model's own default applies.
fireworks
Levels run from Low to Max. A model that takes fewer levels is set with Alt+C.
huggingface
The Inference Providers router, with a token allowed to call Inference Providers. Which provider serves a model, and what it supports, depends on that pair.
inclusionai
InclusionAI's Ling models through Ant Group's Ling API. The 3.0 and 3.1 models switch thinking on or off, with no levels. A Ling server you host yourself is added with compatible.
inference
Its model list names each model's thinking levels, and Rune offers exactly those.
meta
The Meta Model API, not a Meta AI chatbot login. Levels run from Minimal to Extra high. Muse Spark always reasons and refuses Off and stop words, so leave Stop empty in Generation.
mimo
Pay-as-you-go keys and Token Plan keys reach different addresses; Rune picks the address from the key you enter.
minimax
Rune asks for thinking apart from the answer. Only MiniMax-M3.1-Flash takes levels (Low to Max): add them with Alt+C. Do not offer Off for MiniMax models.
moonshot
Kimi. kimi-k3 takes Low, High and Max; add them with Alt+C. The kimi-k2 models take no level. Do not offer Off for Kimi models.
novita
Thinking is on or off on models that offer both, with no levels. Prices come from its model list.
nvidia
The hosted NIM API. Thinking controls differ by model and are not listed by the service; set them per model from that model's card. A self-hosted NIM uses its own address.
openrouter
One account offers many models with different prices and limits. Select the exact model and check its current price.
siliconflow
The global address; a .cn account uses its own address and key. Thinking is on or off on the models SiliconFlow lists for it. deepseek-ai/DeepSeek-V3.1 calls tools only with thinking off.
stepfun
Levels are Low, Medium and High. step-3.5-flash-2603 takes only Low and High: remove Medium for it with Alt+C.
tencent
Hunyuan is moving to TokenHub: enter your region's TokenHub address, shown beside the address field, with a key from that region. Thinking is on or off, with levels Low, Medium and High. Some models TokenHub serves for other vendors refuse Off.
together
Its model list gives prices but no thinking levels: add a model's documented levels with Alt+C.
tokenrouter
TokenRouter at tokenrouter.com. Services with similar names on other domains are different companies with their own addresses.
zai
The Z.ai standard API. A Coding Plan has its own keys, addresses and list of eligible tools. Levels run from Minimal to Max; without a chosen level the service's default (Max) applies. glm-5.3 always thinks and takes only Low, High and Max. Only one stop word is accepted.

Models on this computer

Ollama serves local models from this computer on port 11434, with no key. This is a different service from Ollama's cloud web search. A local model keeps prompts on your machine, but web tools, auxiliary jobs and commands can still contact other services.

9router is a router app that runs on your computer, on port 20128 by default, and forwards requests to the upstream accounts you set up in it. One connection serves every model it offers. For Claude Code's models (cc/…), Rune uses 9router's Anthropic-style door by itself, so their cache and thinking counts arrive; there is nothing to set up. Off is a request: when a route reports that thinking cannot be disabled, Off asks for Low instead.

A preset's local address is a default, not proof that the service runs on your machine. Start the service first; Rune's test request tells you whether it answered.

Keys and accounts

A connection can hold several keys. rune -provider keys <name> lists them masked, and Connections manages them without showing their values. When a key reports insufficient balance or reaches its allowance, Rune hands over at once to the next key in the ring; see Runtime & retries.

Removing a connection removes its configuration. Its keys can stay in the encrypted store for reuse; delete a key explicitly when you mean to. A key never travels over plain HTTP to another machine.

Choose a model

Settings → Models lists the models your connected providers return, and can refresh that list. Select one with Enter, or type /model provider:id in the conversation. Alt+C on a model edits what Rune knows about it: context size, output limit, reasoning choices and price. A price you enter is used for the spend shown in the side panel, which is not the provider's invoice.

Models → New-session fallback chooses the provider a new session starts with. It does not switch open conversations; use /provider or /model in a session for that.
