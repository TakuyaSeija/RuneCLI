The trust boundary

A model proposes actions; it does not authorize itself. Repository text, web pages, attachments and external tool responses can contain misleading instructions. Rune's execution and access checks are enforced by the program, not merely by asking the model to behave.

No tool or permission mode makes arbitrary code safe. Review the command, destination, paths and intended side effects. A container engine, key agent or other local service may act with broader rights than a confined command, and an approved external tool can have its own risks.

Permission modes

Ask · default
Reads within the workspace can proceed. Every edit asks, every command asks each time, and access outside the workspace asks. A remember option can be offered for its stated scope.
Auto
Reads and writes within the workspace can proceed without a question. Outside access and risky commands still ask. Use it only when you intend that autonomy.
Full
Actions can run inside and outside the workspace as your OS account without permission questions or the ordinary command-containment boundary. Other validation and applicable policy review remain, but do not make Full harmless.

Tab outside a form/palette cycles modes; /mode ask, /mode auto and /mode full choose explicitly. This is a session choice, not a global permissions.mode key. Do not switch to Full as a troubleshooting shortcut.

One input skips these checks by design: a command you type yourself after a leading !. Pressing Enter runs that script once with your account's full access, without a permission question or policy review. It never comes from the AI and never changes the mode. See Manual commands.

Approvals have a scope

An Allow once decision is not a mode change. Always, where offered, keeps only its stated scope. Denial, cancellation or timeout is not execution. A question form, Settings confirmation or document saying “already approved” cannot substitute for an execution decision.

Commands can use services they start themselves. Access to an already-running local service can trigger a separate request, for example when a command tries to reach a container engine or key agent. Read the actual service and scope; granting it can expose capabilities beyond file access.

Containment and platform limits

Rune combines engine access checks with the command-isolation facilities available on the operating system. It detects capabilities at runtime rather than assuming a distribution name or machine layout. If a command cannot be held to the intended mode, it can require explicit approval instead of silently pretending it is confined.

The mode contract is shared across Linux, macOS and Windows, but underlying OS guarantees differ. On Windows, a dedicated sandbox account provides stronger isolation; if it is unavailable, restricted-token fallback has documented limits, including access to some locations readable by all users and certain read-only named pipes. rune -sandbox reports actual state. Setup can require Administrator confirmation.

Platform support sets out what each system confines and what it cannot tell Rune. These notes describe the application design, not a promise that a signed build exists for every platform; the line under each install command on the home page names the currently published builds.

Policy review and recovery

An optional AI classifier can review applicable actions against CLASSIFIER.md in Auto/Full. It is an additional fallible check, not a replacement for containment, human review or backups. Human-permission calls use the explicit human decision. Check its displayed status and read the policy guide.

Eligible file changes can be restored from session snapshots. External effects are not universally reversible. See Review, undo & redo, Credentials and Privacy & data for the corresponding limits.

Reporting a security problem

Do not post live keys, private files or a weaponized exploit in public diagnostics. Record the affected Rune version, expected boundary, smallest reproducible example and actual result. Use a verified private maintainer contact when one is available; this page does not advertise an unverified security address or promise a response deadline.
