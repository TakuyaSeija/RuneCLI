A skill is a guide

A skill packages reusable instructions and references for a task. It is not an executable permission grant. The agent can discover a relevant skill and read its SKILL.md, or you can explicitly activate one in the conversation. Review advice and scripts from other authors before following them.

Discover and use

/skills list
List available guides and their exact IDs.
/skills show <id>
Read one guide's information.
/skill <id>
Activate a guide for this conversation. Its text cannot approve unrelated actions or override execution checks.
/skills enable|disable <id>
Change availability for the current project; this does not uninstall it for every user or project.
/skills reload
Refresh the catalog after changes. Read a changed guide again before relying on it.

Locations and installation

A project guide lives in .rune/skills/<name>/SKILL.md; portable project guides can use .agents/skills/. Personal guides live under the selected Rune home's skills folder, with the portable personal location available when enabled.

rune -skills install <folder-or-zip> installs a reviewed package in this project's .rune/skills/, so it stays with the project it serves and does not mix into other projects; it is shared with everyone who uses the project's files, a repository included. Add --scope user to make it a personal guide offered in every project. rune -skills update <folder-or-zip> replaces an installed copy in the scope chosen the same way and keeps no copy of the previous version, so keep your source or use version control. Each package has its own lowercase name and matching folder, a SKILL.md with name/description metadata, and optional relative references. Installation and updates should be deliberate rather than automatic trust in downloaded text.

What the AI sees of your skills

The AI is not handed every guide in full. It receives a short catalogue of the available skills, their names and one-line descriptions, and reads a whole guide only when it needs one. That catalogue is limited to 8 KiB of text by default (skills.max_catalog_size); a skill that does not fit stays discoverable, so the AI can still find and read it. The limit is a size in bytes, not a count of model tokens. A capabilities.catalog_bytes value, where you saved one, takes precedence over it.

Change it with rune -config set skills.max_catalog_size 16KiB and return to the default with rune -config reset skills.max_catalog_size. A larger catalogue uses more of the model's context on every request.

Official offline help

Rune bundles the settings-guide skill; it does not require another download or service account. The managed official text can be repaired automatically if changed or damaged. Put customizations in a separate personal/project skill rather than editing that managed copy.

The name rune-settings-guide belongs to this help: no package can be installed or updated under it, and another copy of that name never takes its place; the list shows such a copy as shadowed. Other guides with the same name can come from different scopes, and the project's copy takes precedence. Use the exact listed ID to distinguish them. Disabling capabilities or a guide can also make official help unavailable; it is not proof the installed binary lacks the feature.
