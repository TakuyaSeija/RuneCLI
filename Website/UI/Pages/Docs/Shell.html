Run a command yourself

Type ! as the very first character in the composer, followed by a command, and press Enter. Rune runs that script for you, not the AI. Before you press Enter, the composer shows Shell · full access once, so you can see that this input is a command and not a message.

! git status --short
npm test

The example above is one script of two lines: both run. Only the first line carries the !; a second ! would be read by the shell itself, which in bash and sh turns the next command's failure into success. Use it for a quick check, a build you want to watch, or a step the AI was not allowed to take. The command and its result then become part of the conversation, and the AI answers after it ends.

What counts as a command

  • Only a ! in the first position starts a command. hello ! echo test, a ! after a space, or a ! on a later line of an ordinary message is plain text.
  • Once the input starts with !, every line belongs to the same script. A later ! is shell syntax, not a second Rune command.
  • Pasting never runs anything. Enter runs the whole current script, including every pasted line.
  • A lone ! runs nothing. Delete the leading ! to turn the input back into a message.

What access it has

Enter is the permission. The script runs once with the full access of your operating-system account: outside the workspace boundary and the command sandbox, without classifier or sanitizer review and without another permission question.

It does not run as Administrator or root, does not change the session's mode, and does not approve any later action by the AI. Read the whole script before you press Enter, especially one you pasted.

While the AI is working

A command you send during a turn waits for that turn to finish, then runs in the order you sent it. Its live output appears as it runs. When it ends, or when it moves to the background because it is still running at the configured wait or is waiting for typed input, Rune adds the command and what it printed to the conversation, and the AI responds. That response is a normal model request and can cost money.

If a window reconnects, Rune sends the same submission again without running it twice. After a crash, Rune never replays a command that may already have run.

When the AI was refused

When a command the AI proposed is refused, the refusal can mention this manual option. Rune never submits a ! command for you and never retries a refused action by itself. Other tools gain no such bypass.

Which shell runs it

The shell is set by terminal.shell. With the factory value auto, Rune uses bash where the computer has it and /bin/sh otherwise; on Windows it uses PowerShell 7, then Windows PowerShell, then Command Prompt. Each shell reads commands in its own language.

The command's box shows the shell that actually ran it: $ for bash and zsh, PS> for PowerShell and > for Command Prompt. A collapsed box shows the first row of the script; click it to open the whole script with its original lines.

Privacy

The command and everything it prints are sent to the AI with the next request. Do not print secrets, keys or private files you would not paste into a message. Rune redacts the keys it knows about, which is not a guarantee for every private value.
