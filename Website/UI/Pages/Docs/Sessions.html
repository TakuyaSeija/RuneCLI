Start and resume

/new starts a fresh session in the current workspace. /session opens its session picker; type to search, choose a result and press Enter to resume. /resume <id> selects a known session directly. Shell equivalents are rune -session and rune -resume <id>.

A fresh session does not import another session's composer history. Resuming restores stored conversation and choices; it does not mean every project file still matches the earlier state. Tell Rune about relevant external changes and review its next actions.

Steer and stop

You can send a correction during a task. It is handled in order at a subsequent step; it cannot recall a provider request already sent or reverse a command already executed. State what should change and which previous instruction it replaces.

Esc twice stops active AI work without leaving Rune. Ctrl+C first arms leaving; repeat to leave. Stopping AI work is not proof that every background command ended: inspect the task's reported state separately.

Context and compaction

/context shows information supplied to the model. A context window is not maximum reply length; unknown is not unlimited. /compact requests a summary of older history, and Rune can also compact by itself.

Rune compacts by itself from the input usage your provider reports, or when the provider actually rejects a request as too large for the model's context. It never turns text, thinking, images or file sizes into a guessed token count, so the size of the next request is unknown until the provider reports it. When the provider says no and no older part can be summarized safely, Rune reports that failure instead of resending the same request.

The footer says Compacting while the job is active, including between turns. New messages wait in order. A required failure can offer a retry question; cancelling stops that attempt, and a failed summary is not shown as complete.

The factory preference keeps five recent turns in full where context allows, with a 32,768-token summary allowance constrained by the model. Long history is summarized in batches of at most 128 KiB of text each; that is a size, not a promise that a small model accepts it. Original user instructions are handled separately from historical assistant/tool excerpts. Summaries can still lose detail. Compaction frees model context, not disk storage.

Usage and spend

Spend counts requests with known prices. Unknown is explicitly unpriced, not free. When a previously unpriced request obtains a model price, it is priced then; requests already priced keep their recorded cost. Auxiliary jobs, retries and connection tests can add spending.

Local accounting is not the provider's invoice. usage.warn_spend_usd is a warning threshold, not a hard cap. Use provider-side controls when you need an enforceable budget.

Closing and maintenance

When the last window leaves, active AI work stops. Background commands can remain during the detached-session retention period, 60 seconds by default; Rune is not an indefinite service manager.

rune -session rename <id> <title> changes one title; rune -session delete <id> permanently removes one session. rune -storage list inspects kept project data; prune removes eligible data belonging to missing projects. Review before deletion. A session-list limit does not delete older sessions.
