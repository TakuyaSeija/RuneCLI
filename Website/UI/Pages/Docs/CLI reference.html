Launch and inspect

Run these commands in your operating system's shell. Use rune -help for your installed build. Commands that contact providers, change accounts, delete data or start servers are operations, not harmless diagnostic flags.

rune [dir]
Open the interactive agent in the current or supplied workspace.
rune -p "prompt"
Run one prompt and print the response and tool progress without the full-screen interface. Permission requests are refused rather than silently approved when there is nobody to answer.
-project <dir>
Select the workspace for another command.
-version · -help
Print the application version or command reference.
-settings · -tools
Inspect effective model controls or the tools offered to the agent.
-read-only
Restrict mutating tools. This is not a guarantee that no file is read or no data is sent.
--no-color
Disable color. The NO_COLOR environment variable is also supported.

Configuration

-config
Show the selected settings location.
-config show|defaults|check
Show effective values, show factory defaults, or validate the file. Show can contain private account metadata; check does not prove connectivity.
-config explain <key>
Explain one key's effective value and application timing.
-config set <key> <value>
Save one global choice. Example: rune -config set terminal.command_timeout 2m.
-config reset <key>
Remove a global override so the current default or inheritance applies.
-config format
Reformat grouped settings without intentionally changing their meaning.
-set key=value
Change a supported workspace/model preference, not an arbitrary global configuration key.

Accounts and models

Prefer the masked credential editor under Connections. Real keys in command arguments can leak through shell history and process listings. The syntax below deliberately uses placeholders.

rune -provider add <name> -key <key> [-preset <p>] [-base <url>] [-model <id>]
-provider list
List accounts, presets and web-service availability.
-provider key <name> <key>
Add a key to an account's ring. This changes credentials.
-provider keys <name>
Inspect masked key metadata.
-provider dropkey <name> <n>
Remove the numbered credential after reviewing its identity.
-provider default <name>
Choose the fallback provider for new sessions; this is not a switch for every existing conversation.
-provider remove <name>
Remove provider configuration. Do not assume every retained credential is securely erased.
-provider test <name>
Send a real, potentially billed request to test the account.
-provider models <name>
Query the account's model catalog. Makes a network request.
-provider dryrun <name> [model]
Preview a request without sending it. The preview can include private context; do not share it wholesale.
-provider timeout <name> <seconds>
Set an optional account request timeout, 5–3600 seconds; default removes the override.
-provider new-store --yes
Set an unreadable credential pair aside and start empty. Use only after a deliberate recovery decision; every key must be added again.
-model list · -model set <id>
List or select a model for the chosen workspace.

Sessions and storage

-session · -resume <id>
Open the picker (or list when piped) or resume a known session.
-session rename <id> <title>
Rename one session.
-session delete <id>
Permanently delete one session. Review its identity first.
-storage [list|prune]
Inspect project storage or remove eligible data belonging to projects no longer present.
-sandbox [setup|reset]
Inspect Windows command-isolation state, explicitly set up its dedicated account, or remove Rune's sandbox access/account setup. Other platforms do not use that setup.

Extensions and diagnostics

-skills [operation]
List, show, enable, disable, install or reload reusable guides. Installation takes a reviewed folder or zip and places it in the current project unless --scope user makes it personal.
-mcp [operation]
Manage, approve, validate and test external tool definitions. A connection can start a process or contact a remote service; validation alone is not a successful connection.
--scope user|project|private-project
Choose the supported configuration scope for a capability change. Shared project changes affect other readers of that project.
-doctor
Run diagnostics, including connectivity checks. It can make network requests; review the output before sharing.
-db <path>
Use an alternate engine store. This is separate from choosing an entire settings home with RUNE_HOME.
-host
Use line-delimited JSON for frontend integration, not the interactive UI. It is not a public network server.
-script <file>
Replay a written model script. A script can propose real tools, so never run an unreviewed one against live work.

For capability setup and access, continue with Skills or MCP connections. Do not switch to Full or delete local data simply to work around an error.
