Conversation and application

Enter · Alt+Enter
Send the message, or insert a newline. Modified Return combinations depend on what the terminal reports.
Ctrl+G · Ctrl+O
Open Settings, or toggle the side panel.
Ctrl+T · Ctrl+R
Open the plan, or expand/refold steps and thoughts. Ctrl+R in the session picker instead opens rename.
Alt+T
Cycle the selected model's available reasoning choices.
Tab
Complete a slash command or cycle permission mode. Forms keep their own Tab navigation.
Esc twice
Stop active AI work: the first press shows a confirmation, the second within 3 seconds stops. An idle view closes with Esc.
Ctrl+C twice
Leave Rune. The first press arms leaving; it does not cancel a turn or clear the draft.
Ctrl+L · Ctrl+↓
Repaint the screen, or jump to the latest chat.

Text editing

These bindings are shared by the composer, editable answers, Settings fields, model search, MCP fields and session search/rename. Lists and buttons have their own navigation. A logical line ends at an inserted newline; a visual row can be a soft wrap.

KeyAction
← / →Move by one visible character.
Ctrl+← / Ctrl+→Move to the previous whitespace-delimited word / end of the next word.
↑ / ↓Move through visual rows, retaining the desired column.

Ctrl+Y / Alt+YYank the most recent kill / cycle the preceding kill immediately after a yank.

Alt+U / Alt+L / Alt+VUppercase / lowercase / capitalize the following word or selected text.

Typing, pasting or deleting replaces a selection. Temporary undo and killed text belong to that field, are bounded, and are cleared when the field or session changes. They are not file backups. Rune does not provide the complete Readline alias set; for example Ctrl+B/F and Alt+B/F are not alternative motion bindings.

History and reading

In the composer, Up/Down first navigate visible text, then reach the beginning/end, then recall prompt history. PgUp/PgDn recall history directly. History belongs to the session.

A wheel notch moves the configured number of rows, two by default. Ctrl+wheel or Alt+wheel goes three times as far when the terminal forwards it. A terminal can reserve these gestures for zoom or horizontal scrolling; ordinary wheel and keys remain available.

Mouse

A click places the text cursor or activates a control. Drag over text and release to copy it: the highlight disappears once the text is on your clipboard. A drag in the conversation copies only that pane, without the side panel or Rune's box borders, and tables copy as tab-separated cells. Copying a collapsed command gives back its original line breaks, without the ↵ and … display marks. In an input field a drag copies without moving the cursor or replacing your draft; select text for editing with Shift and the arrow keys. Masked secret fields are never copied.

The terminal must allow clipboard writes for a copy to arrive; SSH or a multiplexer can block them. Shift+drag, where the terminal supports it, uses the terminal's own selection instead, borders included. With ui.mouse = false all selection belongs to the terminal.

Click a link to open its REFERENCE panel: Enter opens a web address in your browser, C copies the complete destination and Esc closes the panel. Dragging across a link copies text and never opens it.

Lists and forms

Arrows select and Enter opens or confirms. Tab/Shift+Tab move focus. Esc cancels an editor or goes back one level. In Models, Ctrl+F focuses search, Alt+C opens model configuration, T tests with a real request and Delete removes the selected result's local configuration.

In question forms, Alt+Left/Right switches questions. Plain Left/Right edits text or selects buttons. Page keys read an overflowing card; they do not submit an answer. Up/Down inside a custom answer first navigate its text before leaving it. Mouse drags select text rather than activating the control underneath.

Terminal differences

A shortcut only works if the terminal reports it. Operating-system shortcuts, terminal profiles and traditional control encodings can reserve combinations. Backgrounds, blur and transparency also belong to the terminal, not Rune. Consult /help for the installed build rather than assuming a shell keymap applies.
