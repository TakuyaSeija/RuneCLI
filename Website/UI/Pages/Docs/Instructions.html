Project guidance

AGENTS.md at the workspace root supplies project guidance: build commands, conventions and boundaries relevant to the work. It is not an API-key file, a permission grant or the classifier policy. Keep credentials out, and only include text you intend to send as model context.

The factory automatic-instruction allowance is 32,768 characters, controlled by instructions.max_chars in Settings → Tools → Project instructions. When a file exceeds the allowance, Rune reports the part it left out, and the AI reads the rest before relying on those rules; the rest of the file has not ceased to exist. If guidance changes during a session, Rune can notify the model to reread the relevant source.

Attach the intended file

/attach <path> adds a file to the next message; /detach <number|all> removes pending attachments. Check the pending list before sending. A model may support text, images or other media differently; the presence of a file does not prove its contents can be understood.

A sent attachment identifies the version of the file that was sent. Editing the path later must not turn an old message into the new bytes. When the original content cannot be recovered, Rune reports that the file changed or disappeared rather than presenting new content as old. Attach the new version explicitly when that is what the task needs.

Factory limits include 60,000 text characters per attached text file and up to ten historical attachments. Context and provider payload limits can remove older media sooner. These are separate from the current message's attachments and from the visible transcript fold.

Project memory

Rune supports durable project notes with a MEMORY.md index. The model receives the index, not every note automatically, and reads a relevant note when needed. The index recall budget is 20 KiB by default; increasing it uses more model context but does not improve the truth of the notes.

Use memory for stable decisions, corrections and ongoing work. Do not store credentials or every temporary command result. Notes can be included in later model requests and are not a separate permission source. The model accesses project memory through file tools using @memory/, not by creating a memory directory inside your repository.

Keep the purposes separate

AGENTS.md
Project guidance supplied as model context.
CLASSIFIER.md
Your policy for applicable AI action review. It has explicit reload behavior and is not the same as guidance.
rune.toml
Settings in the selected Rune home. A similarly named file in a project is not automatically the global settings file.
Skill
A reusable guide activated or read for a task. It cannot grant access by itself.

Repository text, a web page or a tool response can contain misleading instructions. Treat their content as task data, and review actions at the permission boundary rather than trusting a document's claim that approval already exists.
