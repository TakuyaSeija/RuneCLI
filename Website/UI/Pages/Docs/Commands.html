Using commands

Type / in the composer to search the palette. Choose with the arrow keys, complete with Tab, and execute with Enter. Arguments in square brackets are optional; angle brackets describe a value you supply, not text to type literally. /help is the installed build's authority.

Session and context

/new
Start a fresh conversation in this workspace. It does not delete the current session.
/session
Open the searchable session picker for this workspace.
/resume <id>
Resume a particular stored session.
/compact
Summarize older context. This can make a model request and lose historical detail; it does not clear disk storage.
/context
Inspect context supplied to the model. Treat its content as private work when sharing.
/logs [all|warn|error]
Open diagnostic events, optionally filtered by severity. Failed requests and retries belong here; the view is not permission to retry or change accounts.

Model and permissions

/model [provider:id|id]
Select a provider/model pair, or open Models with no argument. An ambiguous model ID is best selected through its provider in the list.
/provider [name]
Choose the answering provider; no name opens the list. This changes where subsequent work can be sent.
/thinking [off|effort]
Inspect or select reasoning from this model's available choices. Alt+T cycles choices. Off is a request, not proof that an upstream route uses zero reasoning.
/mode [ask|auto|full]
Cycle or explicitly set the session's permission mode. Full grants broad autonomy; do not use it merely to silence a failure.
/classifier [on|off|model|reload]
Inspect or configure policy review. Reload adopts policy for an idle session; an enabled switch alone does not prove review is active.
/set key=value
Change a supported model/session control, for example /set temperature=0.2. Clearing an optional value, such as /set temperature=, returns control to the default/provider.

Files and capabilities

/attach path
Add a file to the next message. Review pending attachments before sending; supported content goes to the selected provider.
/detach number|all
Remove one pending attachment by number or remove all pending attachments.
/undo
Preview and restore eligible files to before this session first changed them. Current external edits can be overwritten.
/redo
Preview and restore what the latest undo replaced. It is not an unlimited backup history.
/skills [list|show|enable|disable|reload]
Manage available guides. Show, enable and disable take the listed skill's ID. Reload refreshes the catalog after edits.
/skill <id>
Activate one guide for the conversation. Activation does not grant every action described by that guide.
/mcp [list|add|connect|status]
Manage external tool connections. Review the server, destination and access before adding or connecting; a local server can start code.

Views and application

/settings
Open Settings. /* is an alias; Ctrl+G is the keyboard shortcut.
/theme [name]
Choose violet, cyan or amber. The terminal's own background and transparency remain terminal preferences.
/panel
Toggle the conversation side panel. Narrow terminals may still hide it.
/verbose
Expand or refold tool steps and thoughts. This does not increase a tool's returned-output cap.
/help
Read the current build's command and keyboard reference.
/quit
Leave Rune. Closing the last window stops active AI work; retained background tasks have a separate lifetime.

Shell commands such as rune -config belong in your terminal, not in the slash palette. See the command-line reference for those. To run a shell command from the composer yourself, start the input with !; see Manual commands.
