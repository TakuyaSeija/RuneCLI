What RuneAgent does

RuneAgent is a coding agent that runs in your terminal. You describe a result; a model proposes work, and RuneAgent reads files, runs tools and shows their results in the same conversation. It works with the model account you connect, not an included subscription or a model supplied by Atoryn.

The program and session data live on your computer. This does not mean every task is offline: your selected provider receives the prompts, context and supported attachments needed for its requests. Commands and connected services can also use the network. Read Privacy & data before working with sensitive material.

Start in a project

Install RuneAgent with the command on the home page; Install & update explains each step. Then open the folder you intend RuneAgent to work on. Start with a small, version-controlled project and review its existing changes first.

cd path/to/your-workspace
rune

You can also pass the folder directly with rune path/to/your-workspace. The working folder defines the workspace for file access, session selection and project guidance. Starting in your entire home folder grants a much wider workspace than starting in one repository.

Connect and select a model

  1. Press Ctrl+G and open Connections → Add connection.
  2. Choose the intended model provider. Review the destination, enter any required address and use the masked API-key field. Connecting makes a real request and may be billable.
  3. Open Models, choose the connected provider, and select a model with Enter. Browsing or searching alone does not switch the session.
  4. Check the model name and permission mode beside the composer before sending work.

A provider preset is setup information, not access to an account. Available models depend on the account, endpoint and catalog. See Model providers, Connections and Models & capabilities.

Give one bounded task

Start in Ask, the default mode. Reads within the workspace can proceed; edits and commands ask for approval. A useful request names an outcome, constraints and a way to check it:

Find why the importer accepts a blank date. Explain the cause, add a regression test, and show me the proposed fix before running commands.

Read the actual command, file path or diff on each permission card. An approval belongs to its stated scope; it is not a general promise that the work is safe. Press Esc twice to stop active AI work. You can send a clarification while the agent works; it is handled at a subsequent step rather than rewriting a request already in flight.

Review the result

Read the final report and tool outcomes, inspect the changed files, and verify the result yourself. A model can misunderstand a task or claim more than the tests prove. The side panel shows actual tracked file differences, while /logs and /context help explain failures and context.

/undo can restore an eligible file to its pre-session state. It cannot reverse a deployment, a message sent to a service, or every external side effect. Treat it as a file-restoration tool, not a replacement for Git or backups.
