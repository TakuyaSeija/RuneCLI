Une seule installation. Votre propre espace de travail.

Inspectez l’installateur, vérifiez votre système, puis connectez le compte de modèle que vous comptez utiliser.

01

Vérifiez votre système

L’installateur détecte votre système et votre processeur, ainsi que la bibliothèque C sous Linux (glibc ou musl). Il n’installe qu’une version signée publiée pour cette combinaison.{{with .Latest}} La ligne sous chaque commande d’installation indique ce que contient la version {{.Version}}.{{end}}

Linux et macOS nécessitent curl, tar, gzip et openssl (inclus par défaut sur macOS) ; Windows nécessite uniquement PowerShell. macOS 11 ou version ultérieure et Windows 10 version 1809 ou ultérieure sont pris en charge, tous deux en version bêta. Sous Linux et macOS, exécutez l’installateur avec votre compte utilisateur normal, sans root ; sous Windows, aucun droit d’administrateur n’est requis.

02

Vérifiez avant d’installer

La commande d’installation ci-dessus vérifie la signature et la somme de contrôle de l’archive avant de remplacer le programme.

Lisez le code source de l’installateur, install.sh ou install.ps1, avant de l’exécuter. Pour l’examiner hors ligne, enregistrez le script, inspectez-le, puis lancez sh install.sh, ou .\install.ps1 dans PowerShell.

03

Ouvrez votre projet

cd path/to/your-workspace
rune

Connectez votre compte de modèle dans Settings → Connections, puis sélectionnez un modèle dans Models. Démarrez en mode Ask et passez en revue chaque commande ou modification.

Découvrir votre première session

Ce qui change sur votre machine

Un seul programme
Rune est placé dans ~/.local/bin/rune, ou .local\bin\rune.exe dans votre profil sous Windows. Aucun accès root ou Administrateur n’est requis.
Votre shell reste intact
Votre profil shell n’est jamais modifié. Si ce dossier ne figure pas dans votre PATH, l’installateur lie Rune dans un dossier qui y figure et vous l’indique, ou affiche la ligne qui permet de l’exécuter dans la fenêtre déjà ouverte. Sous Windows, il ajoute le dossier à votre PATH utilisateur, si bien que les nouvelles fenêtres trouvent aussi Rune.
Avis de licence
Enregistrés à côté de vos autres données utilisateur, dans ~/.local/share/runeagent, ou %LOCALAPPDATA%\RuneAgent sous Windows.
Vos données Rune
Les paramètres, les sessions et les clés chiffrées résident dans un seul dossier de données de votre répertoire personnel, créé au premier lancement de Rune.
Votre propre accès aux modèles
Utilisez un compte de fournisseur ou un point de terminaison local compatible. Rune n’inclut aucun crédit API.

Options de l’installateur

L’installateur indique le dossier utilisé et ne modifie jamais un profil shell. Exécutez la ligne ci-dessous dans la fenêtre déjà ouverte et rune y fonctionne aussitôt ; aucun nouveau terminal n’est nécessaire. Pour la conserver dans les terminaux ouverts plus tard, ajoutez vous-même la même ligne à ~/.bashrc ou ~/.zshrc :

export PATH="$HOME/.local/bin:$PATH"

Sous fish, exécutez une seule fois fish_add_path ~/.local/bin. Sous Windows, la page Installation et mise à jour indique la commande PowerShell ; l’installateur ajoute déjà le dossier, si bien que les nouvelles fenêtres trouvent rune aussitôt.

Désinstaller Rune

Terminez ou arrêtez votre travail et fermez toutes les fenêtres Rune, puis supprimez le programme et ses avis de licence. Utilisez votre propre dossier au lieu de ~/.local/bin si vous en aviez choisi un autre.

rm ~/.local/bin/rune
rm -r ~/.local/share/runeagent

Sous Windows, la page Installation et mise à jour détaille les étapes PowerShell, y compris le retrait des accès accordés au bac à sable de commandes de Rune. Vos paramètres, sessions, clés chiffrées et données de restauration restent dans le dossier de données de Rune jusqu’à ce que vous le supprimiez vous-même. Son emplacement figure sur la première ligne affichée par rune -config ; relevez-le avant de supprimer le programme. La suppression de ce dossier entraîne la perte de votre historique et de vos points de restauration, et n’est pas nécessaire pour une simple désinstallation.
