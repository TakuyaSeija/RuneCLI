Chaque paramètre que vous pouvez modifier dans Rune {{.DocVersion}}, regroupé selon la structure de rune.toml : une ligne dans Settings ou une clé du fichier. Chaque entrée indique la valeur par défaut, le rôle du paramètre, les valeurs acceptées et le moment où une modification prend effet. Les constantes propres à Rune — les valeurs qui le font fonctionner — ne sont pas des paramètres : elles ne peuvent pas être modifiées et ne figurent pas ici.

La valeur par défaut s’applique tant que vous n’avez pas choisi autre chose ; vos propres choix s’affichent avec rune -config explain <key>. Réinitialisez un choix avec rune -config reset <key>. Les durées et les tailles exigent leurs unités, telles que "2m" ou "16MiB" ; voir Fichier de configuration pour le format des valeurs.
