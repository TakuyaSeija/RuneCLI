Une compétence est un guide

Une compétence (skill) regroupe des instructions et des références réutilisables pour accomplir une tâche. Ce n’est pas un octroi d’autorisation d’exécution. L’agent peut découvrir une compétence pertinente et lire son fichier SKILL.md, ou vous pouvez en activer une explicitement dans la conversation. Relisez toujours les conseils et les scripts provenant d’autres auteurs avant de les suivre.

Découvrir et utiliser

/skills list
Liste les guides disponibles et leurs identifiants exacts.
/skills show <id>
Lit les informations d’un guide.
/skill <id>
Active un guide pour cette conversation. Son texte ne peut ni approuver des actions sans rapport ni contourner les contrôles d’exécution.
/skills enable|disable <id>
Modifie la disponibilité pour le projet courant ; cela ne désinstalle pas le guide pour tous les utilisateurs ou projets.
/skills reload
Rafraîchit le catalogue après des modifications. Relisez un guide modifié avant de vous y fier.

Emplacements et installation

Un guide de projet réside dans .rune/skills/<name>/SKILL.md ; les guides de projet portables peuvent utiliser .agents/skills/. Les guides personnels résident dans le sous-dossier skills du répertoire de données Rune sélectionné, ainsi que dans l’emplacement personnel portable lorsqu’il est activé.

La commande rune -skills install <folder-or-zip> installe un paquet vérifié dans le dossier .rune/skills/ du projet courant, afin qu’il reste attaché au projet qu’il sert sans se mélanger aux autres projets ; il est partagé avec toutes les personnes qui utilisent les fichiers du projet, y compris via un dépôt Git. Ajoutez --scope user pour en faire un guide personnel proposé dans tous vos projets. La commande rune -skills update <folder-or-zip> remplace une copie installée dans la portée choisie de la même façon et ne conserve aucune copie de la version précédente : gardez donc votre source ou utilisez un gestionnaire de versions. Chaque paquet possède son propre nom en minuscules et un dossier correspondant, un fichier SKILL.md contenant les métadonnées name et description, ainsi que des fichiers de référence relatifs facultatifs. Toute installation ou mise à jour doit résulter d’un choix délibéré plutôt que d’une confiance aveugle dans un texte téléchargé.

Ce que l’IA voit de vos compétences

L’IA ne reçoit pas l’intégralité de chaque guide d’emblée. Elle reçoit un court catalogue des compétences disponibles, comprenant leur nom et leur description sur une ligne, et ne lit un guide complet que lorsqu’elle en a besoin. Ce catalogue est limité à 8 KiB de texte par défaut (skills.max_catalog_size) ; une compétence qui dépasse cette place reste découvrable, de sorte que l’IA peut toujours la chercher et la lire. Cette limite est une taille en octets, et non un nombre de jetons de modèle. Si vous avez enregistré une valeur capabilities.catalog_bytes, celle-ci prévaut.

Modifiez cette limite avec rune -config set skills.max_catalog_size 16KiB et revenez à la valeur par défaut avec rune -config reset skills.max_catalog_size. Un catalogue plus volumineux consomme davantage de contexte de modèle à chaque requête.

Aide officielle hors ligne

Rune intègre d’office la compétence settings-guide ; elle ne nécessite ni téléchargement supplémentaire ni compte de service. Ce texte officiel géré par l’application est réparé automatiquement s’il est modifié ou endommagé. Placez vos personnalisations dans une compétence personnelle ou de projet distincte plutôt que de modifier cette copie gérée.

Le nom rune-settings-guide est réservé à cette aide intégrée : aucun paquet ne peut être installé ou mis à jour sous ce nom, et aucune autre copie portant ce nom ne prend sa place (la liste affiche une telle copie comme masquée, shadowed). D’autres guides portant un même nom peuvent provenir de portées différentes, la copie du projet ayant alors la priorité. Utilisez l’identifiant exact affiché dans la liste pour les distinguer. Désactiver les capacités ou ce guide rend l’aide officielle indisponible, sans que cela signifie que le binaire installé est dépourvu de la fonctionnalité.
