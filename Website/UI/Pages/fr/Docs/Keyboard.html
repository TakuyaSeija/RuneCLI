Conversation et application

Enter · Alt+Enter
Envoie le message ou insère un retour à la ligne. Les combinaisons utilisant la touche Entrée dépendent de ce que transmet le terminal.
Ctrl+G · Ctrl+O
Ouvre Settings, ou affiche/masque le panneau latéral.
Ctrl+T · Ctrl+R
Ouvre le plan, ou déplie/replie les étapes et les réflexions. Dans le sélecteur de session, Ctrl+R ouvre le renommage.
Alt+T
Fait défiler les niveaux de raisonnement disponibles pour le modèle sélectionné.
Tab
Complète une commande slash ou fait défiler le mode d’autorisation. Les formulaires conservent leur propre navigation par tabulation.
Esc deux fois
Arrête le travail actif de l’IA : le premier appui affiche une demande de confirmation, le second dans les 3 secondes arrête l’exécution. Lorsqu’aucun travail n’est en cours, Esc ferme la vue active.
Ctrl+C deux fois
Quitte Rune. Le premier appui prépare la sortie ; il n’annule pas un tour et n’efface pas votre brouillon.
Ctrl+L · Ctrl+↓
Redessine l’écran, ou revient au message le plus récent.

Édition de texte

Ces raccourcis sont partagés par le compositeur, les réponses modifiables, les champs de Settings, la recherche de modèles, les champs MCP ainsi que la recherche et le renommage de sessions. Les listes et les boutons possèdent leur propre navigation. Une ligne logique se termine par un retour à la ligne inséré ; une ligne visuelle peut résulter d’un retour à la ligne automatique.

Taper, coller ou supprimer remplace une sélection. L’historique d’annulation temporaire et l’anneau de texte coupé sont propres à ce champ, bornés et effacés lorsque vous changez de champ ou de session. Ils ne constituent pas des sauvegardes de fichiers. Rune n’implémente pas l’intégralité des alias Readline ; par exemple, Ctrl+B/F et Alt+B/F ne servent pas de raccourcis de déplacement alternatifs.

Historique et lecture

Dans le compositeur, les touches Haut/Bas parcourent d’abord le texte visible, atteignent le début ou la fin, puis rappellent l’historique des invites. PgUp/PgDn rappellent directement l’historique. Cet historique est propre à la session.

Un cran de molette fait défiler le nombre de lignes configuré, deux par défaut. Ctrl+molette ou Alt+molette défile trois fois plus vite lorsque le terminal transmet l’événement. Un terminal peut réserver ces gestes au zoom ou au défilement horizontal ; la molette simple et le clavier restent toujours disponibles.

Souris

Un clic place le curseur texte ou active un contrôle. Glissez sur du texte et relâchez pour le copier : la surbrillance disparaît dès que le texte se trouve dans votre presse-papiers. Un glisser dans la conversation copie uniquement ce volet, sans le panneau latéral ni les bordures d’encadrés de Rune, et les tableaux sont copiés sous forme de cellules séparées par des tabulations. Copier une commande repliée restitue ses retours à la ligne d’origine, sans les repères d’affichage ↵ et …. Dans un champ de saisie, un glisser copie sans déplacer le curseur ni remplacer votre brouillon ; sélectionnez du texte pour le modifier avec Shift et les touches fléchées. Les champs de secrets masqués ne sont jamais copiés.

Le terminal doit autoriser l’écriture dans le presse-papiers pour que la copie aboutisse ; SSH ou un multiplexeur peuvent la bloquer. Shift+glisser, lorsque le terminal le prend en charge, utilise la sélection native du terminal, bordures comprises. Avec ui.mouse = false, toute sélection relève du terminal.

Cliquez sur un lien pour ouvrir son panneau REFERENCE : Enter ouvre une adresse Web dans votre navigateur, C copie la destination complète et Esc ferme le panneau. Glisser sur un lien copie son texte sans jamais l’ouvrir.

Listes et formulaires

Les flèches sélectionnent et Enter ouvre ou confirme. Tab/Shift+Tab déplacent le focus. Esc annule un éditeur ou remonte d’un niveau. Dans Models, Ctrl+F place le focus sur la recherche, Alt+C ouvre la configuration du modèle, T teste le modèle avec une vraie requête et Delete supprime la configuration locale du résultat sélectionné.

Dans les formulaires de questions, Alt+Gauche/Droite passe d’une question à l’autre. Gauche/Droite seul modifie le texte ou sélectionne les boutons. Les touches Page permettent de lire une carte qui dépasse la hauteur disponible ; elles n’envoient pas la réponse. Haut/Bas dans une réponse personnalisée parcourt d’abord son texte avant d’en sortir. Glisser à la souris sélectionne le texte au lieu d’activer le contrôle situé en dessous.

Différences selon les terminaux

Un raccourci ne fonctionne que si le terminal le transmet. Les raccourcis du système d’exploitation, les profils de terminal et les encodages de contrôle traditionnels peuvent réserver certaines combinaisons. Les arrière-plans, le flou et la transparence relèvent également du terminal, et non de Rune. Consultez /help pour la version installée plutôt que de supposer que les raccourcis de votre shell s’appliquent.
