Emplacement et portée

La configuration globale se trouve dans le fichier rune.toml du répertoire de données Rune sélectionné, normalement ~/.rune/. La Référence des paramètres répertorie toutes les clés qu’il peut contenir. La variable RUNE_HOME permet de choisir un autre répertoire de données. Un fichier nommé rune.toml situé dans un projet n’est pas automatiquement le fichier de paramètres, et l’option -project choisit un espace de travail plutôt qu’un répertoire de paramètres.

Utilisez rune -config pour connaître l’emplacement exact utilisé. Le fichier contient vos choix enregistrés ; les valeurs absentes héritent des valeurs par défaut de la version actuelle. La clé de premier niveau version = 1 décrit le format de configuration, et non la version de l’application. Ne la modifiez pas pour demander une mise à niveau.

Inspecter un élément à la fois

-config explain <key>
Lit la valeur effective d’une clé, sa description et le moment où elle s’applique.
-config defaults
Lit les valeurs par défaut indépendamment de vos choix enregistrés.
-config check
Valide la syntaxe de la configuration et les valeurs prises en charge. Cette commande ne teste ni les clés API, ni le crédit, ni la connectivité.
-config show
Inspecte la configuration effective. Elle peut contenir des métadonnées de compte privées ; masquez-les avant tout partage.
-settings
Inspecte les réglages du modèle pour l’espace de travail sélectionné.

Modifier et réinitialiser

rune -config explain terminal.command_timeout
rune -config set terminal.command_timeout 2m
rune -config reset terminal.command_timeout
rune -config check

N’exécutez la commande set que lorsque vous souhaitez réellement appliquer ce changement global. La commande reset supprime le remplacement ; elle n’écrit pas une copie de la valeur par défaut. Dans Settings, l’action Use default joue le même rôle pour les valeurs globales. Les clés inconnues ou obsolètes produisent des erreurs et ne sont pas traitées en silence comme des alias.

Le format TOML n’a pas de valeur null native. Supprimez une clé facultative ou utilisez la commande reset prise en charge au lieu d’écrire null. Ne supposez pas qu’une chaîne vide, « auto », « none » ou une liste vide équivaut à une réinitialisation pour chaque paramètre.

Types et unités

Booléen
true ou false, sans guillemets en TOML.
Nombre / jetons
Un nombre entier compris dans la plage acceptée par le paramètre. Les jetons, les caractères et les octets sont des unités de mesure distinctes.
Durée
Une chaîne avec unité explicite telle que "500ms", "60s" ou "2m". Seuls les délais d’attente d’autorisation ou de question acceptent une valeur illimitée.
Taille
Utilisez des unités binaires explicites telles que "16MiB". Une taille sans unité est interprétée en KiB, et non en octets.
Liste
Utilisez les entrées exactes documentées. [] représente une sélection explicitement vide, et pas nécessairement une réinitialisation.
[terminal]
command_timeout = "2m"

[generation]
temperature = 0.2
stop = ["END,EXACT", "STOP"]

Cet exemple illustre la syntaxe et ne constitue pas une configuration universelle recommandée. Le tableau stop conserve les chaînes exactes, virgules comprises ; l’éditeur de session accepte quant à lui des entrées séparées par des virgules. Les valeurs globales de génération par défaut n’écrasent pas toutes les sessions en cours.

Moment d’application et risques

Les modifications se propagent normalement sans redémarrage. Utilisez explain pour le paramètre concerné : les valeurs immédiates et celles qui s’appliquent à la prochaine opération n’ont pas le même comportement. Modifier CLASSIFIER.md ne recharge pas une politique de session déjà figée ; utilisez l’action de rechargement lorsque la session est inactive.

N’incluez jamais de points de terminaison privés ni d’identifiants dans des exemples publics. Validez vos modifications manuelles sans écraser d’autres choix sans rapport. Des limites plus élevées peuvent augmenter l’utilisation de la mémoire, du disque, du contexte et les coûts ; elles n’accordent aucun droit d’accès et ne rendent pas compatible un modèle non pris en charge.
