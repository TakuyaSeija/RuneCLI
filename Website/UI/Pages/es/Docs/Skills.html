Una skill es una guía

Una skill empaqueta instrucciones y referencias reutilizables para una tarea. No es una concesión de permisos de ejecución. El agente puede descubrir una skill pertinente y leer su archivo SKILL.md, o bien tú puedes activar una explícitamente en la conversación. Revisa siempre los consejos y scripts de otros autores antes de seguirlos.

Descubrir y usar

/skills list
Lista las guías disponibles y sus identificadores exactos.
/skills show <id>
Muestra la información de una guía concreta.
/skill <id>
Activa una guía para esta conversación. Su texto no puede autorizar acciones no relacionadas ni saltarse los controles de ejecución.
/skills enable|disable <id>
Cambia la disponibilidad para el proyecto actual; esto no la desinstala para todos los usuarios ni en todos los proyectos.
/skills reload
Actualiza el catálogo tras realizar cambios. Vuelve a leer una guía modificada antes de confiar en ella.

Ubicaciones e instalación

Una guía de proyecto reside en .rune/skills/<name>/SKILL.md; las guías portables de proyecto pueden usar .agents/skills/. Las guías personales residen en la carpeta skills del directorio de datos de Rune seleccionado, y también en la ubicación personal portable cuando está habilitada.

rune -skills install <folder-or-zip> instala un paquete revisado en la carpeta .rune/skills/ del proyecto actual, de modo que permanece vinculado al proyecto al que sirve sin mezclarse con otros proyectos, y se comparte con quienes utilicen los archivos de ese proyecto (incluido el repositorio). Añade --scope user para instalarla como guía personal disponible en todos tus proyectos. rune -skills update <folder-or-zip> reemplaza una copia instalada en el ámbito elegido del mismo modo y no conserva copia de la versión anterior, así que guarda el original o utiliza control de versiones. Cada paquete tiene su propio nombre en minúsculas y una carpeta coincidente, un archivo SKILL.md con metadatos de nombre y descripción, y referencias relativas opcionales. Tanto la instalación como las actualizaciones deben hacerse tras revisar el contenido, nunca confiando a ciegas en texto descargado.

Qué ve la IA de tus skills

A la IA no se le entregan todas las guías completas de entrada. Recibe un breve catálogo con las skills disponibles, sus nombres y sus descripciones de una línea, y solo lee una guía completa cuando la necesita. Ese catálogo está limitado a 8 KiB de texto por defecto (skills.max_catalog_size); si una skill no cabe en el resumen inicial, sigue siendo localizable para que la IA pueda buscarla y leerla igualmente. El límite es un tamaño en bytes, no un recuento de tokens del modelo. Si has guardado un valor en capabilities.catalog_bytes, este tendrá prioridad.

Puedes cambiarlo con rune -config set skills.max_catalog_size 16KiB y volver al valor predeterminado con rune -config reset skills.max_catalog_size. Un catálogo mayor consume más contexto del modelo en cada solicitud.

Ayuda oficial sin conexión

Rune incluye de serie la guía de ajustes integrada, sin necesidad de descargas adicionales ni cuentas de servicio. Este texto oficial gestionado se repara automáticamente si se altera o se daña. Coloca tus personalizaciones en una skill personal o de proyecto independiente en lugar de editar esa copia gestionada.

El nombre rune-settings-guide está reservado para esta ayuda: no se puede instalar ni actualizar ningún paquete con ese nombre, y ninguna otra copia llamada así ocupará su lugar (en la lista aparecerá marcada como shadowed). En cambio, otras guías con el mismo nombre pueden proceder de distintos ámbitos, teniendo prioridad la copia del proyecto. Usa el identificador exacto mostrado en la lista para distinguirlas. Desactivar las capacidades o una guía también puede hacer que la ayuda oficial no esté disponible, sin que ello signifique que el binario instalado carezca de esa función.
