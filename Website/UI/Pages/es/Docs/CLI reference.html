Inicio e inspección

Ejecuta estos comandos en la shell de tu sistema operativo. Usa rune -help para consultar tu compilación instalada. Los comandos que contactan con proveedores, modifican cuentas, eliminan datos o inician servidores son operaciones reales, no simples opciones inocuas de diagnóstico.

rune [dir]
Abre el agente interactivo en el espacio de trabajo actual o en el directorio indicado.
rune -p "prompt"
Ejecuta una instrucción única e imprime la respuesta y el progreso de las herramientas sin abrir la interfaz a pantalla completa. Las solicitudes de permiso se rechazan en lugar de aprobarse en silencio cuando no hay nadie para responder.
-project <dir>
Selecciona el espacio de trabajo para otro comando.
-version · -help
Imprime la versión de la aplicación o la referencia de comandos.
-settings · -tools
Inspecciona los controles efectivos del modelo o las herramientas disponibles para el agente.
-read-only
Restringe las herramientas que modifican datos. Esto no garantiza que no se lea ningún archivo ni que no se envíen datos.
--no-color
Desactiva el color. También se admite la variable de entorno NO_COLOR.

Configuración

-config
Muestra la ubicación de los ajustes seleccionados.
-config show|defaults|check
Muestra los valores efectivos, muestra los valores de fábrica o valida el archivo. La opción show puede incluir metadatos privados de cuentas; check no comprueba la conectividad.
-config explain <key>
Explica el valor efectivo de una clave y cuándo se aplica.
-config set <key> <value>
Guarda una preferencia global. Ejemplo: rune -config set terminal.command_timeout 2m.
-config reset <key>
Elimina un valor global personalizado para que vuelva a aplicarse el valor predeterminado actual o la herencia.
-config format
Reorganiza el formato de los ajustes agrupados sin cambiar su significado.
-set key=value
Modifica una preferencia compatible del espacio de trabajo o del modelo, no una clave arbitraria de la configuración global.

Cuentas y modelos

Usa preferiblemente el editor de credenciales ocultas dentro de Connections. Pasar claves reales como argumentos en la línea de comandos puede exponerlas en el historial de la shell y en la lista de procesos. La sintaxis siguiente utiliza marcadores de posición deliberadamente.

rune -provider add <name> -key <key> [-preset <p>] [-base <url>] [-model <id>]
-provider list
Enumera cuentas, perfiles predefinidos y disponibilidad de servicios web.
-provider key <name> <key>
Añade una clave al llavero de una cuenta. Esta acción modifica las credenciales.
-provider keys <name>
Inspecciona los metadatos ocultos de las claves.
-provider dropkey <name> <n>
Elimina la credencial numerada tras revisar su identidad.
-provider default <name>
Elige el proveedor de respaldo para las sesiones nuevas; no cambia el proveedor de todas las conversaciones existentes.
-provider remove <name>
Elimina la configuración del proveedor. No des por sentado que todas las credenciales conservadas se borran de forma irreversible.
-provider test <name>
Envía una solicitud real, potencialmente facturable, para probar la cuenta.
-provider models <name>
Consulta el catálogo de modelos de la cuenta. Realiza una solicitud de red.
-provider dryrun <name> [model]
Previsualiza una solicitud sin enviarla. La vista previa puede contener contexto privado; no la compartas íntegra sin revisarla.
-provider timeout <name> <seconds>
Define un tiempo de espera opcional para las solicitudes de la cuenta, entre 5 y 3.600 segundos; default elimina el valor personalizado.
-provider new-store --yes
Aparta un par de credenciales ilegible y empieza desde cero con un almacén vacío. Úsalo únicamente tras tomar una decisión deliberada de recuperación; tendrás que volver a añadir todas las claves.
-model list · -model set <id>
Lista o selecciona un modelo para el espacio de trabajo elegido.

Sesiones y almacenamiento

-session · -resume <id>
Abre el selector de sesiones (o las lista si se redirige la salida) o reanuda una sesión conocida.
-session rename <id> <title>
Cambia el título de una sesión.
-session delete <id>
Elimina permanentemente una sesión. Comprueba antes su identidad.
-storage [list|prune]
Inspecciona el almacenamiento de proyectos o elimina los datos elegibles pertenecientes a proyectos que ya no existen.
-sandbox [setup|reset]
Inspecciona el estado del aislamiento de comandos en Windows, configura explícitamente su cuenta dedicada o elimina el acceso y la cuenta del entorno aislado de Rune. El resto de plataformas no utilizan esta configuración.

Extensiones y diagnóstico

-skills [operation]
Lista, muestra, activa, desactiva, instala o recarga guías reutilizables. La instalación toma una carpeta o archivo zip revisado y lo coloca en el proyecto actual, salvo que --scope user lo convierta en personal.
-mcp [operation]
Gestiona, aprueba, valida y prueba definiciones de herramientas externas. Una conexión puede iniciar un proceso o contactar con un servicio remoto; la validación por sí sola no implica una conexión establecida.
--scope user|project|private-project
Elige el ámbito de configuración compatible para un cambio de capacidades. Los cambios en el ámbito compartido del proyecto afectan a otros usuarios de ese proyecto.
-doctor
Ejecuta diagnósticos, incluidas comprobaciones de conectividad. Puede realizar solicitudes de red; revisa la salida antes de compartirla.
-db <path>
Utiliza un almacén alternativo para el motor. Es independiente de elegir un directorio completo de ajustes con RUNE_HOME.
-host
Utiliza JSON delimitado por líneas para la integración con interfaces externas, en lugar de la interfaz interactiva. No es un servidor de red público.
-script <file>
Reproduce un guion de modelo escrito. Un guion puede proponer herramientas reales, así que nunca ejecutes uno sin revisar sobre trabajo real.

Para configurar capacidades y permisos de acceso, continúa con Skills o Conexiones MCP. No cambies al modo Full ni borres datos locales simplemente para sortear un error.
