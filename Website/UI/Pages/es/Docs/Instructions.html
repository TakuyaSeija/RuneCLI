Guía del proyecto

El archivo AGENTS.md situado en la raíz del espacio de trabajo proporciona indicaciones sobre el proyecto: comandos de compilación, convenciones y límites pertinentes para la tarea. No es un archivo para guardar claves de API, ni una concesión de permisos, ni la política del clasificador. No incluyas credenciales en él y escribe únicamente el texto que quieras enviar como contexto al modelo.

El límite de fábrica para las instrucciones cargadas automáticamente es de 32.768 caracteres, controlado mediante instructions.max_chars en Settings → Tools → Project instructions. Cuando un archivo supera ese límite, Rune informa de la parte omitida y la IA lee el resto antes de aplicar esas reglas; el resto del archivo no deja de existir. Si la guía cambia durante una sesión, Rune puede avisar al modelo para que vuelva a leer la fuente correspondiente.

Adjunta el archivo adecuado

/attach <path> añade un archivo al siguiente mensaje; /detach <number|all> quita los adjuntos pendientes. Revisa la lista de pendientes antes de enviar. Cada modelo puede admitir texto, imágenes u otros formatos multimedia de forma diferente; que un archivo esté presente no demuestra que el modelo pueda interpretar su contenido.

Un archivo adjunto enviado queda asociado a la versión exacta del archivo que se envió en ese momento. Editar esa ruta más adelante no transforma un mensaje antiguo en los bytes nuevos. Cuando no es posible recuperar el contenido original, Rune informa de que el archivo cambió o desapareció en lugar de hacer pasar el contenido nuevo por antiguo. Vuelve a adjuntar explícitamente la nueva versión cuando la tarea lo requiera.

Los límites de fábrica incluyen 60.000 caracteres de texto por archivo de texto adjunto y hasta diez archivos adjuntos en el historial. Los límites de contexto y de tamaño de carga útil del proveedor pueden descartar antes los elementos multimedia más antiguos. Estos límites son independientes de los archivos adjuntos del mensaje actual y del plegado visual en la transcripción.

Memoria del proyecto

Rune admite notas persistentes por proyecto mediante un índice MEMORY.md; en Memoria se detalla dónde residen las notas y qué información llega al modelo. El modelo recibe el índice, no todas las notas automáticamente, y abre una nota concreta cuando la necesita. El presupuesto de lectura del índice es de 20 KiB por defecto; aumentarlo consume más contexto del modelo, pero no hace que las notas sean más precisas.

Usa la memoria para decisiones estables, correcciones y trabajo en curso. No guardes en ella credenciales ni resultados temporales de cada comando. Las notas pueden incluirse en solicitudes posteriores al modelo y no constituyen una fuente independiente de permisos. El modelo accede a la memoria del proyecto mediante las herramientas de archivos usando el prefijo @memory/, sin crear ninguna carpeta de memoria dentro de tu repositorio.

Mantén separado el propósito de cada archivo

AGENTS.md
Guía del proyecto suministrada como contexto al modelo.
CLASSIFIER.md
Tu política para la revisión de acciones aplicables de la IA. Tiene un comportamiento de recarga explícito y no es lo mismo que la guía del proyecto.
rune.toml
Ajustes guardados en el directorio de datos de Rune seleccionado. Un archivo con el mismo nombre dentro de un proyecto no actúa automáticamente como archivo de configuración global.
Skill
Una guía reutilizable que se activa o se lee para una tarea concreta. Por sí sola no puede conceder permisos de acceso.

El texto de un repositorio, una página web o la respuesta de una herramienta pueden contener instrucciones engañosas. Trata su contenido como datos de trabajo y revisa las acciones en el control de permisos, en lugar de confiar en un documento que afirme que la aprobación ya ha sido concedida.
