Configurar el acceso no equivale a seleccionar

Connections gestiona las direcciones de las cuentas y las claves de API. No elige el modelo actual, el tiempo de espera de las solicitudes al modelo, la ruta de búsqueda web ni el lector de páginas; esos ajustes pertenecen a Models, Runtime y Tools respectivamente.

Configured
Hay una o más claves API guardadas para esta cuenta. No prueba que una solicitud haya funcionado ni que tengas saldo.
Key missing
No hay ninguna clave guardada para esta cuenta en la carpeta de datos activa; añádela en Connections.
Unavailable
El almacén cifrado existe en el disco pero no se puede abrir; restaura la pareja de copia de seguridad correspondiente.

Comprueba el error concreto en /logs en lugar de reemplazar la cuenta una y otra vez.

Añadir una cuenta de modelo

Cada perfil predefinido de proveedor, junto con su clave y dirección, está documentado en Proveedores de modelos.

  1. Abre Settings → Connections → Add connection y elige el proveedor de modelos deseado.
  2. Revisa el formulario, marcado inicialmente como Not connected yet. Un perfil con dirección fija te pedirá la clave; si la dirección depende de la cuenta o es personalizada, deberás indicarla explícitamente.
  3. Comprueba el nombre de la conexión y el nombre de la clave. Introduce los secretos únicamente en el campo de credencial.
  4. Conecta. Rune prueba la nueva cuenta de modelo antes de aceptarla; esa solicitud puede facturarse. Si cancelas, la conexión no se guarda.
  5. Una vez conectada la cuenta, selecciona el par proveedor/modelo correspondiente en Models.

Un perfil predefinido aporta valores iniciales compatibles, pero no es una cuenta, ni un derecho de uso de la API, ni una garantía de que todos los productos del proveedor funcionen. Las suscripciones específicas de un plan y las direcciones regionales pueden diferir de la API estándar de un proveedor.

Añadir una cuenta de servicios web

Elige un proveedor dentro de Search & Fetch, introduce la dirección o clave requerida y guarda la cuenta. Guardar el acceso web por sí solo no activa el proveedor de búsqueda o lectura ni demuestra que funcione. Continúa en Tools → Web search o Web fetch → Provider para añadir, probar y seleccionar el servicio deseado.

La búsqueda y la lectura de páginas tienen selecciones independientes. Una cuenta de modelos locales y el servicio web del mismo proveedor pueden requerir direcciones o claves distintas. Consulta Búsqueda y lectura web.

Editar y eliminar

Abre una conexión existente para cambiar su Base URL o gestionar sus claves con nombre. Los cambios en el punto de conexión de un modelo se prueban antes de aceptarse. Use default restaura la dirección original del perfil del proveedor, sin intentar adivinarla a partir del nombre de la cuenta.

Añadir una clave incorpora una alternativa y no reemplaza automáticamente las demás claves. Revisa el nombre de la clave y su vista previa oculta antes de eliminarla.Al eliminar una conexión, sus credenciales pueden permanecer disponibles para reutilizarse; quitar una cuenta no equivale a un borrado criptográfico seguro.

Destino y pruebas

Cambiar un punto de conexión puede enviar tanto tus credenciales como tus instrucciones a otro tercero. Verifica quién lo gestiona y la región deseada antes de conectar. Los puntos de conexión remotos que usan clave requieren transporte cifrado; un servicio local en tu propia máquina es un caso aparte.

Las pruebas de conexiones y de modelos son solicitudes reales y pueden generar costes. Una prueba de cuenta satisfactoria valida la solicitud probada, no todos los modelos, herramientas, tamaños de contexto o permisos de tu cuenta. Es preferible hacer una prueba pequeña y deliberada tras consultar el error exacto en los registros.
