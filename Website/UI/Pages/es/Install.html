Una sola instalación. Tu propio espacio de trabajo.

Inspecciona el instalador, comprueba tu sistema y conecta la cuenta del modelo que vayas a utilizar.

01

Comprueba tu sistema

El instalador detecta tu sistema operativo y tu procesador y, en Linux, la biblioteca de C (glibc o musl). Solo instala una compilación firmada y publicada para esa combinación.{{with .Latest}} La línea situada bajo cada comando de instalación indica qué incluye la versión {{.Version}}.{{end}}

Linux y macOS requieren curl, tar, gzip y openssl (incluidos de serie en macOS); Windows solo necesita PowerShell. Se admiten macOS 11 o posterior y Windows 10 versión 1809 o posterior, ambos en fase beta. En Linux y macOS ejecuta el instalador con tu usuario habitual, no como root; en Windows no necesita permisos de administrador.

02

Verifica antes de instalar

El comando de instalación anterior verifica la firma y la suma de comprobación del paquete antes de reemplazar el programa.

Lee el código fuente del instalador, install.sh o install.ps1, antes de ejecutarlo. Para revisarlo sin conexión, guarda el script, inspecciónalo y ejecuta sh install.sh, o bien .\install.ps1 en PowerShell.

03

Abre tu proyecto

cd path/to/your-workspace
rune

Conecta tu cuenta de modelo en Settings → Connections y selecciona un modelo en Models. Empieza en el modo Ask y revisa cada comando o edición.

Guía paso a paso para tu primera sesión

Qué cambia en tu equipo

Un único programa
Rune se coloca en ~/.local/bin/rune, o en .local\bin\rune.exe dentro de tu perfil en Windows. No requiere permisos de root ni de administrador.
Tu shell, intacta
Nunca se modifican tu perfil de shell ni tu variable PATH. Si esa carpeta no está en tu PATH, el instalador te lo indica.
Avisos de licencia
Se guardan junto al resto de tus datos de usuario, en ~/.local/share/runeagent o en %LOCALAPPDATA%\RuneAgent en Windows.
Tus datos de Rune
Los ajustes, las sesiones y las claves cifradas residen en una única carpeta de datos dentro de tu directorio personal, que se crea la primera vez que inicias Rune.
Tu propio acceso a modelos
Usa una cuenta de proveedor o un punto de conexión local compatible. Rune no incluye crédito de API.

Opciones del instalador

Las variables de entorno permiten elegir una versión, una ruta absoluta de destino o, en Linux, la biblioteca de C. Si no las defines, se utiliza la última versión publicada, la carpeta bin de tu usuario y la detección automática. Si ya has revisado y guardado el script como install.sh:

RUNE_VERSION=X.Y.Z sh install.sh
RUNE_INSTALL_DIR="$HOME/bin" sh install.sh
RUNE_LIBC=musl sh install.sh

En PowerShell, define primero la variable y luego ejecuta el comando de instalación:

$env:RUNE_VERSION = "X.Y.Z"
irm {{.Origin}}{{url "install.ps1"}} | iex

Sustituye X.Y.Z por una versión publicada. Estos ejemplos son alternativas independientes, no pasos que deban ejecutarse en orden. Si no existe un paquete para tu sistema, procesador o biblioteca, la instalación se rechaza.

Actualizar una instalación existente

Vuelve a ejecutar el instalador para la versión deseada, usando el mismo RUNE_INSTALL_DIR si elegiste uno personalizado. El instalador verifica la descarga y reemplaza el programa en un solo paso. Comprueba después la versión con rune -version.

En Linux y macOS, las sesiones abiertas compatibles adoptan la nueva compilación cuando quedan inactivas; en Windows se utiliza la próxima vez que abras Rune. No fuerces el cierre de tareas activas para actualizar. Mantén copias de seguridad independientes de tus proyectos importantes y de los datos de Rune.

«rune: command not found»

El instalador indica la carpeta que ha utilizado. Ejecuta rune desde allí usando su ruta completa o añade esa carpeta a tu variable PATH manualmente; el instalador nunca modifica tu perfil de shell ni tu PATH. Para la carpeta predeterminada, añade esta línea a ~/.bashrc o ~/.zshrc:

export PATH="$HOME/.local/bin:$PATH"

En fish, ejecuta fish_add_path ~/.local/bin una sola vez. En Windows, consulta la línea correspondiente para PowerShell en Instalación y actualización. Después, abre una terminal nueva.

Desinstalar Rune

Termina o detén tu trabajo y cierra todas las ventanas de Rune; a continuación, elimina el programa y sus avisos de licencia. Usa tu propia carpeta en lugar de ~/.local/bin si elegiste una distinta.

rm ~/.local/bin/rune
rm -r ~/.local/share/runeagent

En Windows, la guía Instalación y actualización detalla los pasos en PowerShell, incluido cómo revocar los permisos del entorno aislado de comandos de Rune. Tus ajustes, sesiones, claves cifradas y datos de restauración permanecen en la carpeta de datos de Rune hasta que la borres manualmente. Su ubicación aparece en la primera línea que imprime rune -config; consúltala antes de eliminar el programa. Si borras esa carpeta perderás tu historial y tus puntos de restauración, y no es necesario hacerlo solo para desinstalar el programa.
