Security

Trust that does not depend on the model behaving.

A model can be wrong, and text it reads can try to mislead it. RuneAgent is built on that assumption: every protection below is enforced by RuneAgent and your operating system, not by instructions to the model.

What stays on your machine

Your code, your conversations, your undo history, your settings and your API keys. RuneAgent has no account, no cloud sync and no Atoryn server it reports to.

What leaves it

Only the requests to the model provider you configured, and web lookups through the services you enabled. Secrets are masked in everything RuneAgent logs or shows.

Everything outside is untrusted

Model output, file contents, web pages and connected tools are all treated as untrusted input. None of them can grant permissions; only you can.

An enforced sandbox

Commands run isolated by the operating system kernel. The project folder is the boundary, private files elsewhere in your home stay out of reach, and contact with local services such as container engines or key agents is held for your approval.

One path for every change

There is exactly one way for the agent to change a file, and it always keeps the original first. That is why every change can be undone, even after a crash.

Keys encrypted at rest

API keys are stored encrypted, readable only by your user account. They are never written to logs, error messages or the screen.

Permissions you can read

Ask, Auto and Full modes decide what runs without asking. In Auto you can add your own written rules that a reviewer model checks every action against.

Signed releases

Every release is signed. The installer checks the signature and every checksum before anything is placed on your system, and refuses on any mismatch.
