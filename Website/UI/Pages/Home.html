Why RuneAgent

An agent you can let work.

Most assistants ask a model to behave. RuneAgent does not have to ask: what the agent may touch is decided by RuneAgent itself, on your machine, before anything runs.

I

Local-first by design

Your repository, history and settings stay on your computer. There is no Atoryn server in between: the only traffic is the request to the model provider you configured.

II

Guardrails that hold

Commands run in an isolated sandbox enforced by the operating system. The project folder is the boundary; reaching beyond it needs your explicit approval.

III

No write without an undo

Before a file is changed, its original is kept. Review what changed, see the diff, and roll back one file or a whole session in a keystroke.

IV

Bring any model

Use Anthropic, any OpenAI-compatible endpoint, a local model or one of more than twenty ready-made provider presets. Switch models without switching tools.

V

Made for long sessions

Builds and servers keep running in the background, interactive prompts are recognised, and new versions take over without closing your work.

VI

Extensible when you need it

Connect tools over the Model Context Protocol, add project skills, and give the agent web search and page reading through services you choose.

Three steps

From install to first change.

Install

One command places a single, signed binary in your home folder. No root, no system changes.

Connect a model

Start rune in your project and add the provider you want. Your API key is stored encrypted on your machine.

Choose the freedom

Pick how much the agent may do on its own, describe the work, and watch every step as it happens.

Permission modes

You decide how far it goes.

Ask

Every action, approved

Reading your project is free. Every edit and every command waits for your yes. The default.

Auto

Trusted inside the project

Edits and sandboxed commands in the project run on their own, still undoable. Anything beyond the project still asks.

Full

Unrestricted, by choice

For the moments you deliberately want no limits. Never the default, always one switch away from Ask.

Ready
