Ein Skill ist eine Anleitung

Ein Skill bündelt wiederverwendbare Anweisungen und Referenzmaterialien für eine bestimmte Art von Aufgabe. Er ist keine ausführbare Berechtigungsfreigabe. Der Agent kann einen passenden Skill selbst finden und dessen SKILL.md lesen, oder du aktivierst ihn gezielt in der Unterhaltung. Prüfe Empfehlungen und Skripte fremder Autoren sorgfältig, bevor du ihnen folgst.

Entdecken und nutzen

/skills list
Listet alle verfügbaren Anleitungen samt ihren exakten IDs auf.
/skills show <id>
Zeigt den Inhalt und die Metadaten einer einzelnen Anleitung an.
/skill <id>
Aktiviert eine Anleitung für diese Unterhaltung. Ihr Text kann weder unbeteiligte Aktionen freigeben noch Ausführungskontrollen außer Kraft setzen.
/skills enable|disable <id>
Ändert die Verfügbarkeit für das aktuelle Projekt; der Skill wird dadurch nicht für alle Benutzer oder Projekte deinstalliert.
/skills reload
Aktualisiert den Katalog nach Dateiänderungen. Lies eine geänderte Anleitung erneut ein, bevor du dich auf sie verlässt.

Speicherorte und Installation

Eine projektspezifische Anleitung liegt unter .rune/skills/<name>/SKILL.md; portierbare Projektanleitungen können .agents/skills/ nutzen. Persönliche Anleitungen liegen im Ordner skills des gewählten Rune-Home-Verzeichnisses (oder am portierbaren persönlichen Speicherort, sofern aktiviert).

rune -skills install <folder-or-zip> installiert ein geprüftes Paket unter .rune/skills/ im aktuellen Projekt, sodass es direkt beim zugehörigen Projekt bleibt und sich nicht mit anderen Projekten vermischt; es wird mit allen geteilt, die mit den Projektdateien bzw. dem Repository arbeiten. Mit dem Zusatz --scope user installierst du es stattdessen als persönliche Anleitung, die in jedem deiner Projekte zur Verfügung steht. rune -skills update <folder-or-zip> ersetzt eine installierte Kopie im gewählten Geltungsbereich auf dieselbe Weise und hebt keine Sicherung der vorherigen Version auf – behalte daher deine Quelldateien oder nutze eine Versionsverwaltung. Jedes Paket besitzt einen eigenen kleingeschriebenen Namen mit passendem Ordnernamen, eine SKILL.md mit Name und Beschreibung sowie optionale relative Referenzdateien. Installiere und aktualisiere Skills stets bewusst, statt heruntergeladenen Texten blind zu vertrauen.

Was die KI von deinen Skills sieht

Der KI wird nicht jede Anleitung vorab im Volltext übergeben. Sie erhält zunächst nur einen kompakten Katalog der verfügbaren Skills mit deren Namen und Kurzbeschreibungen und liest eine vollständige Anleitung erst dann ein, wenn sie diese tatsächlich benötigt. Dieser Katalog ist standardmäßig auf 8 KiB Text begrenzt (skills.max_catalog_size); ein Skill, der nicht mehr hineinpasst, bleibt über die Suche auffindbar, sodass die KI ihn weiterhin entdecken und lesen kann. Das Limit wird in Bytes gemessen, nicht in Modell-Tokens. Hast du einen Wert für capabilities.catalog_bytes gespeichert, hat dieser Vorrang.

Du änderst das Limit mit rune -config set skills.max_catalog_size 16KiB und setzt es mit rune -config reset skills.max_catalog_size auf den Standardwert zurück. Ein größerer Katalog belegt bei jeder Anfrage entsprechend mehr Kontextfenster des Modells.

Offizielle Offline-Hilfe

Rune liefert den Skill settings-guide direkt eingebaut mit; dafür ist weder ein separater Download noch ein Dienstkonto nötig. Wird dieser verwaltete Hilfetext verändert oder beschädigt, stellt Rune ihn automatisch wieder her. Lege eigene Anpassungen daher in einem separaten persönlichen oder projektspezifischen Skill ab, statt die verwaltete Kopie zu bearbeiten.

Der Name rune-settings-guide ist fest für diese integrierte Hilfe reserviert: Unter diesem Namen lässt sich kein eigenes Paket installieren oder aktualisieren, und ein gleichnamiger anderer Skill kann ihn niemals überschreiben (in der Liste wird eine solche Kopie als shadowed markiert). Bei anderen gleichnamigen Anleitungen aus unterschiedlichen Ebenen hat die Projektkopie Vorrang. Nutze zur eindeutigen Unterscheidung die exakt aufgelistete ID. Wenn du Erweiterungen allgemein oder diesen Hilfs-Skill deaktivierst, steht auch die integrierte Offline-Hilfe nicht zur Verfügung – das bedeutet jedoch nicht, dass die Funktion im installierten Programm fehlt.
