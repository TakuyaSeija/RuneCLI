Getting started

Ten minutes to your first session.

Everything you need to begin. Inside RuneAgent, /help explains every screen and setting in detail.

1. Install

Run the command from the install page, then open a new terminal so rune is on your path.

2. Start in your project

cd path/to/your/project
rune

The folder you start in is the project. It is what the agent may read freely and, with your permission, change.

3. Connect a model

Open Settings › Connections and add a model provider: pick a preset or enter any compatible endpoint, then type your API key into its key field. RuneAgent tests the connection before saving it, and stores the key encrypted on your machine. Choose the model under Settings › Models; you can add more providers and switch at any time. Never paste a key into the chat.

4. Choose a mode

  • Ask: every edit and command waits for your approval. Start here.
  • Auto: work inside the project runs on its own, in the sandbox, and stays undoable.
  • Full: no limits, for when you deliberately want them off.

5. Describe the work

Write what you want in plain language. The agent plans, shows each step as it goes, and asks when something is unclear. You can type a follow-up while it works; it is read at the next step.

6. Review and undo

The side panel lists every file changed in the session. /undo shows each change with its diff and restores any of them; /redo brings an undone change back.

One-off tasks

For a single question or a script, run a prompt without opening the interface:

rune -p "summarise what changed in this branch"

Staying current

Run the install command again to update. Open windows and running sessions switch to the new version by themselves when idle; nothing is lost.
