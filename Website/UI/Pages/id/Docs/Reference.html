Setiap pengaturan yang dibaca Rune {{.DocVersion}} dari rune.toml, dikelompokkan persis seperti di dalam berkas konfigurasi. Setiap entri mencantumkan nilai bawaan pabrik, fungsi pengaturan tersebut menurut program, nilai yang diterima, dan kapan perubahan mulai berlaku. Sebagian besar pengaturan memiliki baris di menu Settings; selebihnya diubah melalui perintah rune -config set.

Nilai bawaan pabrik berlaku selama Anda belum menetapkan pilihan sendiri; pilihan efektif Anda dapat diperiksa dengan rune -config explain <key>. Kembalikan suatu pilihan ke bawaan dengan rune -config reset <key>. Nilai durasi dan ukuran wajib menyertakan satuannya, seperti "2m" atau "16MiB"; lihat halaman Berkas konfigurasi untuk format nilai selengkapnya.
