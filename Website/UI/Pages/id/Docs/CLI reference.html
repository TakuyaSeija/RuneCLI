Menjalankan dan memeriksa

Jalankan perintah-perintah ini di shell sistem operasi Anda. Gunakan rune -help untuk melihat referensi biner yang terpasang di mesin Anda. Perintah yang menghubungi penyedia, mengubah akun, menghapus data, atau menjalankan server adalah operasi nyata, bukan sekadar flag diagnostik pasif.

rune [dir]
Membuka agen interaktif di ruang kerja saat ini atau direktori yang diberikan.
rune -p "prompt"
Menjalankan satu prompt lalu mencetak balasan serta kemajuan tool tanpa antarmuka layar penuh. Permintaan izin akan ditolak alih-alih disetujui diam-diam karena tidak ada pengguna yang menjawab secara interaktif.
-project <dir>
Memilih ruang kerja untuk perintah lain.
-version · -help
Mencetak versi aplikasi atau referensi perintah.
-settings · -tools
Memeriksa kontrol model yang berlaku atau daftar tool yang ditawarkan kepada agen.
-read-only
Membatasi tool yang mengubah berkas atau sistem. Flag ini bukan jaminan bahwa tidak ada berkas yang dibaca atau tidak ada data yang dikirim.
--no-color
Menonaktifkan warna. Variabel lingkungan NO_COLOR juga didukung.

Konfigurasi

-config
Menampilkan lokasi berkas pengaturan yang dipilih.
-config show|defaults|check
Menampilkan nilai efektif, menampilkan nilai bawaan pabrik, atau memvalidasi berkas konfigurasi. Keluaran show dapat memuat metadata akun pribadi; check tidak menguji koneksi jaringan.
-config explain <key>
Menjelaskan nilai efektif suatu kunci beserta waktu berlakunya.
-config set <key> <value>
Menyimpan satu pilihan global. Contoh: rune -config set terminal.command_timeout 2m.
-config reset <key>
Menghapus penimpaan global sehingga nilai bawaan atau pewarisan kembali berlaku.
-config format
Merapikan format pengelompokan pengaturan tanpa mengubah artinya.
-set key=value
Mengubah preferensi ruang kerja/model yang didukung, bukan sembarang kunci konfigurasi global.

Akun dan model

Utamakan editor kredensial bertopeng di menu Connections. Menuliskan kunci asli pada argumen baris perintah dapat bocor melalui riwayat shell dan daftar proses sistem. Sintaks di bawah ini sengaja menggunakan penampung (placeholder).

rune -provider add <name> -key <key> [-preset <p>] [-base <url>] [-model <id>]
-provider list
Mencantumkan akun, preset, dan ketersediaan layanan web.
-provider key <name> <key>
Menambahkan kunci ke rangkaian kunci akun. Perintah ini mengubah kredensial.
-provider keys <name>
Memeriksa metadata kunci dalam keadaan disamarkan.
-provider dropkey <name> <n>
Menghapus kredensial bernomor tersebut setelah Anda memeriksa identitasnya.
-provider default <name>
Memilih penyedia cadangan untuk sesi baru; perintah ini tidak mengganti penyedia pada setiap percakapan yang sudah ada.
-provider remove <name>
Menghapus konfigurasi penyedia. Jangan berasumsi bahwa setiap kredensial yang tersimpan ikut terhapus secara permanen.
-provider test <name>
Mengirim permintaan nyata (yang mungkin dikenai biaya) untuk menguji akun.
-provider models <name>
Mengambil katalog model dari akun tersebut. Melakukan permintaan jaringan.
-provider dryrun <name> [model]
Menampilkan pratinjau permintaan tanpa mengirimkannya. Pratinjau dapat memuat konteks pribadi; jangan membagikannya secara mentah-mentah.
-provider timeout <name> <seconds>
Mengatur batas waktu permintaan opsional untuk akun tersebut, 5–3600 detik; default menghapus penimpaan.
-provider new-store --yes
Menyisihkan pasangan penyimpanan kredensial yang tidak dapat dibaca lalu memulai dari kosong. Gunakan hanya setelah mengambil keputusan pemulihan secara sadar; setiap kunci harus ditambahkan kembali.
-model list · -model set <id>
Mencantumkan atau memilih model untuk ruang kerja yang dipilih.

Sesi dan penyimpanan

-session · -resume <id>
Membuka pemilih sesi (atau mencetak daftar saat dialirkan lewat pipe) atau melanjutkan sesi tertentu.
-session rename <id> <title>
Mengubah nama satu sesi.
-session delete <id>
Menghapus satu sesi secara permanen. Periksa identitas sesi terlebih dahulu.
-storage [list|prune]
Memeriksa penyimpanan proyek atau menghapus data yang memenuhi syarat milik proyek yang foldernya sudah tidak ada.
-sandbox [setup|reset]
Memeriksa status isolasi perintah Windows, menyiapkan akun khususnya secara eksplisit, atau menghapus pengaturan akses/akun sandbox Rune. Platform lain tidak menggunakan pengaturan ini.

Ekstensi dan diagnostik

-skills [operation]
Mencantumkan, menampilkan, mengaktifkan, menonaktifkan, memasang, atau memuat ulang panduan tugas (skill). Pemasangan menerima folder atau arsip zip yang telah Anda tinjau lalu menempatkannya di proyek saat ini kecuali --scope user menjadikannya pribadi.
-mcp [operation]
Mengelola, menyetujui, memvalidasi, dan menguji definisi tool eksternal. Koneksi MCP dapat menjalankan proses lokal atau menghubungi layanan jarak jauh; validasi saja belum berarti koneksi berhasil.
--scope user|project|private-project
Memilih cakupan konfigurasi yang didukung untuk perubahan kapabilitas. Perubahan pada cakupan proyek bersama memengaruhi pengguna lain yang membuka proyek tersebut.
-doctor
Menjalankan diagnostik, termasuk pemeriksaan konektivitas. Perintah ini dapat melakukan permintaan jaringan; tinjau keluarannya sebelum dibagikan.
-db <path>
Menggunakan berkas penyimpanan mesin alternatif. Ini terpisah dari pemilihan folder home pengaturan secara keseluruhan dengan RUNE_HOME.
-host
Menggunakan JSON per baris untuk integrasi antarmuka eksternal, bukan antarmuka interaktif. Mode ini bukan server jaringan publik.
-script <file>
Memutar ulang skrip model tertulis. Skrip dapat mengusulkan pemanggilan tool nyata, jadi jangan pernah menjalankan skrip yang belum ditinjau pada pekerjaan asli.

Untuk penyiapan kapabilitas dan akses, lanjutkan ke Skill atau Koneksi MCP. Jangan beralih ke mode Full atau menghapus data lokal hanya untuk mengakali suatu galat.
