Lokasi dan cakupan

Konfigurasi global disimpan di rune.toml dalam folder home data Rune yang dipilih, biasanya ~/.rune/. Halaman Referensi pengaturan mencantumkan setiap kunci yang dapat dimuatnya. Variabel RUNE_HOME memilih folder home yang berbeda. Berkas bernama rune.toml di dalam folder proyek tidak otomatis menjadi berkas pengaturan, dan flag -project memilih ruang kerja, bukan folder home pengaturan.

Gunakan rune -config untuk melihat lokasi sebenarnya. Berkas ini menyimpan pilihan yang Anda tetapkan; nilai yang tidak dicantumkan akan mewarisi nilai bawaan saat ini. Baris tingkat atas version = 1 menjelaskan versi format konfigurasi, bukan versi aplikasi. Jangan mengubah angka tersebut untuk meminta pembaruan aplikasi.

Periksa satu per satu

-config explain <key>
Membaca nilai efektif suatu kunci, penjelasannya, serta kapan perubahannya berlaku.
-config defaults
Membaca nilai bawaan pabrik secara terpisah dari pilihan yang Anda simpan.
-config check
Memvalidasi sintaks konfigurasi dan nilai yang didukung. Perintah ini tidak menguji kunci API, saldo kredit, maupun konektivitas jaringan.
-config show
Memeriksa konfigurasi efektif saat ini. Keluarannya dapat memuat metadata akun pribadi; samarkan bagian sensitif sebelum dibagikan.
-settings
Memeriksa kontrol model untuk ruang kerja yang dipilih.

Mengubah dan mengatur ulang

rune -config explain terminal.command_timeout
rune -config set terminal.command_timeout 2m
rune -config reset terminal.command_timeout
rune -config check

Jalankan perintah set hanya bila Anda benar-benar menginginkan perubahan global tersebut. Perintah reset menghapus penimpaan yang tersimpan, bukan menuliskan salinan nilai bawaan ke dalam berkas. Di menu Settings, tombol Use default memiliki fungsi yang sama untuk nilai global. Kunci yang tidak dikenal atau sudah tidak dipakai lagi akan dilaporkan sebagai galat, bukan dianggap sebagai alias secara diam-diam.

Format TOML tidak memiliki tipe null bawaan. Hapus kunci opsional yang bersangkutan atau gunakan perintah reset yang didukung alih-alih menulis null. Jangan berasumsi bahwa string kosong, “auto”, “none”, atau daftar kosong berarti reset untuk setiap pengaturan.

Tipe nilai dan satuan

Boolean
true atau false, ditulis tanpa tanda kutip di TOML.
Jumlah / token
Bilangan bulat di dalam rentang yang didukung pengaturan tersebut. Token, karakter, dan byte adalah satuan ukuran yang berbeda.
Durasi
String dengan satuan eksplisit seperti "500ms", "60s", atau "2m". Hanya waktu tunggu izin/pertanyaan yang menerima nilai tak terbatas (unlimited).
Ukuran
Gunakan satuan biner eksplisit seperti "16MiB". Angka ukuran tanpa satuan ditafsirkan sebagai KiB, bukan byte.
Daftar (List)
Gunakan entri persis seperti yang terdokumentasi. [] adalah pilihan daftar kosong secara eksplisit, belum tentu berarti reset.
[terminal]
command_timeout = "2m"

[generation]
temperature = 0.2
stop = ["END,EXACT", "STOP"]

Contoh di atas adalah panduan sintaks, bukan rekomendasi konfigurasi umum. Array stop di TOML mempertahankan string persis apa adanya, termasuk tanda koma di dalamnya; sebaliknya, editor sesi menerima entri yang dipisahkan dengan koma. Nilai bawaan generasi global tidak menimpa seluruh sesi yang sudah ada.

Waktu berlaku dan risiko

Perubahan pengaturan umumnya langsung diterapkan tanpa perlu memulai ulang aplikasi. Gunakan explain untuk memeriksa kunci tertentu: nilai yang langsung berlaku (live) dan nilai yang berlaku pada operasi berikutnya memiliki waktu penerapan yang berbeda. Mengedit CLASSIFIER.md tidak otomatis memuat ulang kebijakan yang sudah dikunci pada sesi aktif; gunakan tindakan muat ulang saat sesi sedang diam.

Jangan sertakan endpoint akun dan kredensial dalam contoh publik. Validasi pengeditan manual tanpa menimpa pilihan lain yang tidak berkaitan. Menaikkan batas dapat meningkatkan pemakaian memori, disk, konteks, dan biaya; namun tidak memberikan izin akses baru atau membuat model yang tidak didukung menjadi berfungsi.
