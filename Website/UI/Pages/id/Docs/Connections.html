Akses bukan pemilihan model

Menu Connections mengelola alamat akun dan kunci API. Menu ini tidak memilih model yang sedang dipakai, batas waktu permintaan model, jalur pencarian web, maupun pembaca halaman web. Pengaturan tersebut masing-masing berada di Models, Runtime, dan Tools.

Configured
Satu atau beberapa kunci API telah tersimpan untuk akun ini. Status ini belum membuktikan permintaan nyata berhasil atau saldo kredit tersedia.
Key missing
Belum ada kunci yang disimpan untuk akun ini di folder data aktif; tambahkan melalui Connections.
Unavailable
Penyimpanan kredensial terenkripsi ada di disk tetapi tidak dapat dibuka; pulihkan pasangan cadangan yang cocok sebelum melakukan perubahan.

Periksa pesan galat sebenarnya di /logs alih-alih berulang kali menghapus dan membuat ulang akun.

Menambahkan akun model

Setiap preset penyedia, lengkap dengan format kunci dan alamatnya, tercantum di halaman Penyedia model.

  1. Buka Settings → Connections → Add connection lalu pilih penyedia model yang diinginkan.
  2. Periksa formulir yang awalnya ditandai Not connected yet. Preset dengan alamat tetap hanya meminta kunci API; alamat yang bergantung pada akun atau alamat kustom harus diisi secara eksplisit.
  3. Periksa nama koneksi dan nama kunci. Masukkan rahasia hanya pada kolom kredensial.
  4. Pilih Connect. Rune menguji akun model baru sebelum menerimanya; permintaan uji ini dapat dikenai biaya oleh penyedia. Tombol Cancel membatalkan penambahan tanpa menyimpannya.
  5. Setelah tersambung, pilih pasangan penyedia/model yang ingin digunakan di menu Models.

Preset menyediakan nilai bawaan penyiapan yang kompatibel. Preset bukanlah akun, kuota API, atau jaminan bahwa semua produk dari penyedia tersebut dapat dipakai. Langganan khusus paket tertentu dan alamat regional dapat berbeda dari API standar milik vendor.

Menambahkan akun layanan web

Pilih vendor di bawah Search & Fetch, masukkan alamat atau kunci yang diperlukan, lalu simpan akun. Menyimpan akses layanan web saja belum mengaktifkan atau membuktikan bahwa penyedia pencarian/pembaca halaman tersebut berfungsi. Lanjutkan ke Tools → Web search atau Web fetch → Provider untuk menambahkan, menguji, dan memilih layanan yang diinginkan.

Pencarian web dan pengambilan halaman memiliki pilihan penyedia yang terpisah. Akun model lokal dan layanan web dari vendor yang sama mungkin memerlukan alamat atau kunci yang berbeda. Lihat Pencarian & pengambilan web.

Mengedit dan menghapus

Buka koneksi yang sudah ada untuk mengubah Base URL atau mengelola kunci bernama. Perubahan endpoint model akan diuji terlebih dahulu sebelum diterima. Opsi Use default memulihkan alamat bawaan penyedia, bukan menebak alamat dari nama akun.

Menambahkan kunci baru berarti menambah alternatif; langkah ini tidak otomatis menggantikan semua kunci yang sudah ada. Periksa nama kunci dan pratinjau bertopengnya sebelum menghapus. Menghapus koneksi dapat meninggalkan kredensialnya tetap tersedia untuk dipakai kembali; penghapusan akun bukanlah jaminan penghapusan kriptografis secara permanen.

Tujuan jaringan dan pengujian

Mengubah endpoint dapat mengirim kredensial sekaligus prompt Anda ke pihak lain. Pastikan kepemilikan layanan dan wilayah (region) yang dituju sebelum menyambungkan. Endpoint jarak jauh yang memakai kunci mewajibkan jalur terenkripsi (HTTPS); endpoint di mesin lokal adalah kasus terpisah.

Pengujian koneksi dan model adalah permintaan nyata yang dapat menimbulkan biaya. Pengujian akun yang berhasil hanya membuktikan permintaan uji tersebut berhasil, bukan menjamin setiap model, perangkat, panjang konteks, atau kuota lainnya. Gunakan pengujian kecil secara terarah setelah memeriksa pesan galat di log.
