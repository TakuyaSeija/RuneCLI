Membuka dan bernavigasi

Tekan Ctrl+G, ketik /settings, atau gunakan aliasnya /*. Halaman ringkasan menautkan keenam bagian pengaturan. Gunakan tombol panah untuk memilih baris atau kartu, lalu tekan Enter untuk membukanya. Tombol Tab/Shift+Tab memindahkan fokus, dan Esc membatalkan pengeditan atau kembali satu tingkat. Baris kaki menjelaskan fungsi kontrol yang sedang dipilih.

Buka sebuah nilai, ubah isinya, lalu pilih Apply. Tombol Cancel mempertahankan nilai sebelumnya. Beberapa baris pilihan langsung menyimpan perubahan saat Anda menekan tombol Left/Right; baca petunjuk di layar dan tunggu pesan berhasil muncul. Sekadar menyorot item di dalam daftar pemilih terpisah belum berarti menerapkannya.

Satu tempat khusus untuk setiap pengaturan

Models
Menelusuri model dari akun yang dikonfigurasikan, memilih pasangan penyedia/model, menyegarkan katalog, serta mengatur kapabilitas permanen dan informasi harga melalui Alt+C.
Generation
Mengatur penalaran, sampling, dan batas keluaran untuk sesi saat ini. Kontrol model bantu (auxiliary) yang bersifat global berada di bagian bawah halaman yang sama.
Connections
Mengelola akses akun: alamat API dan kunci bernama. Menu ini tidak memilih penyedia pencarian web aktif maupun batas waktu permintaan model.
Runtime
Mengatur batas waktu permintaan model, perilaku percobaan ulang (retry), rotasi cincin kunci, serta waktu tunggu sambungan dan aliran data.
Tools
Mengatur waktu tunggu khusus tool, batas keluaran dan ruang kerja, tenggat waktu pertanyaan dan kartu izin, serta pemilihan penyedia layanan web secara terpisah.
Appearance
Mengatur tema warna dan preferensi panel samping percakapan. Menu ini tidak mengatur gambar latar, efek blur, maupun transparansi terminal.

Pilihan global dan pilihan sesi

Batas tool, pengaturan percobaan ulang dan jaringan, serta pilihan model bantu berlaku secara global untuk folder home Rune yang dipilih. Sebaliknya, kontrol utama di bagian atas Generation dan pemilihan model berlaku untuk sesi atau model yang sedang aktif. Preferensi model yang disimpan akan diingat kembali saat Anda memilih model tersebut di lain waktu.

Tabel [generation] di berkas konfigurasi global menyediakan nilai awal bawaan untuk sesi baru, bukan instruksi untuk menimpa setiap sesi yang sudah berjalan. Pengaturan New-session fallback memilih penyedia awal untuk sesi mendatang, bukan mengganti penyedia di semua percakapan yang sedang terbuka.

Pengaturan ulang dan waktu berlaku

Opsi Use default menghapus penimpaan global yang tersimpan sehingga nilai bawaan versi aplikasi atau pewarisan kembali berlaku. Menyimpan angka yang kebetulan sama dengan nilai bawaan pabrik tetap dicatat sebagai pilihan eksplisit, berbeda dengan membiarkan kunci tersebut kosong. Untuk nilai opsional sesi di menu Generation, mengosongkan kolom akan mengembalikan kendali ke penyedia atau nilai bawaan.

Perubahan pengaturan umumnya langsung berlaku tanpa perlu memulai ulang Rune. Beberapa komponen langsung menerapkan nilai baru seketika; komponen lain memakainya pada operasi berikutnya sementara pekerjaan yang sedang berjalan tetap menyelesaikan langkahnya dengan pengaturan awal. Gunakan perintah rune -config explain <key> untuk melihat rincian kunci tertentu. Kebijakan pengklasifikasi memiliki tindakan muat ulang eksplisit tersendiri.

Periksa sebelum mengubah

Konfigurasi yang valid secara sintaks belum membuktikan bahwa koneksi jaringan berfungsi, dan status Configured belum membuktikan bahwa akun memiliki saldo kredit. Pengujian koneksi mengirim permintaan nyata yang dapat dikenai biaya. Mengganti penyedia dapat mengubah ke mana data Anda dikirim; menaikkan batas percobaan ulang atau batas keluaran dapat meningkatkan pengeluaran.

Tidak semua opsi lanjutan memiliki baris pengaturan di antarmuka menu. Halaman Berkas konfigurasi menjelaskan cara memeriksa dan mengatur ulang opsi-opsi tersebut tanpa mengarang nama kunci atau menimpa pilihan lain yang tidak berkaitan.
