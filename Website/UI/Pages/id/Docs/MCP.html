Kapabilitas eksternal

MCP menyambungkan server eksternal yang menyediakan tool, sumber daya, atau prompt. Gunakan /mcp atau rune -mcp; fitur ini tidak berada di tab tersendiri pada menu Settings saat ini. Menyambungkan server berbeda dengan menyetujui setiap tugas yang dijalankan melalui perangkatnya.

Server jarak jauh menerima data yang Anda kirimkan kepadanya. Server lokal menjalankan kode program di komputer ini. Teks yang dikembalikan oleh server MCP diperlakukan sebagai data tugas yang tidak dipercaya begitu saja, bahkan jika teks tersebut mengklaim berisi instruksi resmi.

Cakupan dan persetujuan

User
Definisi pribadi yang tersedia lintas proyek Anda.
Project
Definisi bersama di dalam berkas konfigurasi MCP proyek. Tinjau dan setujui secara eksplisit; definisi bersama yang berubah memerlukan persetujuan ulang.
Private project
Definisi pribadi khusus untuk satu proyek, yang menjadi cakupan bawaan saat Anda mengubah pengaturan MCP. Cakupan ini dapat menimpa definisi proyek bersama dengan ID yang sama, dan definisi proyek bersama dapat menimpa definisi pengguna pribadi.

Periksa dengan perintah list/status dan validasi definisinya sebelum menyambungkan. Validasi sintaks bukanlah pengujian koneksi langsung. Perintah add menerima ID server beserta URL jarak jauh atau path absolut program lokal lengkap dengan argumennya. Lihat bantuan perintah pada versi yang terpasang untuk sintaks lengkap setiap operasi.

Meninjau hak akses

Sebelum menambahkan atau mengaktifkan sebuah server, periksa program/argumennya atau alamat tujuan jarak jauhnya, cara autentikasinya, variabel lingkungannya, izin tulis ke proyek, folder baca/tulis tambahan, serta aksesnya ke layanan lokal yang sedang berjalan. Berikan hanya hak akses yang benar-benar dibutuhkan untuk tugas tersebut.

Endpoint jarak jauh mewajibkan HTTPS; HTTP biasa hanya diizinkan untuk alamat loopback lokal. Jangan menanamkan rahasia secara langsung di dalam URL bersama atau nilai variabel lingkungan mentah. Gunakan alur kredensial yang didukung. Program lokal dan folder tambahan adalah keputusan pemberian akses nyata, bukan sekadar label deskriptif.

Folder tambahan di luar ruang kerja dapat meminta persetujuan dalam mode Ask/Auto sebelum server lokal dijalankan. Akses luas ke layanan lokal dapat menjangkau program lain yang berjalan dengan hak akun pengguna Anda. Jangan memperluas opsi akses ini hanya untuk membungkam kegagalan koneksi.

Menyambungkan, menguji, dan menghapus

list · status
Memeriksa server yang dikonfigurasikan beserta status koneksinya saat ini.
validate
Memeriksa keabsahan definisi tanpa mengklaim koneksi telah berhasil.
connect <id> · test <id>
Melakukan koneksi nyata, yang dapat menjalankan kode lokal atau menghubungi layanan jarak jauh.
approve <id>
Menyetujui definisi proyek bersama yang telah Anda tinjau. Jangan memberikan persetujuan untuk berkas yang belum Anda periksa isinya.
disconnect <id>
Menutup koneksi yang sedang aktif tanpa menghapus definisi yang tersimpan.
enable|disable|remove <id>
Mengubah ketersediaan definisi yang dimaksud atau menghapusnya, sesuai cakupan konfigurasi yang dipilih.
reload
Menyegarkan daftar koneksi yang telah dikonfigurasikan.
login <id> · login-status <id>
Memulai alur autentikasi yang didukung atau memeriksa status masuknya.

Operasi-operasi ini dijalankan setelah rune -mcp, misalnya rune -mcp status. Periksa cakupan dan ID yang dipilih pada setiap perubahan. Perintah kredensial lanjutan seperti token/secret menerima nilai sensitif; utamakan antarmuka autentikasi yang didukung agar rahasia tidak tercatat di riwayat shell.

Autentikasi dapat menggunakan kredensial bearer atau alur OAuth. Jangan menempelkan token ke dalam percakapan chat. Server yang berhasil tersambung bukan bukti bahwa setiap perangkat di dalamnya aman, dapat dibatalkan perubahannya, atau didukung sepenuhnya. Model akan membaca skema masukan tool yang sebenarnya dan tetap melewati kontrol eksekusi normal, bukan mengarang API sendiri.
