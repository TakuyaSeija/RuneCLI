Kumpulkan bukti terkecil yang relevan

Catat keluaran rune -version, pesan galat persisnya, status pada baris kaki, perintah atau pengaturan yang terdampak, serta apakah masalah terjadi pada satu sesi saja atau di semua sesi. Baca entri /logs yang relevan dan periksa pengaturan terkait menggunakan subperintah explain. Samarkan kode atau data pribadi sebelum membagikannya.

rune -version
rune -config check
rune -config explain network.stream_idle_timeout

Perintah-perintah di atas hanya memeriksa versi dan berkas konfigurasi lokal. Berkas konfigurasi yang valid belum membuktikan bahwa koneksi ke penyedia berfungsi. Perintah -doctor, pengujian penyedia, dan pengujian model dapat melakukan permintaan jaringan nyata.

Masalah pemasangan

rune: command not found
Skrip pemasang menampilkan nama folder tempat biner disimpan. Jalankan rune menggunakan path lengkapnya dari sana, atau tambahkan folder tersebut ke PATH Anda seperti yang ditunjukkan pada halaman Pasang & perbarui, lalu buka terminal baru.
No build for your system
Rilis saat ini tidak menyediakan biner bertanda tangan untuk kombinasi sistem operasi, prosesor, atau pustaka C tersebut. Baris di bawah perintah pemasangan pada halaman pemasangan menyebutkan biner apa saja yang tersedia. Tidak ada berkas yang dipasang ke sistem Anda.
SIGNATURE CHECK FAILED atau CHECKSUM MISMATCH
Berkas yang terunduh tidak cocok dengan rilis resmi yang diterbitkan. Tidak ada yang dipasang; jangan gunakan berkas unduhan tersebut. Coba lagi nanti melalui jaringan yang Anda percaya, dan laporkan jika masalah terus berulang.
Run as your normal user
Di Linux dan macOS, skrip pemasang menolak dijalankan sebagai root karena program dipasang ke dalam folder home pengguna Anda sendiri. Buka terminal biasa tanpa sudo lalu jalankan kembali. Di Windows, PowerShell Administrator tidak diperlukan; program dipasang ke dalam profil akun pengguna yang menjalankan jendela tersebut.
Program tidak dapat berjalan di sistem ini
Versi sistem operasi lebih lama dari batas minimum yang didukung Rune, atau arsitektur prosesornya tidak cocok. Halaman Dukungan platform mencantumkan versi sistem yang didukung.

Pintasan tombol, mouse, warna, dan penyalinan

Pintasan papan ketik yang tidak bereaksi biasanya ditahan oleh aplikasi terminal Anda. Konsole menggunakan Ctrl+wheel untuk memperbesar tampilan kecuali profilnya diubah, dan beberapa terminal mengubah Alt+wheel menjadi guliran mendatar; jalankan /help untuk melihat pintasan yang dikenali Rune. Warna yang tampak kurang terbaca pada latar terang atau gelap biasanya terjadi karena terminal tidak melaporkan warna latarnya: atur variabel lingkungan RUNE_THEME ke dark, light, atau kode warna hex.

Di Linux, penyalinan teks berjalan melalui terminal sehingga terminal harus mengizinkan program mengisi papan klip; saat memakai SSH atau di dalam tmux, izin tersebut sering kali mati secara bawaan. Aktifkan di pengaturan terminal (untuk tmux gunakan set -g set-clipboard on), atau tahan tombol Shift sambil menyeret mouse untuk memakai pemilihan teks bawaan terminal.

Perintah terus meminta izin dalam mode Auto

Mode Auto hanya menjalankan perintah tanpa bertanya apabila perintah tersebut dapat dibatasi di dalam sandbox. Pada sistem yang tidak menyediakan fasilitas sandbox—misalnya kernel Linux versi lama—setiap perintah akan meminta izin terlebih dahulu; periksa bagian This machine di dalam /help untuk melihat apakah sandbox aktif. Di Windows tanpa akun sandbox khusus Rune, Git Bash serta program berbasis MSYS2 atau Cygwin akan meminta izin sebelum setiap perintah dijalankan; jalankan rune -sandbox untuk melihat statusnya dan rune -sandbox setup untuk menyiapkan akun sandbox tersebut. Selain itu, perintah yang mencoba menghubungi layanan lokal yang sudah berjalan di komputer Anda (seperti daemon container atau agen kunci SSH) juga akan meminta izin secara terpisah.

Perintah latar belakang tampak macet

Baca laporan status dan berkas log perintah tersebut sebelum menghentikannya atau mengirim ketikan masukan. Di Linux, Rune dapat mendeteksi saat perintah menunggu ketikan masukan. Namun macOS hanya melaporkan masukan tersembunyi seperti prompt kata sandi, dan Windows tidak melaporkannya sama sekali—sehingga perintah yang tampak diam di kedua sistem tersebut bisa jadi sedang menunggu jawaban atau memang masih bekerja. Jangan pernah menebak kata sandi atau mengirim konfirmasi hanya karena sebuah perintah tampak diam. Menutup seluruh jendela Rune akan mengakhiri perintah latar belakang setelah masa tenggang sesi tanpa jendela (60 detik secara bawaan) berakhir.

Model melaporkan ukuran konteks terlalu besar

Rune meringkas riwayat lama secara otomatis berdasarkan laporan pemakaian token dari penyedia, atau setelah penyedia menolak permintaan karena melebihi kapasitas konteks. Jika tidak ada lagi bagian riwayat lama yang dapat diringkas dengan aman, pesan galat dari penyedia akan ditampilkan dan permintaan yang sama tidak dikirim ulang. Periksa ukuran jendela konteks model di Models → Alt+C, mulai sesi baru dengan /new untuk tugas yang tidak berkaitan, atau jalankan /compact. Jika model bantu perangkum berukuran kecil menolak satu batch ringkasan, turunkan nilai compact.max_batch_size.

Kunci API tidak tersedia

Status Key missing berarti folder data saat ini belum menyimpan kunci untuk akun tersebut; tambahkan kuncinya di menu Connections. Status Unavailable berarti penyimpanan terenkripsi ada tetapi tidak dapat dibuka, misalnya karena berkas materi kuncinya hilang atau berasal dari pasangan cadangan yang berbeda. Pulihkan pasangan cadangan yang cocok terlebih dahulu. Memulai penyimpanan kredensial baru (new-store) akan menyisihkan penyimpanan lama dan mengharuskan semua kunci dimasukkan kembali dari awal; gunakan hanya sebagai langkah pemulihan terakhir, bukan untuk pengujian rutin. Halaman Kredensial menjelaskan arti setiap status tersebut.

Pesan tampak menunggu tanpa kemajuan

Bedakan antara pesan yang sedang mengantre giliran, kartu izin atau pertanyaan yang belum Anda jawab, proses generasi aktif yang sedang berpikir, hitung mundur percobaan ulang (retry), dan proses peringkasan (Compacting). Kolom tulis yang kosong saja tidak menunjukkan status mana yang sedang terjadi. Hindari mengirim pesan “Lanjutkan” berulang-ulang sebagai cara mendiagnosis, karena setiap pesan tersebut akan menjadi antrean tugas tambahan.

Aliran respons yang lambat tetapi masih berjalan berbeda dengan aliran yang terputus tanpa data. Periksa batas waktu yang dilaporkan di log sebelum mengubah pengaturannya. Perintah terminal yang berpindah ke latar belakang juga bukan berarti perintah tersebut gagal atau mati; periksa laporan status tugasnya.

Akun atau model gagal merespons

Periksa kembali pasangan penyedia/model yang dipilih beserta alamat endpoint-nya. Status Key missing, Unavailable, dan Resting memiliki penyebab yang berbeda. Tercantumnya nama model di katalog belum menjamin akun Anda memiliki kuota untuk model tersebut, dan adanya kata tertentu pada ID model tidak membuktikan mode penalaran tertentu pasti didukung.

Percobaan ulang otomatis tidak akan memperbaiki kunci API yang salah atau parameter yang tidak didukung. Baca pesan galat spesifiknya di log terlebih dahulu; jangan terburu-buru merombak penyimpanan kredensial, mengganti penyedia, atau menjalankan pengujian berbayar berulang kali tanpa alasan yang jelas.

Keluaran atau hasil pencarian terpotong

Bedakan antara lipatan tampilan empat baris di layar, batas karakter keluaran yang dikembalikan ke AI, pencarian yang berhenti karena mencapai batas pemindaian, dan meluapnya jendela konteks model. Klik kotak untuk membuka lipatan tampilan, baca pemberitahuan keluaran tersimpan jika ada, lalu persempit rentang baris atau direktori pencarian. Pencarian yang terhenti karena mencapai batas bukan berarti tidak ada kecocokan lain di sisa proyek.

Ukuran jendela konteks bukanlah batas panjang balasan maksimum. Menaikkan angka kapabilitas di pengaturan lokal tidak dapat memperbesar batas sebenarnya di server penyedia. Sebaliknya, menurunkan batas keluaran terlalu rendah dapat membuat jawaban akhir terpotong habis oleh proses penalaran.

Status kebijakan atau layanan web tampak tidak sesuai

Sakelar Classifier yang berstatus Enabled belum tentu berarti peninjauan sedang aktif: periksa mode izin sesi saat ini, keabsahan berkas kebijakan, daftar pengecualian perangkat, serta apakah kebijakan perlu dimuat ulang saat sesi sedang diam. Evaluasi kebijakan yang gagal tidak pernah dianggap sebagai persetujuan. Penyedia layanan web yang dipilih secara eksplisit namun sedang tidak tersedia akan dilaporkan gagal, bukan dialihkan diam-diam ke layanan pihak ketiga lain.

Pencarian web dan pengambilan halaman memiliki pilihan penyedia yang terpisah. Menyimpan akun layanan web di menu Connections belum memilihnya sebagai penyedia aktif; pilih penyedianya di bawah menu Tools.

Setelah memperbarui versi

Di Linux dan macOS, sesi terbuka yang kompatibel dapat beralih sendiri ke biner baru saat sedang diam tanpa perlu ditutup paksa. Di Windows, jendela yang sedang terbuka tetap berjalan pada versi awalnya, sedangkan jendela Rune baru yang dibuka setelahnya akan menggunakan versi baru. Jika suatu sesi gagal dilanjutkan karena alasan tertentu, jangan langsung menghapus sesi tersebut.

Jika Rune melaporkan bahwa struktur datanya belum dapat diperbarui, perbaiki prasyarat yang disebutkan—seperti sisa ruang disk atau izin tulis folder—lalu coba kembali. Jika satu item dilaporkan tidak berubah, jangan berasumsi seluruh item lainnya ikut gagal. Jangan pernah menghapus berkas runtime yang sedang aktif, mematikan peninjauan kebijakan, beralih ke mode Full, atau menghapus seluruh folder penyimpanan hanya sebagai jalan pintas tanpa memeriksa penyebabnya.
