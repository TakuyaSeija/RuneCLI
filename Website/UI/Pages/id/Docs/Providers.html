Menambahkan penyedia

Penyedia (provider) adalah akun layanan yang menjawab permintaan model dari Rune. Rune tidak menyertakan akun bawaan maupun saldo kredit API sendiri: setiap permintaan dikirim langsung ke penyedia yang Anda sambungkan dan ditagih oleh penyedia tersebut.

  1. Tekan Ctrl+G, buka Connections, lalu pilih Add connection.
  2. Di bawah MODEL PROVIDERS, pilih preset untuk penyedia Anda, atau pilih compatible untuk endpoint lain yang kompatibel dengan format OpenAI.
  3. Jika preset tidak memiliki alamat tetap, masukkan alamat endpoint Anda terlebih dahulu. Setelah itu, tempelkan kunci API ke kolom bertopeng lalu tekan Enter.
  4. Rune mengirim satu permintaan nyata untuk memeriksa akun sebelum menyimpan koneksi. Permintaan uji tersebut dapat dikenai biaya dan mengirim teks pengujian singkat ke penyedia.
  5. Buka Models, pilih penyedia tersebut, lalu pilih model dengan menekan Enter.

Tersimpannya koneksi membuktikan bahwa akun tersebut berhasil menjawab satu kali pengujian. Hal itu belum membuktikan bahwa setiap model di dalam daftar penyedia tersebut tersedia untuk paket akun Anda. Kunci API disimpan dalam keadaan terenkripsi di komputer Anda; lihat Kredensial.

Catatan khusus per penyedia

Kontrol penalaran berbeda-beda menurut penyedia dan modelnya. Catatan di bawah ini menjelaskan apa yang dikirimkan oleh Rune; penyedia tetap dapat menyesuaikan perilaku model di sisi server. Atur pilihan penalaran sebuah model dengan menekan Alt+C di menu Models, sebagaimana dijelaskan di halaman Generasi & penalaran.

alibaba
Gunakan alamat mode kompatibel dari ruang kerja dan wilayah Model Studio Anda, dipasangkan dengan kunci dari wilayah yang sama. Penalaran hanya berupa nyala (on) atau mati (off) tanpa tingkatan. Jangan pernah memilih Off untuk model yang selalu melakukan penalaran karena permintaan akan ditolak. Model keluarga GLM di Model Studio hanya mengembalikan pemanggilan perangkat jika disertai opsi khusus yang tidak dikirim oleh Rune, jadi gunakan model GLM melalui preset Z.ai.
cerebras
Tingkat penalaran berbeda-beda menurut model dan tidak dicantumkan secara otomatis oleh layanan. Model gpt-oss-120b dan qwen-3.8-27b menerima tingkat Low, Medium, dan High; tambahkan ketiganya dengan Alt+C.
cloudflare
Workers AI. Alamat endpoint memuat ID akun Anda, dan kuncinya adalah token API dengan hak akses Workers AI (bukan token Tunnel). Daftar model dibaca langsung dari daftar model akun Anda.
compatible
Endpoint apa pun yang kompatibel dengan format OpenAI. Rune tidak mengasumsikan spesifikasi modelnya: atur ukuran konteks, batas keluaran, dan dukungan penalaran dengan Alt+C sesuai dokumentasi endpoint tersebut.
deepinfra
Daftar modelnya menyertakan informasi harga dan menandai model mana saja yang mendukung penalaran. Tingkatannya adalah Low, Medium, dan High; jika tidak dipilih, nilai bawaan model akan berlaku.
fireworks
Tingkatan penalaran mulai dari Low hingga Max. Untuk model yang hanya mendukung sebagian tingkatan, sesuaikan pilihannya dengan Alt+C.
huggingface
Router Inference Providers, menggunakan token yang memiliki izin memanggil Inference Providers. Penyedia mana yang melayani suatu model dan fitur apa yang didukungnya bergantung pada pasangan model dan penyedia tersebut.
inclusionai
Model keluarga Ling dari InclusionAI melalui Ling API milik Ant Group. Model versi 3.0 dan 3.1 hanya menyalakan atau mematikan penalaran tanpa tingkatan. Server Ling yang Anda jalankan sendiri dapat ditambahkan menggunakan preset compatible.
inference
Daftar modelnya menyebutkan tingkat penalaran untuk setiap model, dan Rune menawarkan pilihan persis seperti yang dilaporkan.
meta
Meta Model API, bukan akun login chatbot Meta AI biasa. Tingkat penalaran mulai dari Minimal hingga Extra high. Model Muse Spark selalu melakukan penalaran serta menolak opsi Off maupun kata penghenti (stop words), jadi biarkan kolom Stop kosong di menu Generation.
mimo
Kunci pay-as-you-go dan kunci Token Plan mengarah ke alamat endpoint yang berbeda; Rune memilih alamat yang tepat secara otomatis berdasarkan awalan kunci yang Anda masukkan.
minimax
Rune meminta isi penalaran dipisahkan dari teks jawaban utama. Hanya MiniMax-M3.1-Flash yang menerima tingkatan (Low hingga Max): tambahkan pilihan tersebut dengan Alt+C. Jangan menawarkan opsi Off untuk model MiniMax.
moonshot
Kimi. Model kimi-k3 menerima tingkat Low, High, dan Max; tambahkan dengan Alt+C. Keluarga model kimi-k2 tidak memakai tingkatan. Jangan menawarkan opsi Off untuk model Kimi.
novita
Penalaran berupa nyala atau mati pada model yang mendukung keduanya, tanpa tingkatan. Informasi harga diambil langsung dari daftar modelnya.
nvidia
Layanan NIM API terkelola. Kontrol penalaran berbeda-beda untuk setiap model dan tidak dicantumkan di katalog layanan; atur per model dengan Alt+C sesuai kartu dokumentasi model yang bersangkutan. Untuk NIM yang di-host sendiri, masukkan alamat server Anda.
openrouter
Satu akun menyediakan banyak model dengan harga dan batas yang beragam. Pilih ID model yang tepat dan periksa harganya saat ini.
siliconflow
Menggunakan alamat global secara bawaan; akun .cn menggunakan alamat dan kuncinya sendiri. Penalaran berupa nyala atau mati pada model yang ditandai oleh SiliconFlow. Model deepseek-ai/DeepSeek-V3.1 hanya dapat memanggil perangkat apabila penalaran dimatikan (off).
stepfun
Tingkat penalaran adalah Low, Medium, dan High. Model step-3.5-flash-2603 hanya menerima Low dan High: hapus opsi Medium untuk model tersebut melalui Alt+C.
tencent
Layanan Hunyuan beralih ke TokenHub: masukkan alamat TokenHub wilayah Anda (ditampilkan di samping kolom alamat) beserta kunci dari wilayah yang sama. Penalaran dapat dinyalakan atau dimatikan, dengan tingkatan Low, Medium, dan High. Beberapa model pihak ketiga yang dilayani melalui TokenHub menolak opsi Off.
together
Daftar modelnya menyertakan harga tetapi tidak mencantumkan tingkat penalaran: tambahkan tingkatan yang terdokumentasi untuk suatu model melalui Alt+C.
tokenrouter
Layanan TokenRouter di tokenrouter.com. Layanan dengan nama serupa pada domain lain adalah perusahaan berbeda yang memiliki alamat sendiri.
zai
API standar Z.ai. Paket Coding Plan memiliki kunci, alamat, dan daftar perangkat yang diizinkan tersendiri. Tingkat penalaran mulai dari Minimal hingga Max; tanpa pilihan eksplisit, nilai bawaan layanan (Max) akan digunakan. Model glm-5.3 selalu melakukan penalaran dan hanya menerima Low, High, serta Max. Layanan ini hanya menerima maksimal satu kata penghenti (stop word).

Model di komputer ini

Ollama melayani model lokal dari komputer ini pada port 11434 tanpa kunci API. Ini adalah layanan yang berbeda dari fitur pencarian web cloud milik Ollama. Model lokal menjaga prompt tetap di mesin Anda, namun perangkat web, tugas model bantu, dan perintah shell tetap dapat menghubungi layanan luar bila digunakan.

9router adalah aplikasi router yang berjalan di komputer Anda (pada port 20128 secara bawaan) dan meneruskan permintaan ke akun-akun hulu yang Anda siapkan di dalamnya. Satu koneksi di Rune melayani seluruh model yang ditawarkan oleh 9router. Untuk model Claude Code (cc/…), Rune secara otomatis memakai jalur bergaya Anthropic milik 9router sehingga angka token cache dan penalarannya tetap tercatat tanpa perlu pengaturan tambahan. Opsi Off bersifat permintaan: bila suatu rute melaporkan bahwa penalaran tidak dapat dimatikan, memilih Off akan meminta tingkat Low sebagai gantinya.

Alamat lokal pada sebuah preset hanyalah nilai bawaan, bukan bukti bahwa layanan lokal tersebut sudah berjalan di mesin Anda. Jalankan layanannya terlebih dahulu; permintaan uji dari Rune akan memberi tahu Anda apakah layanan tersebut merespons.

Kunci dan akun

Satu koneksi dapat menyimpan beberapa kunci API sekaligus. Perintah rune -provider keys <name> mencantumkan daftarnya dalam keadaan disamarkan, dan menu Connections mengelolanya tanpa memperlihatkan teks kunci secara terbuka. Saat sebuah kunci melaporkan saldo tidak mencukupi atau menghabiskan jatahnya, Rune langsung menyerahkan giliran ke kunci berikutnya di dalam cincin; lihat Runtime & percobaan ulang.

Menghapus sebuah koneksi akan menghapus konfigurasinya. Kunci-kuncinya dapat tetap tersimpan di penyimpanan terenkripsi untuk digunakan kembali; hapus kunci secara eksplisit jika Anda memang ingin membuangnya. Kunci API tidak pernah dikirim melalui koneksi HTTP biasa tanpa enkripsi ke mesin lain.

Memilih model

Menu Settings → Models mencantumkan seluruh model yang dikembalikan oleh penyedia Anda yang tersambung, serta dapat menyegarkan katalog tersebut. Pilih satu model dengan Enter, atau ketik /model provider:id di dalam percakapan. Menekan Alt+C pada sebuah model akan mengedit informasi yang diketahui Rune tentang model tersebut: ukuran jendela konteks, batas keluaran, pilihan tingkat penalaran, dan harga. Harga yang Anda masukkan dipakai untuk menghitung angka biaya (Spend) di panel samping, yang merupakan perkiraan lokal dan bukan tagihan resmi dari penyedia.

Pengaturan Models → New-session fallback memilih penyedia awal yang dipakai saat membuka sesi baru. Pengaturan ini tidak mengubah percakapan yang sedang terbuka; gunakan /provider atau /model di dalam sesi untuk menggantinya.
