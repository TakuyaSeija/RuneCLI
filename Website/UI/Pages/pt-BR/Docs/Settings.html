Abrir e navegar

Pressione Ctrl+G, digite /settings ou use o atalho equivalente /*. A visão geral leva a seis seções. As setas direcionais escolhem uma linha ou cartão; Enter o abre. Tab/Shift+Tab movem o foco e Esc cancela uma edição ou volta um nível. O rodapé descreve o controle selecionado.

Abra um valor, edite-o e escolha Apply. Cancel mantém o valor anterior. Algumas linhas de seleção salvam diretamente conforme você alterna com as setas Esquerda/Direita; leia a dica e aguarde a mensagem de confirmação. Apenas destacar um item em um seletor separado não significa que ele foi aplicado.

Um lugar para cada configuração

Models
Navegue pelos modelos das contas configuradas, aplique um par provedor/modelo, atualize o catálogo e configure capacidades persistentes e preços com Alt+C.
Generation
Raciocínio, amostragem e limite de saída solicitados para a sessão atual. Os controles globais de modelos auxiliares ficam mais abaixo na mesma página.
Connections
Acesso a contas: endereços de API e chaves nomeadas. Não escolhe o provedor web nem controla os tempos limite de requisição aos modelos.
Runtime
Tempos limite de requisição aos modelos, comportamento de novas tentativas, rotação do anel de chaves e tempos de espera compartilhados de conexão e streaming.
Tools
Tempos de espera e limites de saída/trabalho específicos de cada ferramenta, prazos de perguntas e permissões, além da seleção independente de provedores web.
Appearance
Tema de cores e preferência de exibição do painel lateral da conversa. Não configura papel de parede, desfoque nem transparência do terminal.

Escolhas globais e por sessão

Limites de ferramentas, configurações de rede/novas tentativas e escolhas de modelos auxiliares são globais para a pasta de dados selecionada do Rune. Já os controles principais de Generation e a seleção de modelo afetam a sessão e o modelo ativos. Preferências salvas para um modelo podem ser recuperadas quando você volta a usá-lo.

A tabela global [generation] fornece valores iniciais padrão, não uma instrução para sobrescrever todas as sessões já existentes. A opção New-session fallback seleciona um provedor inicial para sessões futuras, sem alterar o provedor das conversas já abertas.

Redefinição e momento de aplicação

A opção Use default remove a substituição global salva para que o padrão atual ou a herança volte a valer. Salvar manualmente o mesmo número do valor de fábrica registra uma escolha fixa, o que é diferente de deixar a chave sem definição. Para valores opcionais de Generation na sessão, limpar o campo devolve o controle ao provedor ou ao padrão.

As configurações normalmente entram em vigor sem precisar reiniciar o Rune. Alguns componentes se atualizam na hora (live); outros aplicam o novo valor na próxima operação, enquanto o trabalho em andamento mantém as configurações com que iniciou. Use rune -config explain <key> para consultar o comportamento exato de uma chave. A política do classificador possui uma ação explícita e separada de recarregamento.

Inspecione antes de alterar

Uma configuração válida não prova que uma conexão esteja funcionando, e o estado Configured não prova que uma conta tenha saldo. Testes de conexão realizam requisições reais e podem gerar custos. Trocar de provedor pode mudar para onde seus dados são enviados; aumentar o número de tentativas ou o limite de saída pode elevar os gastos.

Nem toda opção avançada possui uma linha na interface gráfica. O guia do arquivo de configuração explica como inspecionar e redefinir essas opções sem inventar controles nem substituir escolhas não relacionadas.
