Todas as configurações que você pode alterar no Rune {{.DocVersion}}, agrupadas exatamente como no arquivo rune.toml: uma linha em Settings ou uma chave do arquivo. Cada entrada informa o valor de fábrica, o que a configuração faz nas palavras do próprio programa, os valores aceitos e quando uma alteração entra em vigor. As constantes do próprio Rune — os valores que o mantêm funcionando — não são configurações, não podem ser alteradas e não aparecem aqui.

O valor de fábrica é o que vale até você escolher outro; suas escolhas salvas aparecem com rune -config explain <key>. Redefina uma escolha com rune -config reset <key>. Durações e tamanhos exigem unidades explícitas, como "2m" ou "16MiB"; consulte Arquivo de configuração para ver os formatos de valores.
