Orientações do projeto

O arquivo AGENTS.md na raiz do workspace fornece orientações sobre o projeto: comandos de build, convenções e limites relevantes para o trabalho. Ele não é um arquivo de chaves de API, uma concessão de permissão nem a política do classificador. Mantenha credenciais fora dele e inclua apenas textos que você deseja enviar como contexto para o modelo.

O limite de fábrica para instruções automáticas é de 32.768 caracteres, controlado por instructions.max_chars em Settings → Tools → Project instructions. Quando um arquivo ultrapassa esse limite, o Rune informa qual parte ficou de fora, e a IA lê o restante antes de se basear nessas regras; o restante do arquivo não deixa de existir. Se as orientações mudarem durante uma sessão, o Rune pode avisar o modelo para reler a fonte correspondente.

Anexe o arquivo desejado

O comando /attach <path> adiciona um arquivo à próxima mensagem; /detach <number|all> remove anexos pendentes. Confira a lista de anexos pendentes antes de enviar. Cada modelo pode lidar de forma diferente com textos, imagens ou outras mídias; a presença de um arquivo não garante que seu conteúdo possa ser interpretado pelo modelo.

Um anexo enviado identifica a versão exata do arquivo no momento do envio. Editar o arquivo no mesmo caminho mais tarde não transforma uma mensagem antiga nos novos bytes. Quando o conteúdo original não pode ser recuperado, o Rune informa que o arquivo mudou ou desapareceu, em vez de apresentar o conteúdo novo como se fosse o antigo. Anexe a nova versão explicitamente quando a tarefa precisar dela.

Os limites de fábrica incluem 60.000 caracteres de texto por arquivo de texto anexado e até dez anexos no histórico. Limites de contexto e de tamanho de requisição do provedor podem remover mídias mais antigas antes disso. Esses limites são independentes dos anexos da mensagem atual e do recolhimento visual na transcrição.

Memória do projeto

O Rune oferece suporte a notas persistentes por projeto com um índice MEMORY.md; Memória explica onde essas notas ficam guardadas e o que chega ao modelo. O modelo recebe o índice — não todas as notas automaticamente — e lê uma nota relevante quando necessário. O orçamento de leitura do índice é de 20 KiB por padrão; aumentá-lo consome mais contexto do modelo, mas não torna as notas mais precisas.

Use a memória para decisões estáveis, correções e trabalhos em andamento. Não armazene credenciais nem resultados temporários de cada comando. As notas podem ser incluídas em requisições posteriores ao modelo e não constituem uma fonte de permissão separada. O modelo acessa a memória do projeto pelas ferramentas de arquivo usando @memory/, sem criar uma pasta de memória dentro do seu repositório.

Mantenha as finalidades separadas

AGENTS.md
Orientações do projeto enviadas como contexto para o modelo.
CLASSIFIER.md
Sua política para revisão de ações aplicáveis da IA. Possui comportamento explícito de recarregamento e não se confunde com as orientações do projeto.
rune.toml
Configurações na pasta de dados selecionada do Rune. Um arquivo com o mesmo nome dentro de um projeto não se torna automaticamente o arquivo de configurações globais.
Skill
Um guia reutilizável ativado ou lido para uma tarefa. Não pode conceder acesso por conta própria.

Textos do repositório, páginas web ou respostas de ferramentas podem conter instruções enganosas. Trate seu conteúdo como dados de trabalho e revise as ações na fronteira de permissão, em vez de confiar na afirmação de um documento dizendo que a aprovação já foi concedida.
