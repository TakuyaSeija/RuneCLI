Execute você mesmo um comando

Digite ! como o primeiro caractere no campo de mensagem, seguido de um comando, e pressione Enter. O Rune executa esse script para você, sem passar pela IA. Antes de pressionar Enter, o campo de mensagem exibe Shell · full access once, deixando claro que a entrada é um comando direto e não uma mensagem.

! git status --short
npm test

O exemplo acima é um único script de duas linhas: ambas são executadas. Apenas a primeira linha leva o caractere !; um segundo ! seria interpretado pelo próprio shell (no bash e no sh, ele inverte o código de saída do comando seguinte). Use esse recurso para uma verificação rápida, um build que você queira acompanhar ou uma etapa que a IA não teve permissão para executar. O comando e seu resultado passam a fazer parte da conversa, e a IA responde assim que ele termina.

O que conta como comando

  • Apenas um ! na primeira posição inicia um comando. Entradas como hello ! echo test, um ! após um espaço ou um ! em uma linha seguinte de uma mensagem comum são tratadas como texto normal.
  • Quando a entrada começa com !, todas as linhas fazem parte do mesmo script. Um ! em linhas seguintes é sintaxe do shell, não um segundo comando do Rune.
  • Colar texto nunca executa nada sozinho. Pressionar Enter executa todo o script atual, incluindo todas as linhas coladas.
  • Um ! isolado não executa nada. Apague o ! inicial para transformar o texto de volta em uma mensagem comum.

Qual acesso ele tem

Pressionar Enter já é a própria permissão. O script roda uma única vez com o acesso completo da sua conta do sistema operacional: fora dos limites do workspace e da sandbox de comandos, sem revisão do classificador ou do sanitizador e sem exibir outro cartão de permissão.

Ele não roda como Administrador nem como root, não altera o modo da sessão e não aprova nenhuma ação posterior da IA. Leia todo o script antes de pressionar Enter, especialmente quando tiver colado o conteúdo.

Enquanto a IA está trabalhando

Um comando enviado durante um turno aguarda o término desse turno e, em seguida, é executado na ordem em que você o enviou. A saída ao vivo aparece enquanto ele roda. Quando ele termina — ou quando passa para segundo plano por continuar rodando após o tempo de espera configurado ou por aguardar entrada digitada —, o Rune adiciona o comando e tudo o que ele imprimiu à conversa, e a IA responde em seguida. Essa resposta é uma requisição normal ao modelo e pode gerar custos.

Se uma janela se reconectar, o Rune reenvia a mesma submissão sem executar o comando duas vezes. Após um encerramento inesperado (crash), o Rune nunca repete um comando que já possa ter sido executado.

Quando um comando da IA foi recusado

Quando um comando proposto pela IA é recusado, o aviso de recusa pode mencionar esta opção manual. O Rune nunca envia um comando com ! no seu lugar e nunca repete uma ação recusada por conta própria. Nenhuma outra ferramenta possui um atalho semelhante.

Qual shell executa o comando

O shell é definido por terminal.shell. Com o valor de fábrica auto, o Rune usa o bash onde estiver disponível e /bin/sh caso contrário; no Windows, usa o PowerShell 7, depois o Windows PowerShell e, por último, o Prompt de Comando. Cada shell interpreta os comandos na sua própria sintaxe.

A caixa do comando mostra qual shell realmente o executou: $ para bash e zsh, PS> para PowerShell e > para Prompt de Comando. Uma caixa recolhida mostra a primeira linha do script; clique nela para abrir o script completo com suas linhas originais.

Privacidade

O comando e tudo o que ele imprimir na tela são enviados para a IA na requisição seguinte. Não imprima segredos, chaves nem arquivos privados que você não colaria em uma mensagem. O Rune oculta as chaves que já conhece, mas isso não garante a remoção de qualquer valor privado arbitrário.
