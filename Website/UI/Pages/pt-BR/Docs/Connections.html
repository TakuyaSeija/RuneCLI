Acesso não é seleção

A seção Connections cuida dos endereços de contas e das chaves de API. Ela não escolhe o modelo atual, o tempo limite de requisição ao modelo, a rota de busca na web nem o leitor de páginas. Essas escolhas pertencem a Models, Runtime e Tools, respectivamente.

Configured
Uma ou mais chaves de API estão salvas para esta conta. Isso não prova que uma requisição teve sucesso nem que há saldo disponível.
Key missing
Nenhuma chave está salva para esta conta na pasta de dados ativa; adicione uma em Connections.
Unavailable
O cofre criptografado existe no disco, mas não pode ser aberto; restaure o par de backup correspondente.

Verifique o erro exato em /logs em vez de substituir a conta repetidamente.

Adicionar uma conta de modelo

Cada predefinição de provedor, com seu formato de chave e endereço, está listada em Provedores de modelos.

  1. Abra Settings → Connections → Add connection e escolha o provedor de modelo desejado.
  2. Revise o formulário, inicialmente marcado como Not connected yet. Uma predefinição com endereço fixo pede apenas a chave; um endereço dependente da conta ou personalizado precisa ser informado explicitamente.
  3. Verifique o nome da conexão e o nome da chave. Insira segredos apenas no campo de credencial.
  4. Conecte. O Rune testa uma nova conta de modelo antes de aceitá-la; essa requisição pode ser tarifada. Cancelar descarta a adição sem salvar.
  5. Selecione o par provedor/modelo desejado em Models após conectar.

Uma predefinição fornece padrões compatíveis de configuração. Ela não é uma conta, uma permissão de uso de API nem uma garantia de que todos os produtos do provedor funcionarão. Assinaturas específicas de planos e endereços regionais podem diferir da API comum de um fornecedor.

Adicionar uma conta web

Escolha um fornecedor em Search & Fetch, informe o endereço/chave necessários e salve a conta. Salvar o acesso web por si só não ativa nem comprova que um provedor de busca ou leitura de páginas funciona. Continue em Tools → Web search ou Web fetch → Provider para adicionar, testar e selecionar o serviço desejado.

Busca e leitura de páginas têm seleções independentes. Uma conta de modelo local e o serviço web do mesmo fornecedor podem exigir endereços ou chaves diferentes. Veja Busca e leitura web.

Editar e remover

Abra uma conexão existente para alterar sua Base URL ou gerenciar chaves nomeadas. Alterações no endpoint do modelo são testadas antes de serem aceitas. A opção Use default restaura o endereço padrão do provedor, sem tentar adivinhar um endereço pelo nome da conta.

Adicionar uma chave acrescenta uma alternativa; não substitui todas as chaves automaticamente. Verifique o nome e a prévia mascarada de uma chave antes de removê-la. Remover uma conexão pode deixar suas credenciais disponíveis para reutilização; remover a conta não é uma promessa de exclusão segura e irreversível.

Destino e testes

Alterar um endpoint pode enviar tanto credenciais quanto prompts para outra parte. Verifique a titularidade do serviço e a região desejada antes de conectar. Endpoints remotos que usam chaves exigem transporte criptografado; um endpoint na própria máquina é um caso local à parte.

Testes de conexão e de modelo são requisições reais e podem gerar custos. Um teste de conta bem-sucedido vale para a requisição testada, não para todos os modelos, ferramentas, tamanhos de contexto ou permissões da conta. Prefira fazer um teste pequeno e deliberado após verificar o erro exato nos logs.
