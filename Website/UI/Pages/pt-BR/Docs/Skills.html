Uma skill é um guia

Uma skill reúne instruções e referências reutilizáveis para uma tarefa. Ela não é uma concessão executável de permissão. O agente pode descobrir uma skill relevante e ler seu arquivo SKILL.md, ou você pode ativar uma explicitamente na conversa. Revise orientações e scripts de outros autores antes de segui-los.

Descobrir e usar

/skills list
Lista os guias disponíveis e seus IDs exatos.
/skills show <id>
Lê as informações de um guia específico.
/skill <id>
Ativa um guia para esta conversa. Seu texto não pode aprovar ações não relacionadas nem ignorar as verificações de execução.
/skills enable|disable <id>
Altera a disponibilidade no projeto atual; isso não desinstala a skill para todos os usuários ou projetos.
/skills reload
Atualiza o catálogo após alterações. Leia novamente um guia alterado antes de se basear nele.

Localizações e instalação

Um guia de projeto fica em .rune/skills/<name>/SKILL.md; guias de projeto portáteis podem usar .agents/skills/. Guias pessoais ficam na pasta skills dentro da pasta de dados selecionada do Rune, com a localização pessoal portátil disponível quando ativada.

O comando rune -skills install <folder-or-zip> instala um pacote revisado em .rune/skills/ deste projeto, mantendo-o junto ao projeto ao qual serve sem misturá-lo a outros projetos; ele é compartilhado com todos que usam os arquivos do projeto, inclusive no repositório. Adicione --scope user para torná-lo um guia pessoal disponível em todos os projetos. O comando rune -skills update <folder-or-zip> substitui uma cópia instalada no escopo escolhido da mesma forma e não guarda cópia da versão anterior, portanto mantenha seu original ou use controle de versão. Cada pacote possui seu próprio nome em letras minúsculas e pasta correspondente, um arquivo SKILL.md com metadados de nome e descrição e referências relativas opcionais. A instalação e as atualizações devem ser deliberadas, sem confiar cegamente em textos baixados.

O que a IA vê das suas skills

A IA não recebe todos os guias na íntegra de uma vez. Ela recebe um catálogo curto das skills disponíveis, com seus nomes e descrições de uma linha, e só lê um guia completo quando precisa dele. Esse catálogo é limitado a 8 KiB de texto por padrão (skills.max_catalog_size); uma skill que não caiba ali continua descobrível, de modo que a IA ainda pode encontrá-la e lê-la. O limite é um tamanho em bytes, não uma contagem de tokens do modelo. Um valor definido em capabilities.catalog_bytes, quando salvo, tem precedência sobre ele.

Altere esse limite com rune -config set skills.max_catalog_size 16KiB e volte ao padrão com rune -config reset skills.max_catalog_size. Um catálogo maior consome mais contexto do modelo em cada requisição.

Ajuda oficial offline

O Rune traz embutida a skill settings-guide; ela não exige nenhum download adicional nem conta de serviço. O texto oficial gerenciado pode ser reparado automaticamente caso seja alterado ou corrompido. Coloque suas personalizações em uma skill pessoal ou de projeto separada em vez de editar essa cópia gerenciada.

O nome rune-settings-guide pertence a esta ajuda integrada: nenhum pacote pode ser instalado ou atualizado sob esse nome, e outra cópia com o mesmo nome nunca toma o seu lugar (a lista mostra essa cópia como oculta/shadowed). Outros guias com nomes iguais podem vir de escopos diferentes, tendo precedência a cópia do projeto. Use o ID exato listado para diferenciá-los. Desativar capacidades ou um guia específico também pode tornar a ajuda oficial indisponível; isso não significa que o binário instalado não possua o recurso.
