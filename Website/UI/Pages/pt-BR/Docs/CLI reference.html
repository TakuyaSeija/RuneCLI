Iniciar e inspecionar

Execute estes comandos no shell do seu sistema operacional. Use rune -help para consultar a sua compilação instalada. Comandos que contatam provedores, alteram contas, excluem dados ou iniciam servidores são operações reais, não flags de diagnóstico inofensivas.

rune [dir]
Abre o agente interativo no workspace atual ou no diretório informado.
rune -p "prompt"
Executa um único prompt e imprime a resposta e o progresso das ferramentas sem a interface em tela cheia. Solicitações de permissão são recusadas em vez de aprovadas silenciosamente quando não há ninguém para responder.
-project <dir>
Seleciona o workspace para outro comando.
-version · -help
Imprime a versão do aplicativo ou a referência de comandos.
-settings · -tools
Inspeciona os controles efetivos do modelo ou as ferramentas oferecidas ao agente.
-read-only
Restringe ferramentas que modificam dados. Isso não garante que nenhum arquivo seja lido nem que nenhum dado seja enviado.
--no-color
Desativa o uso de cores. A variável de ambiente NO_COLOR também é suportada.

Configuração

-config
Mostra a localização das configurações selecionadas.
-config show|defaults|check
Mostra os valores efetivos, exibe os padrões de fábrica ou valida o arquivo. O comando show pode conter metadados privados de contas; o comando check não comprova conectividade.
-config explain <key>
Explica o valor efetivo de uma chave e quando ela entra em vigor.
-config set <key> <value>
Salva uma escolha global. Exemplo: rune -config set terminal.command_timeout 2m.
-config reset <key>
Remove uma substituição global para que o padrão atual ou a herança volte a valer.
-config format
Reformata as configurações agrupadas sem alterar intencionalmente o seu significado.
-set key=value
Altera uma preferência compatível do workspace/modelo, e não uma chave arbitrária da configuração global.

Contas e modelos

Prefira o editor de credenciais mascarado em Connections. Chaves reais passadas como argumentos de comando podem vazar pelo histórico do shell e pela listagem de processos. A sintaxe abaixo usa espaços reservados propositalmente.

rune -provider add <name> -key <key> [-preset <p>] [-base <url>] [-model <id>]
-provider list
Lista contas, predefinições e disponibilidade de serviços web.
-provider key <name> <key>
Adiciona uma chave ao chaveiro de uma conta. Isso altera as credenciais.
-provider keys <name>
Inspeciona os metadados mascarados das chaves.
-provider dropkey <name> <n>
Remove a credencial de número correspondente após revisar sua identidade.
-provider default <name>
Escolhe o provedor padrão para novas sessões; isso não altera todas as conversas já existentes.
-provider remove <name>
Remove a configuração do provedor. Não presuma que todas as credenciais retidas foram apagadas de forma irreversível.
-provider test <name>
Envia uma requisição real, potencialmente tarifada, para testar a conta.
-provider models <name>
Consulta o catálogo de modelos da conta. Faz uma requisição de rede.
-provider dryrun <name> [model]
Pré-visualiza uma requisição sem enviá-la. A prévia pode incluir contexto privado; não a compartilhe integralmente.
-provider timeout <name> <seconds>
Define um tempo limite opcional para requisições da conta, de 5 a 3600 segundos; default remove a substituição.
-provider new-store --yes
Separa um par de credenciais ilegível e inicia um cofre vazio. Use apenas após uma decisão deliberada de recuperação; todas as chaves precisarão ser adicionadas novamente.
-model list · -model set <id>
Lista ou seleciona um modelo para o workspace escolhido.

Sessões e armazenamento

-session · -resume <id>
Abre o seletor de sessões (ou lista quando redirecionado via pipe) ou retoma uma sessão conhecida.
-session rename <id> <title>
Renomeia uma sessão.
-session delete <id>
Exclui permanentemente uma sessão. Verifique a identidade dela primeiro.
-storage [list|prune]
Inspeciona o armazenamento dos projetos ou remove dados elegíveis pertencentes a projetos que não existem mais no disco.
-sandbox [setup|reset]
Inspeciona o estado do isolamento de comandos no Windows, configura explicitamente sua conta dedicada ou remove o acesso e a configuração da conta de sandbox do Rune. Outras plataformas não utilizam essa configuração.

Extensões e diagnóstico

-skills [operation]
Lista, mostra, ativa, desativa, instala ou recarrega guias reutilizáveis. A instalação recebe uma pasta ou arquivo zip revisado e o coloca no projeto atual, a menos que --scope user o torne pessoal.
-mcp [operation]
Gerencia, aprova, valida e testa definições de ferramentas externas. Uma conexão pode iniciar um processo ou contatar um serviço remoto; apenas validar não equivale a uma conexão estabelecida com sucesso.
--scope user|project|private-project
Escolhe o escopo de configuração compatível para uma alteração de capacidade. Alterações compartilhadas no projeto afetam outras pessoas que utilizam esse projeto.
-doctor
Executa diagnósticos, incluindo verificações de conectividade. Pode fazer requisições de rede; revise a saída antes de compartilhá-la.
-db <path>
Usa um banco de dados alternativo para o motor. Isso é independente de escolher uma pasta inteira de configurações com RUNE_HOME.
-host
Usa JSON delimitado por linhas para integração de interface, em vez da interface interativa. Não é um servidor de rede público.
-script <file>
Reproduz um script de modelo escrito. Um script pode propor ferramentas reais, portanto nunca execute um script não revisado em um trabalho real.

Para configurar capacidades e acessos, continue em Skills ou Conexões MCP. Não mude para o modo Full nem exclua dados locais apenas para contornar um erro.
