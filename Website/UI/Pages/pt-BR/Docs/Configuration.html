Localização e escopo

A configuração global fica no arquivo rune.toml dentro da pasta de dados selecionada do Rune, normalmente ~/.rune/. A Referência de configurações lista todas as chaves que ele pode conter. A variável RUNE_HOME seleciona uma pasta de dados diferente. Um arquivo chamado rune.toml dentro de um projeto não se torna automaticamente o arquivo de configurações, e -project escolhe um workspace, não uma pasta de configurações.

Use rune -config para ver a localização exata. O arquivo guarda apenas as escolhas que você salvou; valores ausentes herdam os padrões atuais. A linha superior version = 1 descreve o formato da configuração, não a versão do aplicativo. Não a altere para tentar solicitar uma atualização.

Inspecione um item por vez

-config explain <key>
Lê o valor efetivo de uma chave, sua descrição e quando ela entra em vigor.
-config defaults
Lê os padrões de fábrica separadamente das suas escolhas salvas.
-config check
Valida a sintaxe da configuração e os valores aceitos. Não testa chaves, saldo nem conectividade.
-config show
Inspeciona a configuração efetiva. Pode conter metadados privados de contas; oculte informações sensíveis antes de compartilhar.
-settings
Inspeciona os controles do modelo para o workspace selecionado.

Alterar e redefinir

rune -config explain terminal.command_timeout
rune -config set terminal.command_timeout 2m
rune -config reset terminal.command_timeout
rune -config check

Execute o comando set apenas quando desejar fazer essa alteração global. O comando reset remove a substituição; ele não grava uma cópia do valor padrão. Em Settings, a opção Use default cumpre a mesma função para valores globais. Chaves desconhecidas ou descontinuadas geram erro, não sendo tratadas silenciosamente como apelidos compatíveis.

O formato TOML não possui um valor nulo nativo. Remova uma chave opcional ou use o comando reset suportado em vez de escrever null. Não presuma que uma string vazia, “auto”, “none” ou uma lista vazia significam redefinição para todas as configurações.

Tipos e unidades

Booleano
true ou false, sem aspas no TOML.
Contagem / tokens
Um número inteiro dentro do intervalo aceito pela configuração. Tokens, caracteres e bytes são medidas diferentes.
Duração
Uma string com unidades explícitas, como "500ms", "60s" ou "2m". Apenas os tempos de espera de permissão e de pergunta aceitam unlimited.
Tamanho
Use unidades binárias explícitas, como "16MiB". Um tamanho sem unidade é interpretado como KiB, não como bytes.
Lista
Use exatamente as entradas documentadas. [] representa uma seleção explicitamente vazia, não necessariamente uma redefinição.
[terminal]
command_timeout = "2m"

[generation]
temperature = 0.2
stop = ["END,EXACT", "STOP"]

Isto é apenas um exemplo de sintaxe, não uma configuração universal recomendada. O array stop preserva strings exatas, incluindo vírgulas; já o editor da sessão aceita entradas separadas por vírgula. Os padrões globais de geração não sobrescrevem todas as sessões atuais.

Momento de aplicação e riscos

As alterações normalmente se propagam sem precisar reiniciar. Use explain para consultar uma configuração específica: valores imediatos (live) e valores aplicados na próxima operação têm comportamentos diferentes. Editar o arquivo CLASSIFIER.md não recarrega uma política já fixada na sessão; use a ação de recarregamento quando a sessão estiver ociosa.

Mantenha endpoints de contas e credenciais fora de exemplos públicos. Valide edições manuais sem substituir escolhas não relacionadas. Limites mais altos podem aumentar o uso de memória, disco, contexto e custo; eles não concedem acesso nem fazem um modelo incompatível funcionar.
