المحادثة والتطبيق

Enter · Alt+Enter
إرسال الرسالة، أو إدراج سطر جديد. تعتمد تركيبات مفتاح Return المعدلة على ما تبلّغ عنه الطرفية.
Ctrl+G · Ctrl+O
فتح الإعدادات (Settings)، أو إظهار/إخفاء اللوحة الجانبية.
Ctrl+T · Ctrl+R
فتح الخطة، أو توسيع/طي الخطوات وأقسام التفكير. وفي منتقي الجلسات يفتح الاختصار Ctrl+R نافذة إعادة التسمية بدلاً من ذلك.
Alt+T
التبديل بين خيارات الاستدلال المتاحة للنموذج المختار.
Tab
إكمال أمر شرطة مائلة أو التبديل بين أوضاع الأذونات. وتحتفظ النماذج الحوارية بتنقل Tab الخاص بها.
Esc مرتين
إيقاف عمل الذكاء الاصطناعي النشط: تعرض الضغطة الأولى رسالة تأكيد، وتوقف الضغطة الثانية خلال 3 ثوانٍ التنفيذ. كما يغلق مفتاح Esc العرض الخامل.
Ctrl+C مرتين
مغادرة Rune. تجهّز الضغطة الأولى الخروج، ولا تلغي الدور الجاري أو تمسح المسودة.
Ctrl+L · Ctrl+↓
إعادة رسم الشاشة، أو الانتقال السريع إلى أحدث موضع في المحادثة.

تحرير النصوص

تعمل هذه الاختصارات في مربع الكتابة، والإجابات القابلة للتحرير، وحقول الإعدادات، والبحث في النماذج، وحقول MCP، والبحث في الجلسات وإعادة تسميتها. وللقوائم والأزرار تنقلها المستقل. ينتهي السطر المنطقي عند فاصل أسطر مدرج، بينما قد ينتج السطر المرئي عن التفاف النص التلقائي.

Ctrl+← / Ctrl+→الانتقال إلى بداية الكلمة السابقة المفصولة بمسافة / نهاية الكلمة التالية.
↑ / ↓التحرك عبر الأسطر المرئية مع الاحتفاظ بالعمود المطلوب.
Ctrl+A / Ctrl+Eبداية / نهاية السطر المنطقي الحالي.
Home / Endبداية / نهاية حقل الإدخال بالكامل.
Backspace / Deleteحذف المحرف المرئي قبل / بعد المؤشر، أو حذف النص المحدد.
Ctrl+U / Ctrl+Kالقص للخلف / للأمام حتى حدود السطر المنطقي. يزيل الاختصار Ctrl+K عند فاصل الأسطر ذلك الفاصل فقط، ولا يفعل شيئاً في نهاية المدخل.

تؤدي الكتابة أو اللصق أو الحذف إلى استبدال النص المحدد. ويتبع سجل التراجع المؤقت والنصوص المقصوصة لذلك الحقل وحده، وهو محدود الحجم ويُمسح عند تغيير الحقل أو الجلسة، ولا يُعد نسخة احتياطية للملفات. لا يوفر Rune مجموعة اختصارات Readline البديلة بالكامل؛ فعلى سبيل المثال لا يُعد Ctrl+B/F وAlt+B/F اختصاري حركة بديلين.

السجل والقراءة

في مربع الكتابة، يتنقل السهمان Up/Down أولاً عبر النص المرئي، ثم يصلان إلى البداية أو النهاية، وبعدها يستدعيان سجل الموجهات السابقة. بينما يستدعي المفتاحان PgUp/PgDn السجل مباشرة. ويتبع السجل للجلسة الحالية.

تحرك كل درجة في عجلة الفأرة العدد المكون من الأسطر (سطران افتراضياً). ويضاعف الاختصار Ctrl+wheel أو Alt+wheel المسافة ثلاث مرات عندما تمرره الطرفية. قد تحجز الطرفية هذه الإيماءات للتكبير أو التمرير الأفقي، وتبقى عجلة الفأرة العادية ولوحة المفاتيح متاحة دائماً.

الفأرة

يضع النقر مؤشر النص أو يفعّل عنصر التحكم. واسحب فوق النص ثم أفلت لنسخه: يختفي التظليل بمجرد وصول النص إلى الحافظة. ينسخ السحب داخل المحادثة ذلك الجزء فقط دون اللوحة الجانبية أو حدود صناديق Rune، وتُنسخ الجداول كخلايا مفصولة بعلامات جدولة (tabs). كما يعيد نسخ الأمر المطوي فواصل أسطره الأصلية دون علامتي العرض ↵ و…. وفي حقل الإدخال ينسخ السحب النص دون تحريك المؤشر أو استبدال مسودتك؛ ولتحديد نص بغرض تحريره استخدم مفتاح Shift مع مفاتيح الأسهم. لا تُنسخ حقول الأسرار المقنّعة أبداً.

يجب أن تسمح الطرفية بالكتابة إلى الحافظة لكي تصل عملية النسخ؛ وقد يمنع اتصال SSH أو برنامج تقسيم الطرفية (multiplexer) ذلك. ويستخدم السحب مع الضغط على Shift (حيثما تدعمه الطرفية) تحديد الطرفية نفسها شاملةً الحدود. وعند ضبط ui.mouse = false يعود كل التحديد إلى الطرفية.

انقر على رابط لفتح لوحة REFERENCE الخاصة به: يفتح Enter عنوان الويب في متصفحك، وينسخ C الوجهة الكاملة، ويغلق Esc اللوحة. أما السحب فوق الرابط فينسخ النص ولا يفتحه أبداً.

القوائم والنماذج

تحدد الأسهم العناصر ويفتحها أو يؤكدها مفتاح Enter. وينقل Tab/Shift+Tab التركيز. ويلغي مفتاح Esc المحرر أو يعود مستوى واحداً للخلف. وفي قسم Models، يركز الاختصار Ctrl+F على البحث، ويفتح Alt+C إعدادات النموذج، ويختبر المفتاح T النموذج بطلب حقيقي، ويزيل مفتاح Delete التكوين المحلي للنتيجة المحددة.

في نماذج الأسئلة، يبدّل الاختصار Alt+Left/Right بين الأسئلة، بينما يحرر السهمان Left/Right النص أو يحددان الأزرار. وتقرأ مفاتيح الصفحات (PageUp/PageDown) البطاقات الطويلة ولا ترسل الإجابة. ويتنقل السهمان Up/Down داخل الإجابة المخصصة عبر نصها أولاً قبل مغادرتها. كما يحدد سحب الفأرة النص بدلاً من تفعيل عنصر التحكم الموجود تحته.

اختلافات الطرفيات

لا يعمل الاختصار إلا إذا أبلغت الطرفية عنه؛ فقد تحجز اختصارات نظام التشغيل أو ملفات إعداد الطرفية أو ترميزات التحكم التقليدية بعض التركيبات. كما تتبع الخلفيات والتمويه والشفافية للطرفية نفسها وليس لـ Rune. راجع الأمر /help للنسخة المثبتة لديك بدلاً من افتراض تطابق خريطة مفاتيح الصدفة.
