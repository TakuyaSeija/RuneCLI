الفتح والتنقل

اضغط على Ctrl+G، أو أدخل /settings، أو استخدم اختصاره البديل /*. تقود النظرة العامة إلى ستة أقسام. تحدد مفاتيح الأسهم صفاً أو بطاقة، ويفتحها مفتاح Enter. وينقل Tab/Shift+Tab التركيز، بينما يلغي مفتاح Esc المحرر أو يعود مستوى واحداً للخلف. ويصف التذييل عنصر التحكم المحدد.

افتح قيمة، وعدّلها ثم اختر Apply. ويحتفظ خيار Cancel بالقيمة السابقة. تحفظ بعض صفوف الخيارات التغيير مباشرة عند التبديل بالسهمين Left/Right؛ اقرأ التلميح وانتظر رسالة النجاح. إن مجرد تظليل عنصر في قائمة اختيار منفصلة لا يعني بالضرورة تطبيقه.

قسم مخصص لكل إعداد

Models
تصفح نماذج الحسابات المكونة، وتطبيق زوج مزود/نموذج، وتحديث الدليل، وتكوين معلومات القدرات والأسعار الدائمة بالاختصار Alt+C.
Generation
الاستدلال وأخذ العينات والمخرجات المطلوبة للجلسة الحالية. وتقع ضوابط النماذج المساعدة العامة في أسفل الصفحة نفسها.
Connections
الوصول إلى الحسابات: عناوين API والمفاتيح المسماة. لا يختار هذا القسم مزود الويب ولا يدير مهل طلبات النماذج.
Runtime
مهل طلبات النماذج، وسلوك إعادة المحاولة، وفترة إراحة الرصيد، ومهل انتظار الاتصال والبث المشتركة.
Tools
مهل الانتظار وحدود المخرجات والعمل الخاصة بكل أداة، ومهل الأسئلة والأذونات، والاختيار المنفصل لمزودي الويب.
Appearance
السمة وتفضيل إظهار اللوحة الجانبية للمحادثة. لا يضبط هذا القسم خلفية الطرفية أو التمويه أو الشفافية.

الخيارات العامة وخيارات الجلسة

تُعد حدود الأدوات وإعدادات الشبكة وإعادة المحاولة وخيارات النماذج المساعدة عامة لمجلد بيانات Rune المحدد. أما ضوابط التوليد الرئيسية واختيار النموذج فتؤثر في الجلسة النشطة والنموذج الحالي. ويمكن استدعاء تفضيلات النموذج المحفوظة عند العودة إلى ذلك النموذج.

يوفر جدول [generation] العام قيم البدء الافتراضية، وليس تعليمة للكتابة فوق كل جلسة حالية. ويختار إعداد New-session fallback مزود البدء للجلسات المستقبلية، وليس المزود لكل محادثة مفتوحة.

إعادة الضبط وتوقيت السريان

يزيل خيار Use default التخصيص العام المحفوظ لتعود القيمة الافتراضية الحالية أو الوراثة إلى السريان. ويُعد حفظ رقم المصنع حرفياً خياراً مخصصاً يختلف عن ترك المفتاح دون تعيين. وبالنسبة لقيم التوليد الاختيارية الخاصة بالجلسة، يعيد مسح الحقل التحكم إلى المزود أو القيمة الافتراضية.

تتبع الإعدادات التغييرات عادةً دون إعادة تشغيل Rune؛ فبعض المستهلكات تتحدث فوراً، بينما يستخدم بعضها الآخر القيمة الجديدة في العملية التالية مع احتفاظ العمل الجاري تنفيذه بإعدادات بدايته. استخدم الأمر rune -config explain <key> للمفتاح المعني. ولسياسة المصنف إجراء إعادة تحميل صريح منفصل.

الفحص قبل التغيير

صحة صيغة التكوين لا تثبت عمل الاتصال، وحالة Configured لا تثبت توفر رصيد في الحساب. وتجري اختبارات الاتصال طلبات حقيقية قد تترتب عليها تكلفة. كما أن تغيير المزود قد يغير وجهة بياناتك، وزيادة محاولات الإعادة أو حدود المخرجات قد ترفع الإنفاق.

ليس لكل خيار متقدم صف في الواجهة الرسومية؛ ويشرح دليل ملف التكوين كيفية فحص تلك الخيارات وإعادة ضبطها دون اختلاق عناصر تحكم أو استبدال خيارات غير مرتبطة.
