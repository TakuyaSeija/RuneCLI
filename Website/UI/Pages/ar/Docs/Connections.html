الوصول ليس هو الاختيار

يتولى قسم Connections إدارة عناوين الحسابات ومفاتيح API، لكنه لا يختار النموذج الحالي أو مهلة طلب النموذج أو مسار البحث في الويب أو قارئ الصفحات؛ فهذه تتبع لأقسام Models وRuntime وTools على التوالي.

يشير عدد المفاتيح أو حالة Configured إلى وجود بيانات اعتماد محفوظة، ولا يعني نجاح الطلب أو توفر رصيد. وقد تعني حالة Resting أن بيانات الاعتماد غير متاحة مؤقتاً. افحص سبب الخطأ الفعلي بدلاً من استبدال الحساب مراراً وتكراراً.

إضافة حساب نموذج

تُعرض الإعدادات المسبقة لكل مزود مع مفتاحه وعنوانه في صفحة مزودو النماذج.

  1. افتح Settings → Connections → Add connection واختر مزود النماذج المطلوب.
  2. راجع النموذج الذي يظهر في البداية بحالة Not connected yet. يطلب الإعداد المسبق ذو العنوان الثابت مفتاح API فقط؛ بينما يجب إدخال العنوان المعتمد على الحساب أو المخصص صراحةً.
  3. تحقق من اسم الاتصال واسم المفتاح، وأدخل الأسرار في حقل بيانات الاعتماد فقط.
  4. اختر Connect. يختبر Rune حساب النموذج الجديد قبل قبوله، وقد تُحتسب تكلفة هذا الطلب. ويترك خيار Cancel الإضافة دون حفظ.
  5. اختر المزود والنموذج الفعليين ضمن قسم Models بعد الاتصال.

يوفر الإعداد المسبق قيم إعداد متوافقة، لكنه ليس حساباً ولا استحقاق استخدام API ولا وعداً بأن جميع منتجات المزود ستعمل. وقد تختلف الاشتراكات الخاصة بخطط معينة والعناوين الإقليمية عن واجهة API العادية للمزود.

إضافة حساب خدمة ويب

اختر مزود خدمة ضمن Search & Fetch، وأدخل العنوان أو المفتاح المطلوب واحفظ الحساب. لا يؤدي حفظ وصول الويب وحده إلى تفعيل مزود البحث أو جلب الصفحات أو إثبات عمله؛ بل تابع في Tools → Web search أو Web fetch → Provider لإضافة الخدمة المطلوبة واختبارها واختيارها.

يمتلك كل من البحث وجلب الصفحات اختيارات مستقلة. وقد يتطلب حساب النموذج المحلي وخدمة الويب التابعة للمزود نفسه عناوين أو مفاتيح مختلفة. راجع البحث في الويب وجلب الصفحات.

التحرير والإزالة

افتح اتصالاً حالياً لتغيير عنوان Base URL الخاص به أو إدارة المفاتيح المسماة. وتُختبر تغييرات نقطة نهاية النموذج قبل قبولها. يعيد خيار Use default العنوان المقدم من المزود وليس عنواناً مخمناً من اسم الحساب.

تضيف إضافة مفتاح خياراً بديلاً ولا تستبدل كل المفاتيح تلقائياً. راجع اسم المفتاح ومعاينته المقنّعة قبل إزالته. قد تترك إزالة الاتصال بيانات اعتماده متاحة لإعادة الاستخدام؛ فإزالة الحساب ليست وعداً بالمسح الآمن النهائي.

الوجهة والاختبار

قد يؤدي تغيير نقطة النهاية إلى إرسال بيانات الاعتماد والموجهات معاً إلى طرف آخر؛ فتحقق من الملكية والمنطقة الجغرافية المقصودة قبل الاتصال. تتطلب نقاط النهاية البعيدة التي تستخدم مفاتيح نقلاً مشفراً، بينما تُعد نقطة النهاية المحلية على الجهاز نفسه حالة محلية منفصلة.

إن اختبارات الاتصال والنماذج هي طلبات حقيقية وقد تترتب عليها تكلفة. وينطبق نجاح اختبار الحساب على الطلب المختبر تحديداً، وليس على كل نموذج أو أداة أو طول سياق أو استحقاق. يُفضل إجراء اختبار صغير ومدروس بعد فحص الخطأ الدقيق في السجلات.
