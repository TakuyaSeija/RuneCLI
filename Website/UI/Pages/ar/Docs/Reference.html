كل إعداد يمكنك تغييره في Rune {{.DocVersion}}، مجمعاً كما يجمعها ملف rune.toml: صف في نافذة Settings أو مفتاح في الملف. يعرض كل مدخل قيمة المصنع الافتراضية، ووظيفة الإعداد، والقيم التي يقبلها، ومتى يسري تغييره. القيم الثابتة التي تحفظ تشغيل Rune ليست إعدادات، ولا يمكن تغييرها، ولا تُذكر هنا.

قيمة المصنع هي القيمة المطبقة حتى تختار غيرها؛ وتظهر خياراتك المخصصة عبر الأمر rune -config explain <key>. أعد ضبط أي خيار بالأمر rune -config reset <key>. تتطلب المدد الزمنية والأحجام ذكر وحداتها، مثل "2m" أو "16MiB"؛ راجع ملف التكوين لتنسيقات القيم.
