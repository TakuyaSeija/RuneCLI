البحث والقراءة أداتان منفصلتان

تعثر أداة web_search على الصفحات انطلاقاً من استعلام بحث، بينما تقرأ أداة web_fetch صفحة HTTP(S) عامة واحدة كنص. وعند تمرير عنوان URL كاستعلام بحث فإنه يُبحث عنه ولا يُجلب تلقائياً. القارئ المدمج ليس متصفحاً تفاعلياً ولا يعد بجلب المحتوى المحمي بتسجيل الدخول أو التطبيقات التي تعتمد كلياً على تشغيل النصوص البرمجية.

يتطلب البحث خدمة مكونة، بينما يعتمد الجلب افتراضياً على قارئ الصفحات المدمج في Rune. وتمتلك الأداتان إعدادات تثبيت مزودين ومهل انتظار وميزانيات مخرجات مستقلة؛ فلا يؤدي تفعيل خدمة في إحداهما إلى اختيارها بصمت للأخرى.

إضافة حساب الوصول أولاً

في المسار Settings → Connections، أضف حساب Search & Fetch المقصود مع عنوانه وبيانات اعتماده. لا يُعد حفظ الوصول وحده دليلاً على أن الخدمة تعمل؛ فقد تكون نقطة نهاية النماذج ونقطة نهاية الويب لدى المزود نفسه خدمتين مختلفتين باستحقاقات مختلفة.

إضافة المزود واختياره

  1. افتح Settings → Tools → Web search أو Web fetch → Provider.
  2. اختر Add provider وحدد الحساب المتصل.
  3. بالنسبة للبوابات (gateways)، أدخل المسار الدقيق المقصود في الحقل الفارغ، ولا تستنتج مساراً من مثال أو اسم نموذج.
  4. يختبر Rune طلباً حقيقياً قبل الاحتفاظ بالمزود، وقد يرسل هذا الطلب استعلاماً أو عنوان صفحة وتترتب عليه تكلفة.
  5. عد إلى القائمة وحدد المزود المقصود. يختبر الاختيار ذلك الخيار الدقيق ويحفظه؛ أما الإضافة وحدها فلا تثبّته صراحةً.

يترك فشل الإضافة أو الاختيار الخيار السابق في مكانه. ويثبت نجاح الاختبار الطلب المختبر تحديداً، وليس وصولاً مستقبلياً غير مقيد لكل صفحة أو خدمة.

الخدمات التي يمكن لـ Rune استخدامها

تتطلب كل خدمة حساباً خاصاً بك لديها. ويستخدم Rune جزء البحث أو قراءة الصفحات المسمى هنا فقط، وليس كل منتج يبيعه المزود. وما لم يذكر الصف خلاف ذلك، فإن للخدمة عنواناً ثابتاً واحداً وتتطلب مفتاحاً.

الوضع الافتراضي والتثبيت الصريح

الافتراضي للبحث
عند عدم التعيين، يُستخدم أول مزود بحث مفعّل بحسب ترتيب الإضافة. ولذلك قد تؤدي إضافة أول مزود إلى جعله المزود الافتراضي المستخدم.
الافتراضي للجلب
استخدام القارئ المدمج. لا تؤدي إضافة قارئ خارجي إلى اختياره تلقائياً.
الاختيار الصريح
تثبيت حساب واحد أو زوج account:route واحد. وفي حال غيابه أو عدم توفره، لا ترسل الأداة الطلب بصمت إلى مزود مختلف.

استخدم خيار Use default أو أعد ضبط web_search.provider/web_fetch.provider لإزالة التثبيت المقابل. اختر بديلاً آخر قبل حذف مزود قيد الاستخدام؛ ويؤدي الحذف إلى إزالة مزود الأداة ذلك دون حذف الحساب أو المفاتيح. ويمكن لخدمة البوابة الاحتفاظ بما يصل إلى 32 مساراً محفوظاً.

الحدود والخصوصية

تبلغ قيم المصنع الافتراضية ثماني نتائج بحث، و60 ثانية لكل طلب أداة، و100,000 محرف معاد لكل أداة. ويمكن لعدد النتائج الممرر في الاستدعاء خفض الحد الأقصى للبحث. ولا يتجاوز سقف المخرجات الأكبر قيود الوصول.

تتلقى خدمة البحث الخارجية نص الاستعلام؛ ويتلقى القارئ الخارجي عنوان الصفحة وقد يحتسب تكلفة مقابل عمله. ويتصل الجالب المدمج بالموقع المطلوب مباشرة، بينما تُرفض الوجهات الخاصة أو الداخلية. ويقتصر التعامل الاختياري مع ملفات تعريف الارتباط (cookies) على عملية قراءة واحدة معادة التوجيه ولا ينشئ جلسة تسجيل دخول دائمة في المتصفح.
