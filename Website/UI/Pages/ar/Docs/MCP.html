القدرات الخارجية

يربط بروتوكول MCP خوادم خارجية تقدم أدوات أو موارد أو موجهات. استخدم الأمر /mcp أو rune -mcp؛ فهو ليس علامة تبويب منفصلة في نافذة الإعدادات الحالية. ويختلف الاتصال بالخادم عن الموافقة على كل مهمة تُنفذ عبر أداة.

يتلقى الخادم البعيد البيانات التي ترسلها إليه، بينما يشغّل الخادم المحلي شيفرة برمجية على هذا الحاسوب. ويُعامل النص المعاد كبيانات مهمة غير موثوقة حتى لو ادعى أنه يتضمن تعليمات ملزمة.

النطاق والموافقة

User
تعريفات شخصية متاحة عبر المشاريع المقصودة.
Project
تعريفات مشتركة في تكوين MCP الخاص بالمشروع. راجعها ووافق عليها صراحةً؛ وقد يتطلب التعريف المشترك المعدّل موافقة جديدة.
Private project
تعريفات شخصية لمشروع واحد، وهو النطاق الافتراضي لتغييرات MCP. ويمكنها تجاوز تعريفات المشروع المشتركة التي تحمل المعرّف نفسه، والتي تتجاوز بدورها تعريفات المستخدم الشخصية.

افحص الخوادم بخياري list/status وتحقق من صحة التعريفات قبل الاتصال. ولا يُعد التحقق من الصيغة اختبار اتصال حياً. يأخذ خيار الإضافة (add) معرّف الخادم وعنوان URL بعيداً مقصوداً أو مسار ملف تنفيذي محلي مطلق مع معاملاته. راجع مساعدة الأمر المثبت لديك لمعرفة الصيغة الدقيقة لكل عملية.

مراجعة الصلاحيات

قبل إضافة خادم أو تفعيله، افحص ملفه التنفيذي ومعاملاته أو وجهته البعيدة، وطريقة المصادقة، ومتغيرات البيئة، وصلاحية الكتابة في المشروع، ومجلدات القراءة/الكتابة الإضافية، والوصول إلى الخدمات المحلية الجارية بالفعل. امنح فقط ما تحتاجه المهمة.

تتطلب نقاط النهاية البعيدة بروتوكول HTTPS؛ ويقتصر بروتوكول HTTP العادي على الحلقة المحلية (loopback). لا تضمّن الأسرار في عنوان URL مشترك أو في قيم بيئة نصية صريحة، بل استخدم مسار بيانات الاعتماد المدعوم. وتُعد الملفات التنفيذية المحلية والمجلدات الجذرية الإضافية قرارات وصول حقيقية وليست مجرد تسميات وصفية.

قد تتطلب المجلدات الخارجية الإضافية موافقة في وضعي Ask وAuto قبل بدء الخادم المحلي. كما يمكن للوصول الواسع إلى الخدمات المحلية الاتصال ببرامج تعمل بصلاحيات حسابك. لا توسّع هذه الخيارات لمجرد إسكات خطأ اتصال فاشل.

الاتصال والاختبار والإزالة

list · status
فحص الخوادم المكونة وحالة الاتصال الحالية.
validate
التحقق من صحة التعريفات دون الادعاء بنجاح الاتصال.
connect <id> · test <id>
إجراء اتصال حقيقي، مما قد يشغّل شيفرة محلية أو يتصل بخدمة بعيدة.
approve <id>
الموافقة على تعريف مشترك تمت مراجعته. لا تمنح موافقة لملف لم تفحصه.
disconnect <id>
إغلاق ذلك الاتصال دون إزالة تعريفه المحفوظ.
enable|disable|remove <id>
تغيير توفر التعريف المقصود أو إزالته باستخدام نطاق التكوين الصحيح.
reload
تحديث الاتصالات المكونة.
login <id> · login-status <id>
بدء مسار مصادقة مدعوم أو فحص حالته.

تأتي هذه العمليات بعد الأمر rune -mcp، مثل rune -mcp status. راجع النطاق والمعرّف المحددين عند كل تغيير. تقبل أوامر بيانات الاعتماد المتقدمة مثل token/secret قيماً حساسة؛ لذا يُفضل استخدام واجهة المصادقة المدعومة بدلاً من وضع بيانات الاعتماد في سجل الصدفة.

قد تستخدم المصادقة رمز حامل (bearer token) أو مسار OAuth. لا تلصق الرموز السرية في المحادثة. ولا يُعد نجاح اتصال الخادم دليلاً على أن كل أداة آمنة أو قابلة للعكس أو مدعومة؛ إذ يكتشف النموذج مدخلات الأداة الدقيقة ويستخدم ضوابط التنفيذ المعتادة بدلاً من اختلاق واجهة API لخادم آخر.
