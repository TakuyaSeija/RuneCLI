التشغيل والفحص

شغّل هذه الأوامر في صدفة نظام التشغيل لديك. استخدم rune -help للاطلاع على مرجع النسخة المثبتة لديك. الأوامر التي تتصل بالمزودين أو تغيّر الحسابات أو تحذف البيانات أو تشغّل الخوادم هي عمليات فعلية وليست خيارات تشخيصية غير ضارة.

rune [dir]
فتح الوكيل التفاعلي في مساحة العمل الحالية أو المحددة.
rune -p "prompt"
تشغيل موجه واحد وطباعة الرد وتقدم الأدوات دون واجهة ملء الشاشة. تُرفض طلبات الأذونات بدلاً من الموافقة عليها بصمت لعدم وجود مستخدم يجيب عنها.
-project <dir>
تحديد مساحة العمل لأمر آخر.
-version · -help
طباعة إصدار التطبيق أو مرجع الأوامر.
-settings · -tools
فحص ضوابط النموذج الفعلية أو الأدوات المتاحة للوكيل.
-read-only
تقييد أدوات التعديل. لا يُعد هذا ضماناً بعدم قراءة أي ملف أو عدم إرسال أي بيانات.
--no-color
تعطيل الألوان. ويُدعم متغير البيئة NO_COLOR أيضاً.

التكوين

-config
عرض مسار ملف الإعدادات المحدد.
-config show|defaults|check
عرض القيم الفعلية، أو عرض قيم المصنع الافتراضية، أو التحقق من صحة الملف. قد يتضمن show بيانات وصفية خاصة بالحساب؛ ولا يثبت check نجاح الاتصال بالشبكة.
-config explain <key>
شرح القيمة الفعلية لمفتاح واحد وتوقيت سريانه.
-config set <key> <value>
حفظ خيار عام واحد. مثال: rune -config set terminal.command_timeout 2m.
-config reset <key>
إزالة التخصيص العام لتعود القيمة الافتراضية الحالية أو الوراثة إلى السريان.
-config format
إعادة تنسيق الإعدادات المجمعة دون تغيير معناها.
-set key=value
تغيير تفضيل مدعوم لمساحة العمل أو النموذج، وليس مفتاح تكوين عاماً عشوائياً.

الحسابات والنماذج

يُفضل استخدام محرر بيانات الاعتماد المقنّع ضمن Connections؛ إذ يمكن أن تتسرب المفاتيح الحقيقية الممررة في معاملات سطر الأوامر عبر سجل الصدفة وقوائم العمليات. تستخدم الصيغة أدناه عناصر نائبة عمداً.

rune -provider add <name> -key <key> [-preset <p>] [-base <url>] [-model <id>]
-provider list
سرد الحسابات والإعدادات المسبقة وتوفر خدمات الويب.
-provider key <name> <key>
إضافة مفتاح إلى حلقة مفاتيح الحساب. يغيّر هذا الأمر بيانات الاعتماد.
-provider keys <name>
فحص البيانات الوصفية المقنّعة للمفاتيح.
-provider dropkey <name> <n>
إزالة بيانات الاعتماد ذات الرقم المحدد بعد مراجعة هويتها.
-provider default <name>
اختيار المزود الاحتياطي للجلسات الجديدة؛ ولا يبدّل هذا المزود في كل المحادثات الحالية.
-provider remove <name>
إزالة تكوين المزود. لا تفترض أن كل بيانات الاعتماد المحفوظة قد مُسحت مسحاً آمناً نهائياً.
-provider test <name>
إرسال طلب حقيقي قد تُحتسب تكلفته لاختبار الحساب.
-provider models <name>
الاستعلام عن دليل نماذج الحساب. يجري هذا الأمر طلباً عبر الشبكة.
-provider dryrun <name> [model]
معاينة طلب دون إرساله. قد تتضمن المعاينة سياقاً خاصاً؛ فلا تشاركها كاملة دون مراجعة.
-provider timeout <name> <seconds>
تعيين مهلة اختيارية لطلبات الحساب بين 5 و3600 ثانية؛ وتزيل القيمة default التخصيص.
-provider new-store --yes
عزل زوج بيانات الاعتماد غير القابل للقراءة جانباً والبدء بمخزن فارغ. لا تستخدمه إلا بعد قرار استعادة مدروس؛ إذ سيتعين إضافة كل مفتاح من جديد.
-model list · -model set <id>
سرد النماذج أو اختيار نموذج لمساحة العمل المحددة.

الجلسات والتخزين

-session · -resume <id>
فتح منتقي الجلسات (أو سردها عند تمرير المخرجات عبر أنبوب) أو استئناف جلسة معروفة.
-session rename <id> <title>
إعادة تسمية جلسة واحدة.
-session delete <id>
حذف جلسة واحدة نهائياً. راجع هويتها أولاً.
-storage [list|prune]
فحص تخزين المشاريع أو إزالة البيانات المؤهلة التابعة لمشاريع لم تعد موجودة.
-sandbox [setup|reset]
فحص حالة عزل الأوامر على Windows، أو إعداد حسابه المخصص صراحةً، أو إزالة إعداد وصلاحيات معزل Rune. لا تستخدم المنصات الأخرى هذا الإعداد.

الامتدادات والتشخيص

-skills [operation]
سرد الأدلة القابلة لإعادة الاستخدام أو عرضها أو تفعيلها أو تعطيلها أو تثبيتها أو إعادة تحميلها. يأخذ التثبيت مجلداً أو ملف zip تمت مراجعته ويضعه في المشروع الحالي ما لم يجعله الخيار --scope user شخصياً.
-mcp [operation]
إدارة تعريفات الأدوات الخارجية والموافقة عليها والتحقق منها واختبارها. قد يبدأ الاتصال عملية محلية أو يتصل بخدمة بعيدة؛ ولا يعني التحقق الصوري وحده نجاح الاتصال.
--scope user|project|private-project
اختيار نطاق التكوين المدعوم لتغيير القدرات. تؤثر التغييرات المشتركة في المشروع على المستخدمين الآخرين لذلك المشروع.
-doctor
تشغيل فحوصات التشخيص بما في ذلك فحوصات الاتصال. قد يجري طلبات عبر الشبكة؛ راجع المخرجات قبل مشاركتها.
-db <path>
استخدام مخزن محرك بديل. وهذا منفصل عن اختيار مجلد إعدادات كامل عبر RUNE_HOME.
-host
استخدام تنسيق JSON المفصول بأسطر لتكامل الواجهات الأمامية بدلاً من الواجهة التفاعلية. وهو ليس خادم شبكة عاماً.
-script <file>
إعادة تشغيل نص برمجي مكتوب للنموذج. قد يقترح النص البرمجي أدوات حقيقية، لذا لا تشغّل نصاً غير مراجع على عمل فعلي.

لإعداد القدرات والوصول إليها، تابع القراءة في المهارات (Skills) أو اتصالات MCP. لا تنتقل إلى وضع Full أو تحذف البيانات المحلية لمجرد الالتفاف على خطأ.
