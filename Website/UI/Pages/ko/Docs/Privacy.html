로컬 실행이 곧 오프라인을 뜻하지는 않습니다

Rune은 사용자의 컴퓨터에서 실행되며 설정, 세션, 프로젝트 데이터를 로컬에 보관합니다. 별도의 Atoryn 계정을 요구하지 않으며 제품 텔레메트리(원격 사용 통계)도 수집하지 않습니다. 하지만 사용자가 연결한 계정, 카탈로그, 모델, 도구가 작동하는 데 필요한 네트워크 요청은 수행합니다.

원격 모델을 사용하면 요청에 필요한 관련 내용이 해당 제공자로 전송됩니다. 즉, 프로그램을 로컬에서 실행한다고 해서 모든 코드가 컴퓨터 안에만 머무르는 것은 아닙니다. 민감한 작업을 다룰 때는 전송 대상 주소, 모델 설정, 첨부 파일, 그리고 해당 제공자의 데이터 보관 정책을 먼저 확인하세요.

외부로 전송될 수 있는 항목

주 모델(Main model)
요청 처리에 필요한 프롬프트, 선택된 대화 컨텍스트, 도구 선언 및 실행 결과, 지원되는 첨부 파일.
보조 모델(Auxiliary models)
정책 검토, 지침 추출, 대화 요약, 제목 생성에 필요한 관련 텍스트. 별도로 구성한 제공자가 해당 부분 데이터를 수신할 수 있습니다.
검색 및 웹페이지 서비스
검색어, 또는 대상 웹페이지 주소와 서비스별 요청 데이터. 내장 리더는 대상 사이트에 직접 접속합니다.
MCP 및 명령어
외부 도구나 프로그램에 전달되는 데이터. 해당 도구나 명령어 자체의 네트워크 동작과 데이터 보관은 “로컬 에이전트”라는 말 하나로 통제되지 않습니다.
계정 테스트 및 카탈로그
인증 및 연결 테스트 요청과 모델 정보 조회 요청. 테스트 요청에는 요금이 부과될 수 있습니다.

다른 엔드포인트를 선택하는 것은 데이터가 어디로 전송될지 결정하는 일입니다. 명시적으로 고정(pin)해 둔 웹 제공자를 사용할 수 없을 때 다른 제3자 서비스로 요청을 몰래 넘기지 않습니다.

로컬에 보관되는 항목

선택된 Rune 홈에는 구성 파일, 암호화된 자격 증명, 대화 및 프로젝트 데이터, 메모리, 파일 복원용 스냅샷 데이터가 저장됩니다. 작업 공간을 바꾸더라도 이전 기록이 지워지지 않으므로 작업을 마친 뒤에도 비공개 프롬프트와 도구 출력이 세션 기록에 남아 있을 수 있습니다.

컨텍스트 압축(Compaction)은 모델에 전달할 컨텍스트를 줄일 뿐 디스크의 데이터를 완전 소거하는 기능이 아닙니다. 세션 삭제와 스토리지 정리(prune)는 사용자가 직접 실행하는 관리 작업입니다. 또한 연결을 삭제하더라도 모든 자격 증명이나 이전 요청 메타데이터가 디스크에서 완전히 지워졌다고 보장하지는 않습니다.

진단 정보 공유 시 주의 사항

로그, 컨텍스트 화면, 요청 미리보기(dry run), 유효 설정 출력에는 비공개 코드, 파일 경로, 계정 이름, 작업 설명이 포함될 수 있습니다. 자격 증명 마스킹 기능이 등록된 시크릿을 가리는 데 도움을 주지만 모든 비공개 문자열을 완벽히 제거한다고 보장할 수는 없습니다.

공유하기 전에 내용을 직접 검토하고 문제 해결에 필요한 가장 작은 발췌본만 공유하세요. 실제 API 키를 채팅, 버전 관리 시스템, 공개 버그 리포트에 절대 붙여넣지 마세요. 데이터 폴더 전체를 덤프해 올리는 대신 마스킹된 키 메타데이터와 최소 재현 예제를 사용하는 것이 안전합니다.

사용자가 제어할 수 있는 수단

의도한 작업 공간과 권한 모드를 선택하고, 꼭 필요한 파일만 첨부하며, 계정 엔드포인트를 확인하고, 필요한 경우 제공자 측의 데이터 보관 및 예산 제어 기능을 함께 사용하세요. 로컬 모델을 쓰면 원격 모델 제공자로의 데이터 노출을 줄일 수 있지만, 별도의 웹 도구나 보조 모델 경로 또는 셸 명령어는 여전히 외부 서비스와 통신할 수 있습니다.

-read-only는 변경 도구를 제한할 뿐 파일 읽기나 네트워크 전송을 막지 않습니다. 지출 경고는 강제 차단 한도가 아니며, 실행 취소(undo)는 로컬 파일을 복원할 뿐 이미 외부로 전송된 정보까지 회수할 수는 없습니다.
