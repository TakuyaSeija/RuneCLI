대화 화면

사용자 메시지, 모델의 응답, 도구 실행 단계는 하나의 대화 기록(transcript)에 함께 표시됩니다. 도구 단계는 수행하는 작업 이름과 그 결과를 보여 줍니다. 실패했거나 거부되었거나 실행되지 않은 호출은 완료된 작업이 아니므로, 박스가 표시되었다는 것만으로 성공했다고 단정하지 말고 안내 문구를 확인하세요.

긴 사용자 메시지와 도구 실행 결과는 화면에서 접혀 표시됩니다. “lines cut. Click to open all” 같은 하단 문구를 클릭하면 접혀 있던 전체 결과를 펼쳐 볼 수 있습니다. 이는 도구 출력 한도(limit)와는 다릅니다. 화면 접기를 펼쳐도 애초에 한도를 넘어 반환되지 않은 텍스트까지 복구되지는 않으며, 저장된 전체 출력이 있는 경우 별도의 안내 문구가 에이전트에 나머지 텍스트를 읽을 위치를 알려 줍니다.

접혀 있는 명령어 박스는 스트리밍 중일 때나 실행 중일 때, 그리고 종료된 후에도 명령어를 한 줄로 요약해 보여 줍니다. 여러 줄로 된 스크립트의 줄바꿈은 ↵로, 너비를 넘어가는 뒷부분은 …로 표시되며, 두 기호 모두 화면 표시용일 뿐 실제로 실행되는 명령어에는 포함되지 않습니다. 출력 결과는 최대 4줄까지 미리 표시되고 숨겨진 명령어 및 출력 줄 수가 하단에 안내됩니다. 박스를 클릭하면 원래 줄바꿈이 유지된 전체 명령어와 전체 출력이 펼쳐집니다.

대화 기록에서 링크를 클릭하면 전체 주소가 담긴 REFERENCE 패널이 열립니다. 웹 주소인 경우 Open in browser를 누르거나 Enter를 치면 시스템 기본 브라우저로 열리고, Copy complete destination이나 C를 누르면 주소가 복사되며, Esc를 누르면 패널이 닫힙니다. 로컬 파일 경로는 복사만 가능하며, Rune은 링크를 통해 파일을 직접 열거나 실행하지 않습니다.

입력창(Composer)

화면 하단의 입력창에는 다음에 보낼 메시지를 작성하며, 현재 선택된 모델과 추론 강도(지원 시), 권한 모드가 함께 표시됩니다. Enter는 메시지를 전송하고 Alt+Enter는 줄바꿈을 넣습니다. 여러 줄을 입력해 입력창이 커지더라도 대화 내용을 볼 수 있도록 일정 높이까지만 늘어납니다.

/를 입력하면 명령어 팔레트가 열리며 명령어 이름이나 설명으로 필터링할 수 있습니다. 팔레트가 열려 있을 때 Tab을 누르면 자동 완성되고, 폼이나 팔레트 밖에서 Tab을 누르면 권한 모드가 순환됩니다. 터미널이 특정 조합 키를 가로채는 경우 단축키가 Rune에 전달되지 않을 수 있으니 /help를 참고하세요.

첫 글자로 !를 입력하면 AI에게 보내는 메시지가 아니라 사용자가 직접 실행하는 셸 명령어가 됩니다. 이때 입력창에는 Shell · full access once가 표시됩니다. 사용하기 전에 먼저 수동 명령어 문서를 읽어 보세요.

사이드 패널

Sessions
세션 제목, 시작 시각, 활동 시간 및 단계 수, 컨텍스트 사용량, 입력/출력/캐시 토큰 수, 지출 비용을 표시합니다. 알 수 없는 한도나 가격은 0이 아니라 미확인 상태로 표시됩니다.
Plan
에이전트가 기록한 작업 목록을 대기(todo), 진행 중(doing), 완료(done) 상태로 보여 줍니다. 완료로 표시된 항목은 에이전트 자체의 진행 보고일 뿐 작업이 올바르게 끝났다는 독립적인 증거는 아닙니다.
Files changed
현재 세션이 추적 중인 파일들의 변경 내역을 추가·삭제된 줄 수와 함께 보여 줍니다. 줄 수는 각 편집 단계의 단순 합계가 아니라 실제 파일 내용의 차이를 반영합니다.

Ctrl+O 또는 /panel로 사이드 패널을 켜거나 끌 수 있습니다. 터미널 폭이 너무 좁으면 패널이 자동으로 숨겨질 수 있으며, 패널을 숨기더라도 사용량 집계나 기록 데이터가 지워지지는 않습니다. Ctrl+T를 누르면 계획을 엽니다.

질문 및 권한 승인

권한 카드는 제안된 개별 작업을 실행해도 되는지 묻고, 질문 폼은 결정 사항이나 누락된 요구 사항을 묻습니다. 두 경우 모두 아직 완료된 도구 결과가 아닙니다. 적용 범위를 확인한 뒤 응답을 고르고 확정하세요. 기억된 승인 옵션이 제공되더라도 해당 컨트롤에 명시된 범위 안에서만 적용됩니다.

내용이 긴 카드는 자체 스크롤 영역과 하단 고정 응답 버튼을 갖습니다. 카드를 스크롤하는 것만으로는 응답이 제출되지 않으며, 대기 시간이 만료되더라도 자동 승인되지 않습니다. 기본 권한 대기 시간은 10분이며, 사용자 질문은 별도로 설정하지 않는 한 만료 없이 응답을 기다립니다.

상태 표시줄 및 읽기

하단 상태 표시줄은 작업 중, 사용자 응답 대기 중, 재시도 중, 컨텍스트 압축 중 상태를 구분해 보여 줍니다. 메시지를 보낸 뒤 입력창이 비워졌다고 해서 제공자가 요청을 정상 수신했다는 뜻은 아니므로, 지연이 발생하면 상태 표시줄과 /logs를 함께 확인하세요.

임시 상태 메시지는 8초 동안 표시됩니다. 다른 메시지나 재시도 카운트다운이 대기 중이면 3초 후 자리를 양보하며, 그 동안에도 재시도 타이머는 계속 흐릅니다. Esc와 Ctrl+C 확인 안내는 언제나 최우선으로 표시됩니다. AI 작업을 멈추려면 3초 안에 Esc를 한 번 더 누르고, Rune을 종료하려면 4초 안에 Ctrl+C를 한 번 더 누르세요.

최신 메시지에서 위로 스크롤하면 읽던 위치가 그대로 고정됩니다. Ctrl+↓를 누르면 최신 대화 위치로 즉시 이동합니다. Settings, 로그, 컨텍스트, 복원 화면은 각각 독립된 탐색 키를 사용하며, 유휴 상태에서 Esc를 누르면 해당 화면을 닫습니다.
