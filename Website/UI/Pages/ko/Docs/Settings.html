열기 및 탐색

Ctrl+G를 누르거나 /settings(또는 별칭 /*)를 입력하세요. 개요 화면은 여섯 개 섹션으로 연결됩니다. 방향키로 행이나 카드를 고르고 Enter로 엽니다. Tab/Shift+Tab은 포커스를 이동하고, Esc는 편집기를 취소하거나 한 단계 위로 돌아갑니다. 화면 하단에는 현재 선택한 컨트롤에 대한 설명이 표시됩니다.

값을 열고 수정한 뒤 Apply를 선택하세요. Cancel을 누르면 이전 값이 유지됩니다. 일부 선택 행은 좌우 방향키로 값을 바꿀 때 즉시 저장되므로 안내 문구를 읽고 저장 완료 메시지를 확인하세요. 별도의 선택 창에서 항목에 커서만 올린 상태로는 아직 적용된 것이 아닙니다.

설정 섹션별 역할

Models
연결된 계정의 모델을 둘러보고, 제공자/모델 쌍을 적용하며, 카탈로그를 새로고침하고, Alt+C로 모델 기능 및 가격 정보를 영구 설정합니다.
Generation
현재 세션의 추론 강도, 샘플링, 요청 출력 길이를 설정합니다. 전역 보조 모델 제어 항목은 같은 페이지 아래쪽에 있습니다.
Connections
API 주소와 이름이 지정된 키 등 계정 접근 정보를 관리합니다. 웹 검색 제공자 선택이나 모델 요청 타임아웃은 여기서 다루지 않습니다.
Runtime
모델 요청 타임아웃, 재시도 동작, 키 링 순환, 공통 연결 및 스트림 대기 시간을 설정합니다.
Tools
도구별 대기 시간과 출력·작업 한도, 질문 및 권한 응답 기한, 개별 웹 제공자 선택을 관리합니다.
Appearance
테마와 대화 사이드 패널 표시 여부를 설정합니다. 터미널 배경 이미지, 블러, 투명도는 다루지 않습니다.

전역 설정과 세션 설정

도구 한도, 재시도 및 네트워크 설정, 보조 모델 선택은 현재 선택된 Rune 홈 전체에 전역으로 적용됩니다. 반면 주요 Generation 제어 항목과 모델 선택은 현재 활성 세션 및 모델에 적용되며, 저장된 모델별 환경설정은 나중에 해당 모델을 다시 선택할 때 불러올 수 있습니다.

전역 [generation] 테이블은 시작 기본값을 제공할 뿐, 기존에 열려 있는 모든 세션의 설정을 덮어쓰지 않습니다. 새 세션 기본 제공자(New-session fallback) 역시 앞으로 만들 세션의 시작 제공자를 정할 뿐 현재 열려 있는 대화들의 제공자를 바꾸지 않습니다.

초기화 및 적용 시점

Use default는 저장된 전역 재정의 값을 제거하여 현재 버전의 기본값이나 상위 상속값이 적용되도록 되돌립니다. 초기 기본 숫자를 직접 입력해 저장하는 것은 명시적인 값 지정이므로 설정을 비워 두는 것과는 다릅니다. 선택 사항인 세션별 Generation 값은 입력란을 비우면 제공자 또는 기본 설정으로 제어권이 돌아갑니다.

설정을 변경하면 보통 Rune을 재시작하지 않아도 바로 반영됩니다. 일부 항목은 즉시(live) 적용되고, 다른 항목은 진행 중인 작업에는 시작 당시 설정을 유지한 채 다음 작업부터 새 값을 적용합니다. 개별 설정 키의 정확한 적용 시점은 rune -config explain <key>로 확인하세요. 분류기 정책은 별도의 명시적 다시 읽기(reload) 절차를 따릅니다.

변경 전 확인 사항

설정 문법이 유효하다고 해서 실제 연결이 작동한다는 뜻은 아니며, Configured 상태가 계정에 잔액이 있음을 보장하지도 않습니다. 연결 테스트는 실제 요청을 전송하므로 비용이 발생할 수 있습니다. 제공자를 바꾸면 데이터가 전송되는 대상이 달라질 수 있고, 재시도 횟수나 출력 한도를 늘리면 지출이 늘어날 수 있습니다.

모든 고급 옵션이 UI 행으로 노출되어 있지는 않습니다. 구성 파일 가이드에서 임의의 설정을 추측하거나 관련 없는 설정을 건드리지 않고 고급 옵션을 확인하고 초기화하는 방법을 살펴보세요.
