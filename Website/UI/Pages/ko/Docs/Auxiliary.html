전역 보조 작업

Settings → Generation 아래쪽의 보조 모델(Auxiliary) 항목들은 선택된 Rune 홈을 사용하는 모든 세션에 공통으로 적용됩니다. 현재 활성 모델을 그대로 상속받거나, 별도의 제공자/모델 쌍을 명시적으로 지정할 수 있습니다. 보조 모델을 변경하면 비용, 지연 시간, 그리고 관련 데이터를 전송받는 제공자가 달라질 수 있습니다(이 설정 확인이 다른 무관한 작업에 대한 승인을 의미하지는 않습니다).

설정한 출력 토큰 허용량은 선택한 모델의 실제 한도와 제공자의 전체 요청 크기 한도 안에서만 작동합니다. Settings에서 숫자를 크게 적어 넣어도 서비스 자체의 한도가 늘어나지는 않습니다. 임시 플레이스홀더 모델 이름을 지어내어 넣지 말고 재정의를 초기화(reset)해 활성 모델을 상속받도록 하세요.

추론이 필요한 보조 모델은 더 큰 실효 출력 한도가 필요할 수 있습니다. Rune은 그런 모델에 자체 하한(기본 4,096 토큰)을 주어 쓸 만한 결과가 들어가도록 합니다. 이 하한은 상수이며 설정이 아니고, 모든 작업에 더해지는 값도 아닙니다.

정제기(Sanitizer)

정제기는 분류기(Classifier)가 사용자의 원래 지침과 제약 사항을 정확히 식별할 수 있도록 돕습니다. 파일을 청소하거나, 모든 메시지에서 특수 유니코드를 지우거나, 대화 내용을 새로 고쳐 쓰는 도구가 아닙니다. 오직 분류기 검토가 적용되는 상황에서만 실행되며, 추출을 사용할 수 없을 때는 원래 지침으로 대체(fallback)되지만 그렇다고 제약 조건이 해제되지는 않습니다.

초기 기본값
활성화됨(enabled), 활성 모델 상속, 요청 타임아웃 120초, 출력 토큰 4,096개, 원본 텍스트는 최대 64 KiB 묶음 단위로 전송.
관련 설정 키
sanitizer.enabled, sanitizer.model, sanitizer.timeout, sanitizer.max_output_tokens, sanitizer.max_batch_size.

묶음 크기(batch size)는 토큰이 아니라 텍스트의 바이트 단위입니다. 크기를 줄이면 요청 횟수가 늘어날 수 있고, 제공자가 허용하는 한도보다 크게 설정하면 제공자가 요청을 거부합니다.

분류기(Classifier)

정책 검토 모델은 제안된 작업들을 사용자의 CLASSIFIER.md 규칙에 비추어 평가합니다. Ask 모드에서는 비활성 상태이며, Auto 또는 Full 모드에서는 유효한 정책 파일이 있을 때 작동합니다. 사용자에게 직접 승인을 묻는 호출은 AI 분류기 검토 대신 사용자의 명시적 결정을 따릅니다. 활성화 플래그가 켜져 있다는 것만으로 특정 작업이 검토되었다고 단정할 수는 없습니다.

초기 기본값은 활성화됨, 활성 모델 상속, 타임아웃 120초, 출력 토큰 1,024개, 결합 텍스트 증거 최대 256 KiB, 정책 파일당 최대 64 KiB입니다. 검토 제외 도구 목록과 최근 입력 컨텍스트 목록은 별도로 설정합니다. 권한 범위, 다시 읽기(reload), 실패 시 동작은 분류기 정책을 참고하세요.

컨텍스트 압축(Compaction)

컨텍스트 압축은 모델 컨텍스트 여유 공간을 확보하기 위해 오래된 대화 기록을 요약합니다. /compact로 수동 요청할 수 있으며, 제공자가 보고한 입력 토큰 사용량에 따라 또는 제공자가 컨텍스트 초과로 요청을 거부한 뒤 Rune이 자동으로 실행하기도 합니다. Rune은 텍스트나 사고 과정, 이미지 크기로 토큰 수를 어림짐작하지 않습니다. 요약본은 모든 세부 사실의 완벽한 복사본이 아니며, 디스크에 저장된 세션을 삭제하지도 않습니다.

설정 키초기 기본값 / 설명
compact.model현재 활성 모델을 상속받습니다.
compact.max_output_tokens요청할 요약 출력 토큰 수(32,768개)로, 모델 한도 내에서 적용됩니다.
compact.max_batch_size요약 요청당 인용할 대화 기록 텍스트 크기(128 KiB). 토큰이 아닌 바이트 단위이며, 소형 요약 모델이 요청을 거부하면 이 값을 낮추세요.
compact.keep_recent_turns원문 그대로 유지할 최근 턴 수(5턴)이며, 가용 컨텍스트에 따라 더 적게 유지될 수 있습니다.
compact.fallback_context_tokens모델이 컨텍스트 창 크기를 공개하지 않을 때 Rune이 자동 압축을 시작하는 기준 입력 토큰 수(보고된 입력 토큰 200,000개). 알려진 한도를 늘리거나 텍스트 길이로 토큰을 추정하지 않습니다.
compact.message_chars메시지당 고려할 이전 어시스턴트 응답 및 도구 결과 텍스트 글자 수(32,000자).
compact.tool_chars도구 호출당 고려할 이전 인수 글자 수(2,000자).

사용자의 원래 지침은 어시스턴트 응답이나 도구 발췌본과 분리되어 묶음 단위로 처리되며 조용히 잘려 나가지 않습니다. 만약 지정한 요약 모델이 컨텍스트 크기 문제로 요청을 거부하면 더 큰 활성 모델이 대신 사용될 수 있습니다. 필수 압축이 실패하면 재시도 여부를 묻고, 취소하거나 거절하면 시도를 중단하며 실패한 요약은 완료로 처리되지 않습니다.

제목 생성 및 초기화

제목 생성 작업은 대화 초반의 관련 작업 내용을 바탕으로 세션 제목을 짓습니다. 기본적으로 활성 모델을 상속받으며 최대 256개의 출력 토큰을 요청하고 제목 길이를 60자로 제한합니다. 이 설정을 변경하면 앞으로 생성될 제목에만 적용되며 기존 제목들은 바뀌지 않습니다(특정 세션 제목을 바꾸려면 세션 이름 변경 기능을 사용하세요).

개별 설정 키는 rune -config explain <key>로 확인하세요. Use default 또는 rune -config reset <key>로 전역 재정의를 제거할 수 있습니다. 검토 예산을 줄이면 검토 범위가 좁아질 수 있고 보조 모델 작업을 늘리면 비용이 증가할 수 있으므로, 전역 값을 바꾸기 전에 구체적인 영향을 먼저 확인하세요.
