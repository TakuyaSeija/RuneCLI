대화 및 애플리케이션 단축키

Enter · Alt+Enter
메시지를 전송하거나 줄바꿈을 삽입합니다. 수정자 키와 결합된 Return 입력은 터미널이 전달하는 방식에 따라 달라질 수 있습니다.
Ctrl+G · Ctrl+O
Settings를 열거나 사이드 패널을 켜고 끕니다.
Ctrl+T · Ctrl+R
계획(Plan)을 열거나, 도구 실행 단계 및 사고 과정을 펼치고 접습니다. 세션 선택기에서는 Ctrl+R이 이름 변경을 엽니다.
Alt+T
선택한 모델에서 사용할 수 있는 추론 강도 옵션을 순환합니다.
Tab
슬래시 명령어를 자동 완성하거나 권한 모드를 순환합니다. 폼 화면에서는 폼 자체의 포커스 이동으로 작동합니다.
Esc 두 번
진행 중인 AI 작업을 중지합니다. 첫 번째 입력 시 확인 안내가 나타나고, 3초 이내에 두 번째로 누르면 중지됩니다. 유휴 상태의 화면에서는 Esc 한 번으로 창을 닫습니다.
Ctrl+C 두 번
Rune을 종료합니다. 첫 번째 입력은 종료 대기를 활성화할 뿐 진행 중인 턴을 취소하거나 작성 중인 초안을 지우지 않습니다.
Ctrl+L · Ctrl+↓
화면을 다시 그리거나 최신 대화 위치로 즉시 이동합니다.

텍스트 편집

아래 키 바인딩은 입력창, 편집 가능한 답변란, Settings 입력란, 모델 검색, MCP 입력란, 세션 검색 및 이름 변경에서 공통으로 작동합니다. 목록과 버튼에는 별도의 이동 키가 적용됩니다. 논리적 줄(logical line)은 실제로 삽입된 줄바꿈 문자로 구분되며, 화면상의 줄(visual row)은 창 너비에 따라 자동 줄바꿈된 줄일 수 있습니다.

키동작
← / →화면에 보이는 글자 한 칸씩 이동합니다.
Ctrl+← / Ctrl+→공백으로 구분된 이전 단어의 시작 / 다음 단어의 끝으로 이동합니다.
↑ / ↓현재 열 위치를 유지하면서 화면 줄(visual row) 단위로 위아래 이동합니다.
Ctrl+A / Ctrl+E현재 논리적 줄의 맨 앞 / 맨 끝으로 이동합니다.
Home / End전체 입력 텍스트의 맨 처음 / 맨 끝으로 이동합니다.
Backspace / Delete커서 앞 / 뒤의 글자나 선택 영역을 삭제합니다.
Ctrl+U / Ctrl+K논리적 줄 경계까지 앞쪽 / 뒤쪽 텍스트를 잘라냅니다(kill). 줄바꿈 위치에서 Ctrl+K를 누르면 해당 줄바꿈만 제거하며 입력 끝에서는 아무 동작도 하지 않습니다.
Ctrl+W / Alt+D왼쪽 / 오른쪽의 공백 구분 단어를 해당 방향의 인접 공백과 함께 잘라냅니다.
Ctrl+Y / Alt+Y가장 최근에 잘라낸 텍스트를 붙여넣거나(yank), 붙여넣은 직후 이전 잘라내기 기록을 순환합니다.
Ctrl+_ / Alt+R현재 입력란에서 텍스트 편집을 실행 취소(undo) / 다시 실행(redo)합니다.
Shift+←/→/↑/↓글자 또는 화면 줄 단위로 선택 영역을 확장합니다.
Ctrl+Shift+← / →단어 단위로 선택 영역을 확장합니다.
Alt+X / Alt+W인접한 두 글자 / 두 단어의 위치를 맞바꿉니다.
Alt+U / Alt+L / Alt+V다음 단어 또는 선택한 텍스트를 대문자 / 소문자 / 첫 글자만 대문자로 변환합니다.

텍스트를選択한 상태에서 글자를 입력하거나 붙여넣거나 삭제하면 선택 영역이 대체됩니다. 임시 실행 취소 기록과 잘라낸 텍스트 버퍼는 해당 입력란에만 속하며 일정 한도까지만 유지되고 입력란이나 세션이 바뀌면 비워집니다(파일 백업이 아닙니다). 또한 Rune은 Readline의 모든 별칭을 다 지원하지는 않습니다(예: Ctrl+B/F 및 Alt+B/F는 커서 이동 키로 작동하지 않습니다).

기록 탐색 및 읽기

입력창에서 위/아래 방향키는 먼저 화면에 보이는 텍스트 줄 사이를 이동하고, 맨 처음이나 끝에 도달한 뒤에 이전 프롬프트 입력 기록을 불러옵니다. PgUp/PgDn을 누르면 입력 기록을 바로 탐색합니다. 입력 기록은 해당 세션에 귀속됩니다.

마우스 휠 한 칸은 설정된 줄 수(기본값 2줄)만큼 스크롤합니다. 터미널이 전달해 주는 경우 Ctrl+휠이나 Alt+휠은 세 배 빠르게 이동합니다. 터미널이 이 제스처를 화면 확대/축소나 가로 스크롤용으로 예약해 둔 경우에도 일반 휠과 키보드 스크롤은 언제나 사용할 수 있습니다.

마우스 조작

클릭하면 텍스트 커서를 놓거나 컨트롤을 활성화합니다. 텍스트 위를 드래그한 뒤 마우스 버튼을 놓으면 텍스트가 복사되며, 클립보드에 복사가 완료되면 하이라이트가 사라집니다. 대화 영역에서 드래그하면 사이드 패널이나 Rune의 박스 테두리 문자를 제외한 해당 본문 영역만 깔끔하게 복사되며, 표는 탭으로 구분된 셀 형태로 복사됩니다. 접혀 있는 명령어를 복사하면 화면 표시용 기호인 ↵와 … 없이 원래의 줄바꿈 그대로 복사됩니다. 입력란 안에서 드래그하면 커서 위치를 옮기거나 작성 중인 초안을 덮어쓰지 않고 텍스트만 복사합니다(편집을 위해 텍스트를 선택하려면 Shift+방향키를 사용하세요). 마스킹된 시크릿 입력란은 절대 복사되지 않습니다.

복사한 내용이 전달되려면 터미널이 클립보드 쓰기를 허용해야 합니다(SSH나 멀티플렉서가 이를 차단할 수 있습니다). 터미널이 지원하는 경우 Shift+드래그를 사용하면 테두리를 포함한 터미널 자체 선택 기능을 대신 사용할 수 있습니다. ui.mouse = false로 설정하면 모든 마우스 선택을 터미널이 직접 처리합니다.

링크를 클릭하면 REFERENCE 패널이 열립니다. Enter는 웹 주소를 브라우저에서 열고, C는 전체 주소를 복사하며, Esc는 패널을 닫습니다. 링크 위를 드래그하면 텍스트만 복사되며 링크가 열리지 않습니다.

목록 및 폼 조작

방향키로 항목을 고르고 Enter로 열거나 확정합니다. Tab/Shift+Tab으로 포커스를 이동하고, Esc로 편집기를 취소하거나 한 단계 이전으로 돌아갑니다. Models 화면에서는 Ctrl+F가 검색창으로 포커스를 옮기고, Alt+C가 모델 구성을 열며, T가 실제 요청으로 모델을 테스트하고, Delete가 선택한 항목의 로컬 구성을 삭제합니다.

질문 폼에서는 Alt+Left/Right로 질문 간에 이동하고, 일반 Left/Right로 텍스트를 편집하거나 버튼을 선택합니다. Page 키는 내용이 긴 카드를 스크롤해 읽을 뿐 응답을 제출하지 않습니다. 직접 입력란(custom answer) 안에서 위/아래 방향키를 누르면 먼저 입력란 내부 텍스트를 이동한 뒤 밖으로 나갑니다. 마우스 드래그는 아래에 있는 버튼을 누르는 대신 텍스트를 선택합니다.

터미널별 차이

단축키는 터미널이 해당 키 입력을 Rune에 전달해 줄 때만 작동합니다. 운영체제 단축키, 터미널 프로필, 전통적인 제어 문자 인코딩이 특정 키 조합을 선점할 수 있습니다. 배경색, 블러, 투명도 역시 Rune이 아니라 터미널 자체 설정에 속합니다. 셸 키맵이 그대로 적용될 것이라 가정하지 말고 현재 설치된 빌드의 /help를 확인하세요.
