색상 테마

Settings → Appearance → Color theme에서는 Violet, Cyan, Amber 테마를 제공합니다. 행 위에서 좌우 방향키를 누르면 테마가 바로 전환되어 저장되며, Enter를 누르면 별도의 목록이 열리고 여기서 Enter를 눌러 선택한 테마를 적용할 수 있습니다(목록만 둘러보고 Esc를 누르면 변경 없이 나갑니다). 초기 기본 테마는 Amber입니다.

테마는 화면 표시 스타일일 뿐 모델의 동작이나 권한에는 아무런 영향을 주지 않습니다. /theme violet, /theme cyan, /theme amber 명령어로도 테마를 바꿀 수 있습니다. 전역 구성 키는 ui.theme이며 초기화(reset)하면 사용자 재정의를 제거합니다.

대화 사이드 패널

Appearance 화면, Ctrl+O 단축키, 또는 /panel 명령어로 사이드 패널을 켜거나 끌 수 있습니다. 초기 기본값은 켜짐(enabled)입니다. 단, 터미널 폭이 좁으면 설정이 켜져 있더라도 나란히 배치되는 사이드 패널이 자동으로 숨겨질 수 있습니다. 패널을 숨기더라도 사용량 집계, 파일 변경 추적, 계획 관리는 중단되지 않고 그대로 작동합니다.

터미널이 담당하는 영역

배경 이미지, 투명도, 블러 효과, 창 테두리 장식, 글꼴 렌더링은 사용자의 터미널 및 데스크톱 환경이 직접 제어합니다. Rune에는 별도의 배경 이미지나 블러 설정이 없습니다. 또한 동일한 테마라도 터미널 배경이 밝은지 어두운지에 따라 다르게 보일 수 있습니다.

수정자 키 조합과 마우스 제스처 역시 터미널 환경에 따라 달라집니다. 터미널 프로필이 화면 확대/축소용으로 Ctrl+휠을, 가로 스크롤용으로 Alt+휠을, 또는 자체 동작을 위해 특정 단축키를 예약해 두고 있을 수 있습니다.

고급 표시 옵션

일부 색상, 마우스, 스크롤 및 렌더링 타이밍 값은 Appearance 화면의 UI 메뉴가 아니라 TOML 파일에서만 설정할 수 있는 고급 옵션입니다. 변경하기 전에 문서화된 개별 키의 설명을 먼저 확인하세요. 화면 새로고침 빈도를 높이면 시스템 리소스를 더 많이 소모할 수 있으며, 스크롤 설정을 바꾼다고 해서 터미널이 지원하지 않는 입력 이벤트를 전달하게 만들 수는 없습니다.

rune -config explain ui.theme
rune -config reset ui.theme

초기화(reset)는 전역 환경설정을 변경합니다. 읽기 및 탐색 단축키는 다른 터미널 프로그램의 방식을 추측하지 말고 /help에서 직접 확인하세요.
