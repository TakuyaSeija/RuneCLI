Rune {{.DocVersion}}에서 변경할 수 있는 모든 설정 항목을 rune.toml의 그룹 구조와 동일하게 정리한 레퍼런스입니다. Settings 화면의 행이나 파일의 키로 설정합니다. 각 항목은 초기 기본값, 프로그램 내 역할 설명, 허용되는 값 범위, 그리고 변경 사항이 적용되는 시점을 안내합니다. Rune 자체의 고정값 — 동작을 유지하는 값 — 은 설정이 아니므로 변경할 수 없으며 여기에 표시하지 않습니다.

기본값은 사용자가 별도로 값을 지정하기 전까지 적용되는 초기 설정입니다. 현재 적용 중인 내 설정은 rune -config explain <key>로 확인하고, 기본값으로 되돌리려면 rune -config reset <key>를 실행하세요. 시간(duration)과 크기(size) 값에는 "2m"이나 "16MiB"처럼 단위를 함께 적어야 합니다. 자세한 값 형식은 구성 파일을 참고하세요.
