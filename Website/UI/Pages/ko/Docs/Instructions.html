프로젝트 지침

작업 공간 루트에 있는 AGENTS.md는 빌드 명령어, 코딩 규칙, 작업 경계 등 프로젝트 지침을 모델에 제공합니다. 이 파일은 API 키 보관소나 권한 부여 수단, 또는 분류기 정책 파일이 아닙니다. 자격 증명은 절대 넣지 말고, 모델 컨텍스트로 전송해도 되는 내용만 작성하세요.

자동으로 불러오는 프로젝트 지침의 기본 한도는 32,768자이며, Settings → Tools → Project instructions의 instructions.max_chars 설정으로 조절할 수 있습니다. 파일 크기가 한도를 넘으면 Rune은 생략된 뒷부분이 있음을 알리고, AI는 해당 규칙에 의존하기 전에 나머지 부분을 파일 도구로 읽습니다(뒷부분이 사라지는 것이 아닙니다). 세션 도중 지침 파일이 변경되면 Rune은 모델이 관련 원본을 다시 읽도록 알릴 수 있습니다.

원하는 파일 첨부하기

/attach <path>는 다음 메시지에 파일을 추가하고, /detach <number|all>는 대기 중인 첨부 파일을 제거합니다. 메시지를 보내기 전에 첨부 대기 목록을 확인하세요. 모델마다 텍스트, 이미지, 기타 미디어를 지원하는 방식이 다르며, 파일이 첨부되었다고 해서 모델이 그 내용을 항상 이해할 수 있다는 뜻은 아닙니다.

전송된 첨부 파일은 전송 시점의 파일 버전을 가리킵니다. 나중에 해당 경로의 파일을 수정하더라도 이전 메시지에 첨부되었던 내용이 새 바이트로 바뀌지 않습니다. 만약 원본 내용을 더 이상 복구할 수 없으면 Rune은 새 내용을 예전 내용인 것처럼 꾸미지 않고 파일이 변경되었거나 사라졌다고 정직하게 알립니다. 수정한 새 버전이 작업에 필요하다면 새 파일을 다시 명시적으로 첨부하세요.

기본 한도는 첨부 텍스트 파일당 60,000자, 이전 대화의 첨부 파일 최대 10개입니다. 컨텍스트 및 제공자 페이로드 한도에 따라 오래된 미디어가 더 일찍 제외될 수 있습니다. 이는 현재 메시지의 첨부 파일이나 화면상의 대화 접기(fold)와는 별개입니다.

프로젝트 메모리

Rune은 MEMORY.md 인덱스를 통해 세션이 끝나도 유지되는 프로젝트 메모를 지원합니다. 메모가 저장되는 위치와 모델에 전달되는 범위는 메모리 문서에서 자세히 다룹니다. 모델은 모든 메모를 한꺼번에 받지 않고 인덱스만 먼저 전달받으며, 필요할 때 관련 메모를 직접 읽습니다. 인덱스 불러오기 예산은 기본 20 KiB이며, 이 값을 늘리면 모델 컨텍스트를 더 많이 소모할 뿐 메모 내용의 정확도가 높아지지는 않습니다.

메모리는 지속적으로 유지할 결정 사항, 수정 지시, 진행 중인 작업 기록에 활용하세요. 자격 증명이나 일시적인 명령어 실행 결과를 저장하는 곳이 아닙니다. 메모 내용은 이후 모델 요청에 포함될 수 있으며 별도의 권한 부여 수단이 아닙니다. 모델은 저장소 안에 메모리 폴더를 만드는 대신 @memory/ 경로와 파일 도구를 통해 프로젝트 메모리에 접근합니다.

파일별 목적 구분하기

AGENTS.md
모델 컨텍스트로 전달되는 프로젝트 지침입니다.
CLASSIFIER.md
AI 작업 검토에 적용되는 사용자 정책 파일입니다. 명시적인 다시 읽기(reload) 절차를 따르며 프로젝트 지침과는 별개입니다.
rune.toml
선택된 Rune 홈 폴더에 있는 설정 파일입니다. 프로젝트 안에 같은 이름의 파일이 있더라도 자동으로 전역 설정 파일이 되지는 않습니다.
Skill
작업을 위해 활성화하거나 읽는 재사용 가능한 가이드입니다. 스킬 자체만으로는 접근 권한을 부여할 수 없습니다.

저장소 내 텍스트, 웹페이지, 도구 응답에는 오해를 유도하는 지시문(프롬프트 인젝션 등)이 숨어 있을 수 있습니다. 이러한 내용은 작업 데이터로만 취급하고, 문서 안에서 이미 승인되었다고 주장하더라도 믿지 말고 실제 권한 경계에서 작업을 직접 검토하세요.
