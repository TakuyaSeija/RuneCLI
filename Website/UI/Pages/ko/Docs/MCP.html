외부 확장 기능

MCP는 도구, 리소스 또는 프롬프트를 제공하는 외부 서버를 연결합니다. /mcp 또는 rune -mcp 명령어로 관리하며, 현재 Settings 화면의 별도 탭으로 분리되어 있지는 않습니다. 서버를 연결하는 것과 그 도구를 통해 수행되는 개별 작업을 승인하는 것은 별개입니다.

원격 서버는 사용자가 보내는 데이터를 수신하며, 로컬 서버는 이 컴퓨터에서 직접 코드를 실행합니다. 서버가 반환한 텍스트는 아무리 권위 있는 지시문이라고 주장하더라도 신뢰할 수 없는 작업 데이터로 취급됩니다.

적용 범위 및 승인

User
여러 프로젝트에서 사용할 수 있는 개인 정의입니다.
Project
프로젝트의 MCP 구성에 저장되는 공유 정의입니다. 내용을 검토한 뒤 명시적으로 승인해야 하며, 공유 정의가 변경되면 다시 승인이 필요할 수 있습니다.
Private project
단일 프로젝트에만 적용되는 개인 정의로, MCP 변경의 기본 범위입니다. 동일한 ID를 가진 공유 프로젝트 정의를 재정의할 수 있으며, 공유 프로젝트 정의는 개인 User 정의보다 우선합니다.

연결하기 전에 list와 status로 구성을 확인하고 정의를 검증(validate)하세요. 형식 검증 통과가 곧 실제 연결 성공을 뜻하지는 않습니다. add는 서버 ID와 원격 URL 또는 인수를 포함한 로컬 실행 파일의 절대 경로를 받습니다. 정확한 명령 구문은 설치된 빌드의 도움말을 확인하세요.

접근 권한 검토하기

서버를 추가하거나 활성화하기 전에 실행 파일과 인수(또는 원격 대상 주소), 인증 방식, 환경 변수, 프로젝트 쓰기 권한, 추가 읽기/쓰기 허용 폴더, 그리고 이미 실행 중인 로컬 서비스에 대한 접근 여부를 꼼꼼히 확인하세요. 작업에 꼭 필요한 권한만 부여해야 합니다.

원격 엔드포인트는 HTTPS가 필수이며 일반 HTTP는 루프백(loopback) 주소로만 제한됩니다. 공유 URL이나 일반 환경 변수 값에 시크릿을 직접 적어 넣지 말고 지원되는 자격 증명 관리 흐름을 사용하세요. 로컬 실행 파일 경로와 추가 루트 폴더 지정은 단순한 설명 라벨이 아니라 실제 시스템 접근 권한을 결정하는 설정입니다.

작업 공간 밖의 추가 폴더를 지정하면 Ask 및 Auto 모드에서 로컬 서버가 시작되기 전에 승인을 요청할 수 있습니다. 또한 광범위한 로컬 서비스 접근을 허용하면 현재 사용자 계정 권한으로 작동하는 다른 프로그램에 접근할 수 있으므로, 단순히 연결 실패를 넘기려는 목적으로 이 옵션들을 넓히지 마세요.

연결, 테스트 및 제거

list · status
구성된 서버 목록과 현재 연결 상태를 확인합니다.
validate
실제 연결을 시도하지 않고 정의 형식을 검사합니다.
connect <id> · test <id>
실제 연결을 수립합니다. 이 과정에서 로컬 코드가 실행되거나 원격 서비스와 통신할 수 있습니다.
approve <id>
검토를 마친 공유 프로젝트 정의를 승인합니다. 직접 확인하지 않은 파일에 대해 승인을 내려서는 안 됩니다.
disconnect <id>
현재 연결을 닫습니다(저장된 정의를 삭제하지는 않습니다).
enable|disable|remove <id>
올바른 구성 범위를 지정해 정의의 사용 가능 여부를 변경하거나 제거합니다.
reload
구성된 연결들을 새로고침합니다.
login <id> · login-status <id>
해당 서버의 인증 흐름을 시작하거나 인증 상태를 확인합니다.

위 작업들은 rune -mcp status처럼 rune -mcp 뒤에 붙여 실행합니다. 변경할 때마다 선택한 범위(scope)와 ID를 확인하세요. token이나 secret 같은 고급 자격 증명 명령어는 민감한 값을 다루므로, 셸 히스토리에 자격 증명이 남지 않도록 가급적 지원되는 인증 UI를 사용하세요.

인증에는 Bearer 자격 증명이나 OAuth 흐름이 사용될 수 있습니다. 대화창에 토큰을 직접 붙여넣지 마세요. 서버 연결에 성공했다고 해서 그 서버의 모든 도구가 안전하거나 되돌릴 수 있거나 완벽히 지원된다는 뜻은 아닙니다. 모델은 임의로 서버 API를 추측하지 않고 탐색된 정확한 도구 입력 형식과 기본 실행 제어 절차에 따라 도구를 호출합니다.
