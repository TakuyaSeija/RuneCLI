직접 명령어 실행하기

입력창의 맨 첫 글자로 !를 입력한 뒤 명령어를 적고 Enter를 누르세요. AI가 아니라 Rune이 사용자를 대신해 해당 스크립트를 직접 실행합니다. Enter를 누르기 전에 입력창에 Shell · full access once가 표시되므로, 일반 메시지가 아니라 셸 명령어를 실행한다는 점을 분명하게 확인할 수 있습니다.

! git status --short
npm test

위 예시는 두 줄짜리 단일 스크립트로, 두 줄 모두 실행됩니다. 첫 번째 줄에만 !를 붙이며, 두 번째 줄에 !를 또 쓰면 셸 자체가 이를 해석합니다(bash와 sh에서 !는 다음 명령어의 종료 상태를 반전시켜 실패를 성공으로 바꿉니다). 간단한 상태 확인, 직접 지켜보고 싶은 빌드, 또는 AI에게 허용되지 않았던 단계를 직접 처리할 때 유용합니다. 실행한 명령어와 출력 결과는 대화 기록에 추가되며, 실행이 끝난 뒤 AI가 이어서 응답합니다.

명령어로 인식되는 기준

  • 맨 첫 칸에 입력된 !만 수동 명령어로 시작됩니다. hello ! echo test, 공백 뒤의 !, 또는 일반 메시지의 둘째 줄 이후에 나오는 !는 일반 텍스트로 처리됩니다.
  • 입력이 !로 시작되면 그 안의 모든 줄이 하나의 스크립트가 됩니다. 이후 줄에 나오는 !는 두 번째 Rune 명령어가 아니라 셸 구문으로 전달됩니다.
  • 붙여넣기만으로는 아무것도 자동 실행되지 않습니다. Enter를 눌러야 붙여넣은 줄을 포함한 현재 스크립트 전체가 실행됩니다.
  • ! 한 글자만 입력하면 아무것도 실행되지 않습니다. 맨 앞의 !를 지우면 다시 일반 메시지 입력으로 돌아갑니다.

적용되는 권한

Enter를 누르는 것 자체가 승인입니다. 해당 스크립트는 현재 운영체제 사용자 계정의 전체 권한으로 한 번 실행됩니다. 즉, 작업 공간 경계와 명령어 샌드박스 밖에서 실행되며, 분류기나 정제기(sanitizer) 검토 및 추가 권한 확인을 거치지 않습니다.

단, 관리자(Administrator)나 root 권한으로 실행되지는 않으며, 세션의 권한 모드를 바꾸지 않고 이후 AI의 작업에 대한 승인을 부여하지도 않습니다. 특히 외부에서 붙여넣은 스크립트라면 Enter를 누르기 전에 전체 내용을 반드시 확인하세요.

AI가 작업하는 도중에 실행할 때

진행 중인 턴 도중에 보낸 수동 명령어는 현재 턴이 끝날 때까지 기다렸다가 보낸 순서대로 실행됩니다. 실행되는 동안 실시간 출력이 화면에 나타납니다. 명령어가 종료되거나, 설정된 대기 시간까지 끝나지 않거나 키보드 입력을 기다려 백그라운드로 전환되면, Rune은 명령어와 출력 내용을 대화 기록에 추가하고 AI가 이에 응답합니다. 이 응답은 일반적인 모델 요청이므로 비용이 발생할 수 있습니다.

창이 재연결되더라도 Rune은 동일한 명령어를 중복 실행하지 않고 기존 제출 내역을 그대로 이어받습니다. 또한 비정상 종료 후 다시 시작할 때는 이미 실행되었을 가능성이 있는 명령어를 절대 자동으로 다시 실행하지 않습니다.

AI의 명령이 거부되었을 때

AI가 제안한 명령어가 거부되면 안내 문구에서 이 수동 실행 방법을 언급할 수 있습니다. 하지만 Rune이 사용자를 대신해 ! 명령어를 자동으로 제출하거나 거부된 작업을 스스로 재시도하는 일은 절대 없습니다. 다른 도구들에는 이러한 우회 실행 경로가 없습니다.

실행에 사용되는 셸

사용할 셸은 terminal.shell 설정을 따릅니다. 기본값인 auto일 때 Rune은 시스템에 bash가 있으면 bash를, 없으면 /bin/sh를 사용하며, Windows에서는 PowerShell 7, Windows PowerShell, 명령 프롬프트(Command Prompt) 순으로 찾습니다. 각 셸은 고유한 문법으로 명령어를 해석합니다.

명령어 박스의 프롬프트 기호는 실제로 명령어를 실행한 셸을 나타냅니다. bash와 zsh는 $, PowerShell은 PS>, 명령 프롬프트는 >로 표시됩니다. 접혀 있는 박스는 스크립트의 첫 줄을 보여 주며, 클릭하면 원래 줄바꿈을 유지한 전체 스크립트가 펼쳐집니다.

프라이버시

실행한 명령어와 그 명령어가 출력한 모든 내용은 다음 요청 시 AI에게 함께 전송됩니다. 일반 메시지에 붙여넣지 않을 시크릿, API 키, 비공개 파일 내용은 화면에 출력하지 마세요. Rune은 등록된 키를 마스킹 처리하지만, 모든 비공개 값을 빠짐없이 가려 준다고 보장할 수는 없습니다.
