연결된 계정의 모델 둘러보기

Models 화면은 설정된 제공자와 그 카탈로그에서 사용할 수 있는 모델 목록, 그리고 사용자가 직접 추가한 모델 ID를 보여 줍니다. 검색은 이 목록 안을 필터링할 뿐 모든 벤더의 전체 모델을 외부에서 검색하지는 않습니다. 실제 사용 가능 여부는 계정, 엔드포인트, 권한, 카탈로그 최신 상태에 따라 달라집니다.

왼쪽에서 특정 제공자 또는 All providers를 선택하세요. 목록을 둘러보는 것만으로는 현재 대화의 모델이 바뀌지 않습니다. 모델을 고른 뒤 Enter를 눌러야 해당 제공자/모델 쌍이 적용됩니다. Ctrl+F를 누르면 검색창으로 돌아갑니다. 현재 활성화된 모델 쌍은 커서가 놓인 강조 항목과 구분되어 별도로 표시됩니다.

카탈로그 및 사용자 지정 ID

Refresh catalog를 실행하면 네트워크 요청을 보내 사용 가능한 모델 ID와 공개된 메타데이터를 받아옵니다(현재 활성 모델을 바꾸지는 않습니다). Enter model ID를 사용하면 정확한 식별자를 직접 추가할 수 있지만, ID를 추가했다는 것만으로 계정이 해당 모델을 실행할 수 있음이 보장되지는 않습니다.

확인되지 않은 컨텍스트 크기, 출력 한도, 가격은 미확인(unknown) 상태로 남습니다. 모델 이름에 들어 있는 단어만 보고 기능을 추측하지 말고, 제공자의 실제 한도가 늘어나는 것처럼 로컬 표시 숫자를 임의로 키우지도 마세요. 목록 항목에서 T를 누르면 실제 모델 테스트 요청을 전송하며 비용이 발생할 수 있습니다.

Alt+C로 모델 기능 설정하기

선택한 모델에서 Alt+C를 누르면 해당 모델의 영구 설정 창이 열립니다. 모델 기능(Capability) 정보는 모델이 수용할 수 있는 한도를 설명하고, Generation은 현재 세션에서 실제로 요청할 값을 제어합니다. 즉, 모델의 최대 출력 한도는 매 답변에서 요청하는 출력 길이가 아닙니다.

Context / output
알려진 모델의 최대 컨텍스트 및 출력 상한선을 기록합니다. 로컬에서 값을 높여도 상위 서비스의 실제 한도가 늘어나지는 않습니다.
Reasoning
시작 시 기본 추론 동작과 선택 가능한 추론 단계를 구성합니다. Thinking 배지는 해당 모델이 추론을 지원한다는 뜻이며 현재 세션에서 켜져 있다는 뜻은 아닙니다.
Modalities (입력 양식)
이 모델이 수용하는 입력 종류(text, image, audio, video, file)를 선언합니다. 카탈로그에 공개된 메타데이터가 있으면 자동 입력되며, 아무것도 공개하지 않는 게이트웨이 모델은 기본값인 text로 시작하여 여기서 직접 선언할 수 있습니다.
Pricing
로컬 비용 집계를 위해 확인된 입력/출력/캐시 가격을 입력합니다. 미확인 가격은 0원이 아니며, 캐시 가격을 입력했다고 해서 엔드포인트가 프롬프트 캐싱을 지원한다는 증거가 되지는 않습니다.

기본 제공자 및 항목 삭제

New-session fallback은 기존 세션을 덮어쓰지 않고 앞으로 새로 여는 세션의 시작 제공자를 지정합니다. 모델 항목에서 Delete를 누르면 목록에서 해당 결과를 숨기거나 제거하고 사용자 지정 모델 설정을 지웁니다(상위 제공자의 실제 모델을 삭제하지는 않습니다). 나중에 다시 추가하면 삭제했던 설정 대신 최신 카탈로그 메타데이터가 적용될 수 있습니다.

비용 집계의 한계 이해하기

지출 비용(Spend)은 사용량과 가격을 모두 알고 있는 요청을 바탕으로 계산됩니다. 가격을 몰랐던 요청에 대해 나중에 모델 가격이 설정되면 그때 비용이 계산되며, 이미 계산된 요청은 기록 당시의 비용을 그대로 유지합니다. 반올림, 캐싱, 할인 또는 불완전한 사용량 보고 때문에 제공자의 실제 청구 금액과는 차이가 날 수 있습니다.

지출 경고 설정은 강제 차단 한도가 아닙니다. 제공자 공식 가격을 확인하고, 엄격한 예산 통제가 필요하면 제공자 계정의 한도 설정을 사용하세요. 특정 답변 하나를 조정하려고 모델 기능(Capability) 값을 바꾸는 대신 생성 및 추론의 세션 제어 기능을 사용하세요.
