스킬은 작업 가이드입니다

스킬(Skill)은 특정 작업에 재사용할 수 있는 지침과 참고 자료를 하나로 묶은 패키지입니다. 실행 권한을 부여하는 수단이 아닙니다. 에이전트가 관련 스킬을 스스로 탐색해 SKILL.md를 읽거나, 사용자가 대화창에서 직접 스킬을 활성화할 수 있습니다. 외부 작성자가 만든 가이드나 스크립트는 따르기 전에 내용을 먼저 검토하세요.

탐색 및 사용법

/skills list
사용 가능한 가이드와 정확한 ID 목록을 나열합니다.
/skills show <id>
특정 가이드의 상세 정보를 읽습니다.
/skill <id>
현재 대화에서 특정 가이드를 활성화합니다. 가이드 본문이 관련 없는 작업을 승인하거나 실행 검사를 우회할 수는 없습니다.
/skills enable|disable <id>
현재 프로젝트에서 해당 스킬의 사용 가능 여부를 변경합니다(모든 사용자나 모든 프로젝트에서 삭제되지는 않습니다).
/skills reload
스킬 파일을 수정한 뒤 카탈로그를 새로고침합니다. 수정된 가이드를 적용하기 전에 내용을 다시 확인하세요.

저장 위치 및 설치

프로젝트 가이드는 .rune/skills/<name>/SKILL.md에 위치하며, 호환 프로젝트 가이드 위치인 .agents/skills/도 사용할 수 있습니다. 개인 가이드는 선택된 Rune 홈의 skills 폴더 아래에 저장되며, 활성화된 경우 호환 개인 위치도 함께 사용할 수 있습니다.

rune -skills install <folder-or-zip>은 검토를 마친 패키지를 현재 프로젝트의 .rune/skills/에 설치합니다. 따라서 다른 프로젝트와 섞이지 않고 해당 프로젝트 안에만 머물며, 저장소를 포함해 이 프로젝트 파일을 쓰는 모든 사람과 공유됩니다. 모든 프로젝트에서 쓸 개인 가이드로 설치하려면 --scope user를 추가하세요. rune -skills update <folder-or-zip>은 동일한 방식으로 선택한 범위의 설치본을 교체하며 이전 버전 사본을 따로 남기지 않으므로 원본을 보관하거나 버전 관리를 사용하세요. 각 패키지는 소문자 이름과 일치하는 폴더, name/description 메타데이터가 담긴 SKILL.md, 그리고 선택적인 상대 경로 참고 파일들로 구성됩니다. 내려받은 텍스트를 무조건 신뢰하지 말고 직접 내용을 확인한 뒤 설치 및 업데이트하세요.

AI에게 전달되는 스킬 정보

AI에게 모든 가이드의 전문이 한꺼번에 전달되지는 않습니다. 대신 사용 가능한 스킬들의 이름과 한 줄 설명으로 구성된 짧은 카탈로그만 먼저 전달되며, 실제로 필요한 스킬이 있을 때만 해당 가이드 전문을 읽습니다. 이 카탈로그는 기본적으로 8 KiB의 텍스트로 제한됩니다(skills.max_catalog_size). 카탈로그 용량에 다 들어가지 못한 스킬도 탐색 가능 상태로 남으므로 AI가 찾아서 읽을 수 있습니다. 이 한도는 모델 토큰 수가 아니라 바이트 단위 크기이며, capabilities.catalog_bytes를 따로 저장한 경우에는 그 값이 우선 적용됩니다.

크기를 변경하려면 rune -config set skills.max_catalog_size 16KiB를, 기본값으로 되돌리려면 rune -config reset skills.max_catalog_size를 실행하세요. 카탈로그 크기를 키우면 매 요청마다 모델 컨텍스트를 더 많이 사용합니다.

공식 오프라인 도움말

Rune에는 설정 가이드 스킬(rune-settings-guide)이 기본 내장되어 있어 별도의 다운로드나 서비스 계정이 필요하지 않습니다. 관리되는 공식 도움말 텍스트가 변경되거나 손상되면 자동으로 복구될 수 있으므로, 공식 가이드를 직접 수정하는 대신 별도의 개인 또는 프로젝트 스킬을 만들어 사용자 정의 내용을 작성하세요.

rune-settings-guide라는 이름은 공식 도움말 전용으로 예약되어 있습니다. 이 이름으로는 패키지를 설치하거나 업데이트할 수 없으며, 같은 이름의 다른 사본이 공식 가이드를 대체하지도 못합니다(목록에는 가려짐(shadowed)으로 표시됨). 그 외 일반 가이드는 여러 범위에 같은 이름으로 존재할 수 있으며 프로젝트 사본이 우선합니다. 구분할 때는 목록에 표시된 정확한 ID를 사용하세요. 확장 기능이나 해당 가이드를 비활성화하면 공식 도움말도 사용할 수 없게 될 수 있으나, 이는 설치된 바이너리에 해당 기능이 없다는 뜻이 아닙니다.
