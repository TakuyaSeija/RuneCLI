세 가지 서로 다른 한도

화면 접기(display fold)는 처음에 화면에 몇 줄을 보여 줄지 제어합니다. 반환 출력 상한(returned-output cap)은 AI가 전달받는 텍스트 양을 제어합니다. 캡처 및 작업 한도(capture/work limit)는 명령어를 중지하거나 검색을 종료시킬 수 있습니다. 어느 하나를 늘린다고 다른 한도가 함께 늘어나지는 않으며, 어떤 한도 설정도 파일이나 네트워크 접근 권한을 새로 부여하지 않습니다.

Settings → Tools를 열고 관련 그룹을 선택한 뒤 수정하고 Apply를 누르세요. Use default는 전역 재정의를 제거합니다. 아래의 초기 기본값은 사용자가 저장한 설정이 아니라 Rune {{.DocVersion}} 기준 기본값이며, 개별 키는 rune -config explain <key>로 확인할 수 있습니다.

파일 도구

inspect_file
단일 파일을 읽으며 텍스트 파일은 시작·끝 줄 범위를 포함해 지정할 수 있습니다. 초기 기본 최대 파일 크기는 16 MiB, 반환 텍스트는 30,000자입니다. 지원되는 비텍스트 파일은 해당 기능을 갖춘 모델에 첨부할 수 있습니다.
find_files
Glob 패턴으로 파일 경로를 찾습니다. 패턴은 *, **, ?, [a-z] 같은 문자 클래스, | 대안, 그리고 중첩 그룹을 포함한 *.{ts,tsx} 같은 중괄호 그룹을 지원합니다. 초기 기본 최대 반환 경로 수는 200개, 텍스트는 20,000자입니다. 호출별 제한 인수는 이 최대치를 낮출 수만 있고 높일 수는 없습니다.
search_text
파일 내용을 검색합니다. include 필터는 같은 경로 glob 문법을 지원합니다. 초기 기본 최대 일치 줄 수는 100줄, 줄당 2,000자, 전체 30,000자이며, 개별 파일 크기 한도는 inspect_file과 공유합니다.
create_file
새 파일을 생성하며 기존 파일이 있으면 덮어씁니다. 권한 확인과 파일 보호 규칙을 통과해야 실행됩니다.
patch_file
정확히 일치하는 텍스트 조각 하나를 교체합니다. 기존 텍스트가 파일 안에서 정확히 한 번만 나타나야 하며, 여러 곳에 중복되는 모호한 일치는 일괄 교체되지 않고 거부됩니다.

경로 및 텍스트 검색은 숨김 파일과 무시된(ignored) 파일 이름도 포함하며, .git과 .rune은 패턴이 그 안의 폴더를 지정할 때만 검색합니다. 공통 스캔 한도는 항목 200,000개, 깊이 32단계, 줄당 정규식 연산 200,000단계입니다. 한도에서 멈춘 검색은 그 사실을 알려 주며 더 많은 결과가 남아 있을 수 있습니다. 검색은 패턴이 지정한 폴더에서 시작하므로, 한도를 높이기 전에 먼저 폴더를 지정해 보세요.

터미널 및 프로세스 도구

terminal_use는 새 셸에서 명령어를 실행합니다. 초기 기본 포그라운드 대기 시간은 120초, 반환 텍스트는 30,000자, 백그라운드 로그당 최대 크기는 100 MiB입니다. 포그라운드 대기 시간이 지나면 작업이 백그라운드로 전환되지만, 출력이나 로그 캡처 한도를 초과하면 실행이 중지될 수 있습니다. process_control은 입력 대기 중인 작업에 응답을 타이핑해 넣거나 하위 프로세스 트리 전체를 중지할 뿐 출력을 읽거나 완료를 기다리지 않습니다. 완료되었거나 입력을 기다리는 작업의 알림에는 상태, PID, 실행 시간, 로그 경로와 아직 전달되지 않은 출력이 담깁니다. 기본 한도는 30,000자이며, 함께 도착한 알림들이 이 한도를 나눠 씁니다.

실행 의도(launch intent), 플랫폼별 입력 대기 감지, 작업 수명에 관한 자세한 내용은 터미널 및 백그라운드 작업을 참고하세요.

웹 및 확장 도구

web_search
검색어와 선택적인 결과 수 제한으로 웹을 검색합니다. 초기 기본 최대 결과 수는 8개, 요청 타임아웃은 60초, 출력 텍스트는 100,000자입니다.
web_fetch
공개 웹페이지 하나를 읽습니다. 초기 기본 타임아웃은 60초, 반환 텍스트는 100,000자이며, 이 도구만의 별도 제공자 선택 설정을 갖습니다.
discover_capabilities
아직 목록에 노출되지 않은 스킬, MCP 도구 및 리소스를 찾습니다. 초기 기본 반환 텍스트 허용량은 30,000자입니다.
call_mcp_tool
탐색된 외부 도구를 해당 서버가 선언한 정확한 입력 형식에 맞춰 호출합니다. 서버가 수행하는 작업과 그에 따른 위험은 해당 서버 자체에 속합니다.
read_mcp_resource
탐색된 리소스를 읽습니다. 초기 기본 반환 텍스트 허용량은 50,000자입니다.

계획, 질문 및 작업 조율

track_tasks는 작업 목록 전체를 교체하며, 기본적으로 각각 120자 이내의 최대 20개 작업 항목을 지원합니다. 설정 가능한 주기에 따라 시스템 알림으로 계획을 다시 회신해 주는 알림 기능도 제공되며, 기본값은 도구 호출 8회마다(plan.reminder_tools) 또는 15분마다(plan.reminder_seconds) 작동하고 0으로 설정하면 해당 트리거를 끌 수 있습니다. ask_user_questions는 명시적인 양식으로 결정을 요청합니다. 질문 대기 시간은 기본적으로 무제한이며 권한 확인 대기는 10분 후 만료됩니다. 무제한은 만료되지 않는다는 의미일 뿐 자동 승인을 뜻하지 않습니다.

tools.max_actions_per_response는 모델 응답 한 번에 제안할 수 있는 최대 도구 호출 수로 기본값은 20개입니다. 이는 전체 작업 예산이나 워커(worker) 수, 또는 병렬 실행 보장을 뜻하지 않으며 각 호출은 여전히 개별적인 권한 확인과 검증을 거칩니다.

신중하게 한도 조정하기

모든 도구에 숫자 편집 UI가 따로 있는 것은 아닙니다. 한도를 높이면 더 많은 내용이 노출되고 시간, 디스크, 메모리, 모델 컨텍스트 소모가 늘어날 수 있습니다. 반대로 한도를 낮추면 필요한 근거가 생략되거나 작업이 멈출 수 있습니다. 잘린(truncated) 결과를 완전한 결과라고 단정하지 말고 불완전한 출력 안내 문구를 항상 확인하세요.
