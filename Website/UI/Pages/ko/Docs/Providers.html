제공자 추가하기

제공자(Provider)는 Rune의 모델 요청에 응답하는 계정입니다. Rune은 자체 계정이나 내장 API 크레딧을 제공하지 않으며, 모든 요청은 사용자가 직접 연결한 제공자로 전송되고 해당 제공자 기준에 따라 과금됩니다.

  1. Ctrl+G를 눌러 Connections를 열고 Add connection을 선택합니다.
  2. MODEL PROVIDERS 아래에서 사용할 제공자의 프리셋을 고르거나, 그 외 OpenAI 호환 엔드포인트라면 compatible을 선택합니다.
  3. 프리셋에 고정 주소가 없는 경우 주소를 먼저 입력한 뒤, 마스킹된 입력란에 API 키를 붙여넣고 Enter를 누릅니다.
  4. Rune은 연결을 저장하기 전에 계정을 확인하기 위해 실제 요청을 한 번 보냅니다. 이 요청에는 테스트 텍스트가 전송되며 요금이 부과될 수 있습니다.
  5. Models를 열고 제공자를 선택한 뒤 Enter로 모델을 선택합니다.

연결이 저장되었다는 것은 계정이 한 번 정상 응답했음을 뜻할 뿐, 해당 제공자 목록의 모든 모델을 사용할 수 있다는 뜻은 아닙니다. API 키는 컴퓨터에 암호화되어 저장됩니다(자격 증명 참고).

모든 프리셋 목록

제공자별 참고 사항

추론(Reasoning) 제어 방식은 제공자와 모델마다 다릅니다. 아래 내용은 Rune이 전송하는 형식을 설명하며, 실제 모델의 동작은 제공자 측 정책에 따라 달라질 수 있습니다. 모델별 추론 선택지는 생성 및 추론의 안내에 따라 Models 화면에서 Alt+C로 설정합니다.

alibaba
Model Studio 작업 공간 및 리전의 호환 모드 주소와 해당 리전의 키를 함께 사용하세요. 사고(Thinking) 기능은 단계 구분 없이 켜기/끄기만 지원합니다. 항상 추론을 수행하는 모델에는 Off를 지정하지 마세요(요청이 거부됩니다). Model Studio의 GLM 모델은 Rune이 보내지 않는 별도 옵션이 있어야만 도구 호출을 반환하므로 Z.ai를 통해 사용하세요.
cerebras
추론 단계가 모델마다 다르며 서비스 목록에 자동 표시되지 않습니다. gpt-oss-120b와 qwen-3.8-27b는 Low, Medium, High를 지원하므로 Alt+C로 추가해 사용하세요.
cloudflare
Workers AI입니다. 주소에는 계정 ID가 들어가며, 키는 Tunnel 토큰이 아니라 Workers AI 접근 권한이 있는 API 토큰이어야 합니다. 모델 목록은 계정의 모델 카탈로그에서 읽어 옵니다.
compatible
임의의 OpenAI 호환 엔드포인트입니다. 모델의 사양을 임의로 가정하지 않으므로, 엔드포인트 문서를 참고해 Alt+C로 컨텍스트 크기, 출력 한도, 추론 옵션을 직접 설정하세요.
deepinfra
모델 목록에서 가격과 추론 지원 여부를 제공합니다. 단계는 Low, Medium, High이며, 단계를 선택하지 않으면 모델 자체 기본값이 적용됩니다.
fireworks
Low부터 Max까지의 단계를 지원합니다. 더 적은 단계만 받는 모델은 Alt+C로 조정하세요.
huggingface
Inference Providers 호출 권한이 있는 토큰으로 Inference Providers 라우터를 사용합니다. 어떤 제공자가 모델을 서빙하는지와 지원 기능은 선택한 조합에 따라 달라집니다.
inclusionai
Ant Group의 Ling API를 통해 InclusionAI의 Ling 모델을 사용합니다. 3.0 및 3.1 모델은 단계 구분 없이 사고 기능을 켜거나 끕니다. 직접 호스팅하는 Ling 서버는 compatible로 추가하세요.
inference
모델 목록에 각 모델의 사고 단계가 명시되어 있으며 Rune은 그 단계들을 그대로 제공합니다.
meta
Meta AI 챗봇 로그인이 아니라 Meta Model API입니다. Minimal부터 Extra high까지의 단계를 지원합니다. Muse Spark는 항상 추론을 수행하며 Off와 중단 시퀀스(stop words)를 거부하므로 Generation에서 Stop을 비워 두세요.
mimo
종량제 키와 Token Plan 키는 서로 다른 주소로 연결되며, 입력한 키 형식에 따라 Rune이 알맞은 주소를 자동으로 선택합니다.
minimax
Rune은 답변 본문과 분리하여 사고 과정을 요청합니다. MiniMax-M3.1-Flash만 단계(Low~Max)를 지원하므로 Alt+C로 추가해 사용하세요. MiniMax 모델에는 Off를 제공하지 마세요.
moonshot
Kimi입니다. kimi-k3는 Low, High, Max를 지원하므로 Alt+C로 추가하세요. kimi-k2 계열 모델은 별도 단계를 받지 않습니다. Kimi 모델에는 Off를 제공하지 마세요.
novita
켜기/끄기를 모두 지원하는 모델에서 단계 구분 없이 사고 기능을 전환합니다. 가격 정보는 모델 목록에서 가져옵니다.
nvidia
호스팅형 NIM API입니다. 사고 제어 옵션은 모델마다 다르며 서비스에서 목록으로 제공하지 않으므로 각 모델 카드 기준에 맞춰 모델별로 설정하세요. 자체 호스팅 NIM은 해당 서버 주소를 입력해 사용합니다.
openrouter
하나의 계정으로 가격과 한도가 서로 다른 수많은 모델을 제공합니다. 정확한 모델을 선택하고 현재 가격을 확인하세요.
siliconflow
글로벌 기본 주소를 사용하며, .cn 계정은 전용 주소와 키를 사용합니다. SiliconFlow가 표시한 지원 모델에서 사고 기능을 켜거나 끌 수 있습니다. deepseek-ai/DeepSeek-V3.1은 사고 기능을 끈 상태에서만 도구를 호출합니다.
stepfun
단계는 Low, Medium, High입니다. step-3.5-flash-2603은 Low와 High만 받으므로 Alt+C에서 Medium을 제거하세요.
tencent
Hunyuan은 TokenHub로 이전 중입니다. 주소 입력란 옆에 안내된 해당 리전의 TokenHub 주소와 그 리전의 키를 입력하세요. 사고 기능은 켜기/끄기 및 Low, Medium, High 단계를 지원합니다. TokenHub가 타사 벤더용으로 서빙하는 일부 모델은 Off를 거부합니다.
together
모델 목록에서 가격은 제공하지만 사고 단계는 제공하지 않으므로 문서에 안내된 모델별 단계를 Alt+C로 추가하세요.
tokenrouter
tokenrouter.com의 TokenRouter입니다. 다른 도메인에서 비슷한 이름을 쓰는 서비스는 별개의 회사와 주소를 가진 다른 서비스입니다.
zai
Z.ai 표준 API입니다. Coding Plan은 별도의 키와 주소, 허용 도구 목록을 사용합니다. 단계는 Minimal부터 Max까지이며 선택하지 않으면 서비스 기본값(Max)이 적용됩니다. glm-5.3은 항상 추론을 수행하며 Low, High, Max만 받습니다. 중단 단어(stop word)는 하나만 허용됩니다.

이 컴퓨터에서 실행되는 모델

Ollama는 API 키 없이 이 컴퓨터의 포트 11434에서 로컬 모델을 서빙합니다(Ollama의 클라우드 웹 검색 서비스와는 별개입니다). 로컬 모델을 쓰면 프롬프트가 내 컴퓨터 안에 머물지만, 웹 도구, 보조 모델 작업, 셸 명령어는 여전히 외부 서비스와 통신할 수 있습니다.

9router는 내 컴퓨터(기본 포트 20128)에서 실행되는 라우터 앱으로, 앱 안에 설정해 둔 상위 계정들로 요청을 전달합니다. 연결 하나로 9router가 제공하는 모든 모델을 사용할 수 있습니다. Claude Code 모델(cc/…)의 경우 Rune이 자동으로 9router의 Anthropic 방식 경로를 사용하므로 별도 설정 없이도 캐시 및 사고 토큰 수치가 정상 전달됩니다. Off는 추론 수준을 전혀 보내지 않습니다. 경로는 자체 기본값을 유지하며, 사고를 켠 뒤 수준을 선택할 때만 이를 덮어씁니다.

프리셋의 로컬 주소는 기본값일 뿐 해당 서비스가 현재 컴퓨터에서 실행 중이라는 뜻은 아닙니다. 먼저 로컬 서비스를 실행한 뒤 연결하세요. 응답 여부는 Rune의 테스트 요청으로 확인할 수 있습니다.

키 및 계정 관리

하나의 연결에 여러 개의 키를 등록해 둘 수 있습니다. rune -provider keys <name>은 키 목록을 마스킹하여 보여 주며, Connections에서도 실제 키 값을 노출하지 않고 관리할 수 있습니다. 특정 키에서 잔액 부족이 보고되거나 할당량을 소진하면 Rune은 링의 다음 키로 즉시 순서를 넘깁니다(런타임 및 재시도 참고).

연결을 제거하면 해당 구성이 삭제되지만, 키 자체는 재사용을 위해 암호화된 저장소에 남아 있을 수 있으므로 키를 완전히 지우려면 키를 명시적으로 삭제하세요. 또한 API 키는 다른 머신으로 일반 HTTP(비암호화)를 통해 절대 전송되지 않습니다.

모델 선택하기

Settings → Models는 연결된 제공자들이 반환한 모델 목록을 보여 주며 목록을 새로고침할 수 있습니다. Enter로 모델을 선택하거나 대화창에서 /model provider:id를 입력하세요. 모델 위에서 Alt+C를 누르면 컨텍스트 크기, 출력 한도, 추론 옵션, 가격 등 Rune이 해당 모델에 대해 알고 있는 정보를 편집할 수 있습니다. 직접 입력한 가격은 사이드 패널의 지출 비용 계산에 사용되며 제공자의 실제 청구서와는 별개입니다.

Models → New-session fallback은 새 세션을 시작할 때 기본으로 사용할 제공자를 지정합니다. 이미 열려 있는 대화의 제공자는 바꾸지 않으므로 열린 세션에서는 /provider나 /model을 사용하세요.
