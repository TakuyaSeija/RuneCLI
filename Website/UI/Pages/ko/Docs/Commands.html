명령어 사용법

입력창에 /를 입력해 팔레트를 검색하세요. 방향키로 항목을 고르고 Tab으로 완성한 뒤 Enter로 실행합니다. 대괄호([ ]) 안의 인수는 선택 사항이며, 꺾쇠괄호(< >)는 그대로 입력하는 글자가 아니라 사용자가 직접 넣어야 할 값을 뜻합니다. 현재 설치된 빌드의 정확한 기준은 /help에서 확인할 수 있습니다.

세션 및 컨텍스트

/new
현재 작업 공간에서 새 대화를 시작합니다. 기존 세션을 삭제하지는 않습니다.
/session
현재 작업 공간의 세션을 검색해 고를 수 있는 선택기를 엽니다.
/resume <id>
저장된 특정 세션을 이어서 진행합니다.
/compact
오래된 컨텍스트를 요약합니다. 모델 요청이 발생할 수 있고 이전 세부 내용이 줄어들 수 있으며, 디스크 저장 공간을 지우지는 않습니다.
/context
모델에 전달되는 컨텍스트를 확인합니다. 외부에 공유할 때는 민감한 작업 내용이 포함되어 있는지 주의하세요.
/logs [all|warn|error]
진단 이벤트 로그를 열며, 심각도별로 필터링할 수 있습니다. 실패한 요청과 재시도 내역이 여기에 기록됩니다(로그를 여는 것만으로는 재시도나 계정 변경이 승인되지 않습니다).

모델 및 권한

/model [provider:id|id]
제공자/모델 쌍을 선택하거나, 인수 없이 실행해 Models 화면을 엽니다. 여러 제공자에 겹치는 모델 ID는 목록에서 제공자를 통해 고르는 것이 확실합니다.
/provider [name]
응답할 제공자를 선택하며, 이름을 생략하면 목록을 엽니다. 이후 작업이 전송되는 대상이 바뀝니다.
/thinking [off|effort]
현재 모델이 지원하는 추론 강도 옵션을 확인하거나 선택합니다. Alt+T로도 순환할 수 있습니다. off는 요청 값일 뿐 상위 경로에서 추론을 전혀 쓰지 않는다는 보장은 아닙니다.
/mode [ask|auto|full]
세션의 권한 모드를 순환하거나 명시적으로 지정합니다. Full은 광범위한 자율 실행 권한을 부여하므로, 단순히 오류를 넘기기 위한 용도로 사용하지 마세요.
/classifier [on|off|model|reload]
정책 검토 분류기를 확인하거나 설정합니다. reload는 유휴 세션에 새 정책을 반영하며, 스위치가 켜져 있다는 것만으로 분류기가 활성 상태임이 보장되지는 않습니다.
/set key=value
/set temperature=0.2처럼 지원되는 모델/세션 제어 값을 변경합니다. /set temperature=처럼 선택 값을 비우면 기본값이나 제공자 기본 설정으로 돌아갑니다.

파일 및 확장 기능

/attach path
다음 메시지에 파일을 첨부합니다. 보내기 전에 대기 중인 첨부 목록을 확인하세요. 지원되는 파일 내용은 선택한 제공자로 전송됩니다.
/detach number|all
대기 중인 첨부 파일을 번호로 하나씩 빼거나 전체를 제거합니다.
/undo
복원 가능한 파일들을 이번 세션에서 처음 변경하기 전 상태로 미리 보고 되돌립니다. 세션 도중 외부에서 수정한 내용이 덮어써질 수 있습니다.
/redo
가장 최근의 undo가 되돌린 내용을 미리 보고 다시 적용합니다. 무제한 백업 기록이 아닙니다.
/skills [list|show|enable|disable|reload]
사용 가능한 스킬 가이드를 관리합니다. show, enable, disable에는 목록에 표시된 스킬 ID를 넘기며, reload는 편집 후 카탈로그를 새로고침합니다.
/skill <id>
현재 대화에서 특정 스킬 가이드를 활성화합니다. 가이드를 활성화해도 가이드에 적힌 모든 작업 권한이 자동 승인되지는 않습니다.
/mcp [list|add|connect|status]
외부 도구 연결을 관리합니다. 추가하거나 연결하기 전에 서버와 대상 주소, 접근 범위를 검토하세요. 로컬 서버는 코드를 직접 실행할 수 있습니다.

화면 및 애플리케이션

/settings
Settings 화면을 엽니다. /*는 별칭이며 키보드 단축키는 Ctrl+G입니다.
/theme [name]
violet, cyan, amber 중 테마를 선택합니다. 터미널 자체의 배경색과 투명도는 터미널 설정에서 관리합니다.
/panel
대화 화면의 사이드 패널을 켜거나 끕니다. 터미널 폭이 좁으면 계속 숨겨질 수 있습니다.
/verbose
도구 실행 단계와 사고 과정을 한꺼번에 펼치거나 다시 접습니다. 도구의 출력 반환 한도 자체를 늘리지는 않습니다.
/help
현재 빌드의 명령어 및 키보드 레퍼런스를 확인합니다.
/quit
Rune을 종료합니다. 마지막 창을 닫으면 진행 중인 AI 작업이 중지되며, 유지 중인 백그라운드 작업에는 별도의 수명이 적용됩니다.

rune -config 같은 셸 명령어는 슬래시 팔레트가 아니라 운영체제 터미널에서 실행합니다. 자세한 내용은 CLI 레퍼런스를 참고하세요. 입력창에서 직접 셸 명령어를 실행하려면 첫 글자를 !로 시작하면 됩니다(수동 명령어 참고).
