# Settings Overview

Open Settings with Ctrl+G, `/settings` or `/*`. Overview has six cards: Models, Generation, Connections, Runtime, Tools and Appearance. Each card opens that section.

## Navigation
- Arrows choose a row/card; Enter opens it. Mouse clicks also select/open controls.
- Tab/Shift+Tab focuses the section tabs when not editing. Left/Right chooses a section; Enter/Down returns to its content.
- Esc cancels an editor, otherwise returns one level. From Overview, Esc returns to the conversation.
- Wheel scrolls the current list. More above/below means additional rows are offscreen.
- The footer explains the selected row. A shortened label may simply need more terminal width.

## Applying values
Open a setting with Enter, enter a valid value, then Apply. Cancel/Esc keeps the previous value. `Use default`, where offered, removes the custom value.

Some choice rows save as Left/Right changes them; check the displayed hint. Merely highlighting an item in a separate list is not always applying it. Wait for the success message before treating a change as saved. A failed save should be reported as failed.

Auxiliary-model settings ask for an extra confirmation because changes affect every session, cost or review behavior. This is a settings confirmation, not permission to run an unrelated command.
