# Website contract (binding)

The owner's binding rules for the public RuneAgent site in `Website/`. They lived in `AGENTS.md`/`CLAUDE.md` until that file outgrew its opening-context budget (`scripts/check_git_policy.py`); the text is unchanged, and `AGENTS.md` points here. Read this before changing anything under `Website/`, and keep it current with every owner decision about the site.

public product information only; no private deployment paths, ports, hosts, credentials or defense internals. User-facing commands/configuration names and public security/privacy/architecture explanations belong in Docs. Brand is `RuneAgent` + `Atoryn Studio`; local Inter and JetBrains Mono, readability first: the header, the footer and every heading use Inter at the parent site's scale, so the whole family reads alike (owner, 2026-11-03: Instrument Serif is no longer used or loaded). The hero is words, not a picture (owner, 2026-10-28): a centred title that says what RuneAgent is and widens line by line — the second line longer than the first, the lead longer than the title and kept as two lines on wide screens — then one install box whose first row holds the Linux/macOS/Windows tabs (CSS radios; the visitor's system preselected), its command under them (Linux and macOS `curl … install.sh | sh`, Windows `irm … install.ps1 | iex` in PowerShell) and a last row naming what the current release has for that system or that the command installs nothing yet (owner, 2026-10-29: the tabs belong to the box, not a capsule above it), and below it two quiet links: the manual and the chosen system's installer (View install.sh / View install.ps1); no buttons, no image. The mark is the owner's own logo (owner, 2026-10-31): the transparent artwork in the header and footer (26 px in the header, 20 px in the footer, decorative because the wordmark names the brand), and the same artwork on its dark plate as the browser tab icon at 16, 32 and 96 px and as the full-bleed touch icon, so a light or dark tab never loses it; `Images/Logo.png` is that artwork at 96 px (the header shows it at 26 px, so a 3x display still has every pixel), and the owner's 256 px originals stay in `Website/Brand/` as the source `Website/Tools/build_brand_assets.py` derives every served file from. Light is one still layer behind the page: each section's glow is a full-width box that fades out before its own edges and runs past its section, so it passes beneath the section lines and is never clipped at a border; the lines stay. No smoke, pulses, twinkles, rings, sweeps, floats or embers (owner, 2026-10-28: those read as AI slop). Header and footer carry the owner's logo image, not a drawn stand-in (owner, 2026-10-31); the replay keeps the CLI's own half-block logo because an illustration shows only what the CLI draws; themes belong in Docs, not Home. Obsidian palette with one ember accent from its core, no decorative status dots. The header is the `RuneAgent` mark and the product name, then `Docs` and `Install` as two text links of the same kind (owner, 2026-11-03: the Install capsule is gone, the header holds words only); the name slides in from the left once the page has scrolled 48px, the same moment, curve and clip as atoryn.com, so above that point the header carries the mark alone; buttons keep the capsule: a faint white fill and a thin neutral rim, never a warm or yellow rim, text only, no icons, never solid ember, no hover glow; header and footer links brighten their ink and draw no underline, the current page is not underlined, and keyboard focus is that same brighter ink — no outline box and no underline, in the header, the footer and the manuals (owner, 2026-11-03); links carry no arrows, only the centre-out underline where a link sits inside prose; headings carry no label above them; every code block has a corner copy icon that copies in one click (async clipboard where secure, the selection command on plain http) and answers with a check in the page's ink, never green. Home may show a live HTML/CSS CLI illustration based on the actual binary's layout and theme/logo assets (owner, 2026-10-26), never a screenshot/video substitute or a fabricated benchmark; label illustrative content and simulated approvals. The illustration is an excerpt of one recorded session (`UI/Data/`, built by `Tools/build_session_data.py` from that session's own records): six chapters chosen in `Server/DemoExcerpt.go` and laid out by `Server/Demo.go` the way `draw.rs` lays it out, complete before any script runs, never the whole recording (owner, 2026-10-28: the 14-minute replay made Home 2 MB). Public source rows remain complete after labelled redaction; the offline builder reuses the CLI's own diff, lexer and palette through `Tools/render_source.py`, never a second implementation. Preview folding is native, interactive and lossless (including no JS); sent messages use the transcript's full width. Effort labels use the CLI composer's neutral Text ink, never the site's theme accent/faint (owner, 2026-10-26). Scrollbars are hidden, not scrolling. Home: centred hero with the single curl block, then centred section intros; the session's honesty labels sit in its lead and the window title, with the six chapters (seek) as one strip of equal cells fixed to the top of the terminal window, parted from its title bar by a change of tone, never a drawn line, the window's rim around both (owner, 2026-10-29), above a uniformly scaled complete 960×600 canvas sized by viewport height so text stays ≥10.5px; full screen is the browser's own (a full-window cover where it refuses) and shows the chapters and the terminal only, nothing of the page; at ≤920px the terminal draws at its own size, one column, panel on request; on phones (≤600px) the replay is not shown — the session's own final report stands in, still, with a native "Show the whole report" disclosure; no minus/percent/plus text-zoom controls. The side panel's stats are one line each, cut with … like the CLI's `{key:<15}` rows; the composer hangs continuation rows under the text after `›`. Header and footer run edge to edge with small padding, a translucent blurred header and a compact footer (License, Atoryn; font licenses on the License page); the footer names its product as a link to this site's own front page, and `Atoryn` leads to the parent site — the same origin in production, the landing's own address where a dev host serves this site on its own port (owner, 2026-11-03: `Config.parentURL`, default `/`); a page that does not exist answers with the site's own 404 — its words, both ways back and its footer — never the server's default, and the footer stays at the foot of the page on every page, so a short page never shows it halfway up a phone screen; a tap draws none of the browser's own highlight, so a phone behaves like the desktop; no development banner on any page; the page scrollbar is a thin warm thumb. Linux is the primary platform; macOS and Windows are stated as beta and have their installers (owner, 2026-10-29): `install.sh` for Linux (x86_64/arm64, glibc/musl) and macOS (Apple silicon/Intel, the system's LibreSSL), `install.ps1` for Windows (x64/ARM64, Windows PowerShell 5.1 and PowerShell 7); the catalog accepts exactly those archives (tar.gz; zip for Windows). Releases are signed with ECDSA P-256 over SHA-256 so stock macOS and Windows can verify them; installers never edit a shell profile or PATH. Docs carry a Platform support article for what differs between the systems. Docs, Changelog, License and 404 share the system: Inter titles at the parent's scale, one readable column, chevron disclosures drawn as a thin line, ember index bars, copy controls on every code block. Reading pages keep a plain ground for understanding: the brand's light appears only on the rim of a box (owner, 2026-10-28); License and Changelog put their contents on the right, like the manual's On this page (owner, 2026-10-29). The License page is the shipped `LICENSE.txt` word for word (`License_test.go`). Text responses are gzipped once and cached. The replay's CLI header and status line name the current version (owner, 2026-10-29). The closing section has one capsule button to the install box and names the release beside it only once one is published; there is no "coming soon" line. Expanded (full-screen) view preserves the same cell geometry; logo uses the CLI's 11-column/eight-row half-block size. Frames touch only new/active steps, not settled syntax trees; closed previews mount only their measured head rows and retain complete source nodes for native disclosure, which restores every row when opened or remeasured. Replay detaches future containers without rewriting their source (SSR/no-JS remains complete). Simulated terminal stdout arrives in complete row batches, never per-character typing; provider text/argument prefixes arrive whole words at a time.
